# 스마트 미러 요약 화면 QA — 2026-10-07

## 범위와 검토 조건

현재 은색 글래스/픽셀 사무실 요약 화면만 검토했다. React 19, Vite 6, Framer Motion 12, 로컬 Galmuri11 woff2, 미러 전용 CSS를 사용한다. 기능 경계와 운영 조건은 `../README.md`, 사용자 제공 AGENTS.md와 개인 설정을 참조했다. 별도의 저장소 디자인 규약 문서는 검색에서 확인하지 못했다.

기존 은색 팔레트, 배경 PNG, 스프라이트 크기, 출근→업무→퇴근 순서와 43초 자동 안내를 유지했다. 실제 카메라/NFC/보고서 화면은 검토 범위 밖이다.

## 검증

- `npm run build`: 성공. 기존 500kB 번들 경고가 남는다.
- `node --test src/features/smart-mirror/lib/*.test.js src/lib/pocApi.test.js`: 23개 통과. 43초 시점, 숨김 탭, 동의 조건, 캐릭터 이동/정지, reduced-motion 분기를 확인한다.
- CUA 실제 브라우저: CSS 320×720에서 가로 넘침 없음, 캡션 12px/설명 14px/단계 16px/굵기 400 확인.
- CSS 2160×3840: 로컬 폰트 로드 확인, 정상 및 오류 상태 가로/세로 넘침 없음.
- 검토 URL `?state=error`, `?state=consent`: 진행률 0, 걷는 스프라이트 0, 복구 안내 노출. 이 파라미터는 검토 harness에서만 사용한다.
- 전경/배경 측정: 퇴근 4K 정지 표본의 인접 배경 기준 단계 비활성 7.16:1, 활성 19.63:1, 카드 메타데이터 6.79:1, 제목 13.16:1, 설명 8.72:1. 배경/글자 전체 픽셀의 최저값이나 모든 장면의 대비를 보증하는 수치는 아니다.
- 캡처와 측정 데이터: 작업 공간 `output/mirror-qa/`. 브라우저 캡처의 여분 캔버스는 CSS 좌표와 대조해 제거한 미리보기를 제공한다.

## 미검증 / 운영 조건

실제 유리 투과율·주변 조명·65인치 TV, OS reduced-motion 설정을 바꾼 실기기 테스트, 200% 브라우저 줌, RTL, 실제 스크린 리더, 자동 접근성 감사, Animations 패널 10% 재생은 미검증이다. reduced-motion 캐릭터 정지는 소스와 단위 테스트로 확인했다.

무터치 미러의 자동 안내는 사용자 지정 운영 조건이므로 유지했다. 화면에 일시정지 제어는 없다. 자동 진행/시간 제한에 대한 일반 웹 접근성 준수 승인은 이 검토에 포함하지 않는다. 일반 웹 페이지로 운영할 경우 별도 중지·재개 경로가 필요하다.

Lazyweb 참고 검색은 수행했으나 보고서 생성 job `8911b27c-a48f-490b-92ff-cdd45b777cde`가 HTTP 502로 실패했다. 생성된 보고서나 링크가 있다고 주장하지 않는다.
