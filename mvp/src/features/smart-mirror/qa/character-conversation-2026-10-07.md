# 인물 비율 및 대화 동작 QA

기존 은색 색감과 레이아웃으로 복원했다. 레이아웃 3안 및 그 전용 컴포넌트는 제거했고 좌우 여백 변경도 되돌렸다.

- 모든 분리된 서 있는 인물은 동일한 96×160 프레임, 장면 너비 10%를 사용한다. 참여자는 기존 16%에서, 대화 상대는 13%에서 줄었다. 배경 PNG에 그려진 앉은 인물은 그대로 유지했다.
- 참여자 정지 위치는 상대 왼쪽 12% 지점이며 바닥 위치도 상대와 일치한다. 7.2초 설명 구간에서 가까이 있을 때만 말풍선과 발화자 몸 움직임을 표시한다.
- 상대의 예시 대사 후 참여자의 예시 응답으로 바뀐다. 설명 화면용 예시이며 실제 사용자의 응답을 대신하지 않는다.
- 출근 익명 인물 중 하나만 이동한다. 둘은 같은 자리에 머무르며 보폭이 좁은 프레임을 사용하고, 몸 높이를 2% 변화시키는 작은 대화 동작을 번갈아 재생한다. 새 입 모양/손짓 스프라이트를 생성한 것은 아니다.
- reduced-motion에서는 몸 움직임 없이 말풍선만 표시한다. 동의/오류 차단 시 대화 및 걷기를 멈추고 말풍선을 숨긴다. 숨긴 탭에서는 애니메이션과 기존 안내 시계가 멈춘다.

## 확인

- 실제 CUA 브라우저 CSS 2160×3840: 가로/세로 넘침 없음.
- 출근 6초: 익명 걷기 1명, 익명 대화 2명. 분리된 인물 5명의 계산 너비 모두 190.078px.
- 참여자와 상대가 가까워진 뒤 상대 말풍선 확인. 10초에 발화자가 참여자로 바뀌는 것 확인.
- 말풍선 경계가 장면 내부에 들어오는 것을 확인. 기존 4K 좌우 여백 129.59px가 유지됨.
- `node --test src/features/smart-mirror/lib/*.test.js src/lib/pocApi.test.js`: 24개 통과. 장면별 정지 위치, 거리, 대화 시간, 발화자 전환, 차단 및 reduced-motion 분기를 포함한다.
- `npm run build`: 성공. 기존 500kB 번들 경고 유지.

증거: 작업 공간 `output/mirror-talk/4k-qa.json`, `4k-conversation.png`, `final-preview.jpg`. 실제 TV/유리와 OS reduced-motion 실기기 확인은 미검증이다.
