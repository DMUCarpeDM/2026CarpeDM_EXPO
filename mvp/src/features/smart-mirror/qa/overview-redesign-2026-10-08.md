# 요약 화면 재설계 검토

범위: 요약 화면만. 기존 검정·실버 PNG 3장과 실제 세션 요약 연결을 유지한다.

## 구성 결정
- 공통 제목 대신 현재 시나리오 제목을 상단의 주요 제목으로 사용한다.
- 세 단계 진행을 상단 한 곳으로 통합한다. 완료한 단계는 채운 상태로 유지한다.
- 상황을 먼저 읽고 이미지를 본 뒤 상대의 실제 첫마디와 연습 목표를 읽는다.
- 별도 시간 배지와 총 진행 막대를 없애고 시간·대화 상대를 상황 위에 정렬한다.
- 하단에서 지금은 읽는 단계라는 점과 다음 장면을 명시한다. 마지막에는 대화 시작을 예고한다.
- 이미지와 텍스트의 넓은 슬라이딩을 줄여 읽는 위치를 고정한다.

## 검증
- smart-mirror lib 테스트 6개 통과: 단계 경계, 18초 읽기, 마지막 카운트다운, 진행 역행 방지, 숨김 시간, 동의 카드, 실제 세션 연결/누락 차단.
- Vite 제품 빌드 통과. 기존 큰 번들 경고는 남아 있다.
- 실제 2160×3840 iframe에서 출근·업무·퇴근 모두 문서 overflow 없음, 이미지 로딩 정상.
- 정지 파라미터 없는 화면에서 출근 표시 후 퇴근 단계로 자동 진행하고, 안내 완료 화면으로 넘어가는 것을 확인했다. 업무 단계는 정지 화면과 단계 경계 테스트로 확인했다.
- 오류/미동의 검토 화면에서 운영자 안내가 표시되고 진행 값이 0인 것을 확인했다.
- 스크린샷은 4K iframe을 창에 맞춰 축소한 브라우저 캡처이며 원본 4K 해상도 캡처라고 표시하지 않는다.
- 화면 증거: workspace의 output/mirror-overview-redesign/*-preview.png.

## 남은 현장 확인
유리 패널 뒤 실제 밝기·가독성, 실제 NFC/카메라/마이크를 포함한 전체 대화 시작은 이번 브라우저 검토에 포함되지 않는다.
