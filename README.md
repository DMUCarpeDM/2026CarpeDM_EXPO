# Mirrorting — AI 직장 대화 연습

Mirrorting은 실제 업무 상황을 바탕으로 직장 대화를 연습하고, 응답·목소리·시선·자세의 4-Fit 분석 결과로 다음 연습을 안내하는 프로젝트입니다.

## 저장소 구성

| 경로 | 역할 |
| --- | --- |
| [`poc/`](./poc) | FastAPI 기반의 로컬 분석 PoC와 원래 웹 클라이언트입니다. 세션, 음성·비언어 데이터, 4-Fit 분석, 리포트를 담당합니다. |
| [`mvp/`](./mvp) | 전시용 MVP 프론트엔드입니다. 3단계 설정, 시뮬레이션 준비 확인, 연습·결과 화면을 제공합니다. |
| [`2026_EXPO_CarpeDM_작품개발계획서_최종.hwp`](./2026_EXPO_CarpeDM_작품개발계획서_최종.hwp) | 작품 개발 계획서입니다. |

PoC의 상세 실행 방법과 설계 문서는 [`poc/README.md`](./poc/README.md) 및 [`poc/docs/`](./poc/docs)에 있습니다.

## PoC와 MVP의 역할

| 항목 | PoC | MVP 전시 앱 |
| --- | --- | --- |
| 목표 | AI 분석 파이프라인과 대화 시뮬레이션의 동작을 검증합니다. | 관람객이 짧은 흐름으로 체험할 수 있도록 UX를 제공합니다. |
| 시나리오 | 클라우드밋 입사 첫날의 장애 대응을 연속 역할극으로 진행합니다. | 상대 역할에 따라 상황을 고르고, 상황에 맞는 목표를 선택합니다. |
| 설정 흐름 | 시드 데이터와 세션 FSM을 중심으로 시작합니다. | 기본 설정 → 상황 선택 → 목표 선택의 3단계로 선택 내용을 확인합니다. |
| 분석 파이프라인 | FastAPI가 세션·음성·비언어 지표를 받아 로컬 STT, Ollama/템플릿 대화, 4-Fit 분석과 SQLite 리포트를 처리합니다. | 브라우저가 `/api` 프록시를 통해 PoC API에 세션·발화·오디오·비언어 지표를 전달하고, 결과를 전시용 화면에 표시합니다. |
| 전시 운영 | 분석 엔진 자체를 검증하는 개발·운영 환경입니다. | 한 대의 PC에서 카메라·마이크 권한을 받아 동작하며, 세션 종료 후 오디오와 분석 결과를 보관합니다. 유휴 시간에는 초기 화면으로 돌아갑니다. |

MVP는 분석 엔진을 중복 구현하지 않습니다. `poc/backend`를 로컬 분석 서버로 사용하므로, 전시에서는 PoC 백엔드와 MVP 프론트엔드를 함께 실행합니다.

## MVP 전시 실행

필수 환경은 Python 3.12 권장, Node.js 20 이상, 카메라·마이크입니다. Ollama와 STT 모델을 준비하면 로컬 AI 분석을 사용할 수 있고, 준비되지 않은 경우에도 PoC의 폴백 경로로 화면 흐름을 확인할 수 있습니다.

1. 첫 터미널에서 분석 서버를 준비하고 실행합니다.

   ```bash
   cd poc/backend
   bash scripts/setup_ai.sh
   .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

2. 두 번째 터미널에서 MVP를 실행합니다.

   ```bash
   cd mvp
   npm install
   npm run dev
   ```

3. 브라우저에서 `http://localhost:5173`을 열고 카메라·마이크 권한을 허용합니다.

PoC의 기존 `poc/frontend`는 분석 원형을 확인할 때만 별도로 실행하세요. MVP 전시 중에는 포트 5173 충돌을 피하기 위해 실행하지 않습니다.

## 확인 명령

```bash
cd mvp
npm test
npm run build
```

PoC의 백엔드 테스트는 `poc/backend`에서 `pytest`로 실행할 수 있습니다.
