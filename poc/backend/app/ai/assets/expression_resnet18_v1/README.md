# 표정 모델 연결

`model.pth`는 전달받은 ResNet-18 가중치 원본입니다. `metadata.json`에 파일 크기와 SHA-256, 전달 안내서의 입력·출력 계약을 기록했습니다.

현재 상태는 **MVP 카메라 분석·응답 API·결과 보고서 연결 완료, 정확도 미검증**입니다. 얼굴 추출과 ResNet-18 추론은 브라우저에서 실행하고, 서버에는 구간별 7개 sigmoid 출력의 평균과 표본 수만 전달합니다. 기존 응답·자세 점수 산식은 변경하지 않습니다.

한 명의 얼굴만 보이고 얼굴 영역을 온전히 추출할 수 있을 때 약 1초마다 분석합니다. 얼굴 미검출·다중 얼굴·화면 밖으로 잘린 얼굴은 표본으로 집계하지 않습니다. 이 주기로 깜빡임 횟수나 짧은 표정의 지속 시간을 계산하지 않습니다. 카메라 종료 시 모델 자원을 해제하며, 이전 구간의 지연된 결과가 다음 구간에 섞이지 않게 처리합니다.

## 확인한 내용

- 표준 ResNet-18의 마지막 출력층을 7개로 구성했을 때 모든 가중치가 일치합니다.
- 합성 입력 `[1, 3, 224, 224]`에서 유한한 `[1, 7]` 출력이 나왔습니다. 실제 인식 정확도를 검증한 결과는 아닙니다.
- 안내서의 출력 순서는 미소, 눈썹 찌푸림, 눈썹 올림, 눈 크게 뜸, 눈 감음, 입 크게 벌어짐, 무표정입니다. 가중치 자체에는 라벨 이름이 없으므로 학습 코드와의 일치는 아직 미확인입니다.
- 안내서는 항목별 sigmoid를 사용하는 다중 라벨 분류를 지정합니다. 모델 원시 출력에 softmax를 적용하지 않습니다.

## 판정·점수 활성화 전 확인할 내용

학습 코드의 얼굴 자르기·여백·색상 처리·리사이즈·정규화, 항목별 판정 기준값, 라벨 순서, 미확정 정답(null)의 학습 제외 처리 및 평가 결과를 확인해야 합니다. 현재 전처리는 RGB, 얼굴 경계의 20% 여백을 포함한 정사각형 자르기, 224×224 리사이즈, ImageNet 정규화입니다. 안내서를 근거로 임시 연결한 값이며 실제 학습 전처리와의 일치는 미확인입니다. 항목별 기준값은 null로 유지합니다.

표정 분류를 점수로 변환하는 정책은 포함하지 않습니다. 얼굴 미검출은 무표정으로 처리하지 않으며, 표정 확정 판정을 하지 않으므로 상충하는 출력도 원시 참고값으로 남깁니다. 향후 판정을 활성화할 때 안내서의 충돌·판단 유보 정책을 적용해야 합니다.

## 로컬 실행 준비

원본 가중치와 ONNX 파일은 Git에 포함하지 않습니다. 새 환경에서는 원본을 이 폴더의 `model.pth`로 배치하고, Python 환경에 PyTorch와 ONNX(변환 검증 버전 1.20.1)를 설치한 뒤 저장소 루트에서 실행합니다.

```sh
python poc/backend/scripts/export_expression_model.py poc/backend/app/ai/assets/expression_resnet18_v1/model.pth mvp/public/models/expression_resnet18_v1/model.onnx
cd mvp
npm ci
npm run dev
```

`predev`와 `prebuild`가 설치된 ONNX Runtime 패키지의 WASM을 로컬 공개 자산으로 복사합니다. MediaPipe 얼굴 모델·런타임은 기존 로컬 우선/CDN 대체 정책을 사용합니다. 전시 오프라인 환경에서는 기존 `npm run setup-offline`도 실행해야 합니다. 이 표정 연결은 MVP의 실제 연습 화면에 적용되며, 정적 디자인 미리보기와 구 PoC 화면은 카메라 표정 분석을 실행하지 않습니다.

## 파일 관리

원본 가중치는 외부 공개 범위가 확인되지 않아 Git 추적에서 제외했습니다. 공개 저장소에 자동 포함되지 않습니다. 안내서와 학습용 얼굴 사진은 복사하지 않았습니다.
