# 미러팅(Mirrorting) 하드웨어 기획서

> 팀 CarpeDM · 동양미래EXPO 2026 · AI 직장 커뮤니케이션 코칭 스마트 미러 키오스크
> 4-Fit 평가 설계서와 별개 — 이 문서는 **물리 하드웨어 구성·배치·컴퓨트 사양**을 정의.
> 상태: 대부분 확정, **GPU/컴퓨트 = 보류(PC 사양 확인 후)**.

**신뢰도:** `[높음]` 확정·근거 · `[중간]` 초안·부분근거 · `⚠️` 미확정/실측 필요 · `[보류]` 결정 대기

---

## 0. 시스템 개요

온디바이스 오프라인 키오스크(전시장 네트워크 미신뢰). 사용자가 스마트 미러 앞에서 AI와 롤플레이 대화 → 실시간 4-Fit 피드백 + 사후 리포트 + 퇴근 영수증 출력.

**핵심 구성:** 65" 미러 디스플레이 + Azure Kinect(모션·깊이) + 지향성 마이크 + NFC 사원증 + 열전사 프린터 + 온디바이스 PC(STT·EXAONE·CV 전부 로컬).

---

## 1. 디스플레이 (스마트 미러) `[높음]`

- **65인치 TV**(사비) — 밝기 충분한 모델(하프미러 뒤라 광량 손실 보상).
- **저철분 유리** 뒷면(2nd surface)에 **디스플레이용 하프미러 필름**(투과율 30~50%) 부착.
  - ⚠️ 필름은 **뒷면(2nd surface)** — 앞면은 맨유리로 두어 IR 터치가 유리 표면을 스치게.
  - 저철분 유리 = 반사 손실 최소화(일반 유리는 녹색 틴트).
- **앞면 IR 터치 프레임**(65" 대응) — 맨유리 위 IR 빔이 표면을 스침.
- **UI = 어두운 배경 설계** — 하프미러 특성상 밝은 부분만 비침(어두운 곳은 거울로 보임).

⚠️ **구매 전 실측(A4 샘플):** 필름의 가시광 반사/투과 + (혹시 몰라) IR 특성 2건 벤치 테스트.
※ 유전체(dielectric) TV 미러 유리 = 비용으로 제외 확정.

## 2. 모션·깊이 센서 — Azure Kinect DK `[높음]`

- **보유 중.** 12MP RGB(4096×3072) + 1MP ToF 깊이(1024×1024) + IR flood + 7채널 마이크 어레이 + IMU.
- **용도:** ① 자세(32관절 body tracking) ② 표정 분석용 RGB(공통 RGB 파이프라인) ③ 깊이/IR = 표정 축 보너스(조명 강건·랜드마크 안정).

### ⭐ 배치 = 유리 위(미러 상단) 노출 + 함체 `[높음, 조사 근거]`
- **미러 뒤 숨김 ❌ → 상단 노출, 아래로 살짝 틸트.** 이유: 실제 스마트미러 사례상 하프미러 뒤 Kinect는 **깊이 품질이 열화**되고 필름 종류에 크게 좌우됨(IR 반사율이 가시광보다 낮아 IR 패턴 강도 약화 → 범위·정확도 하락). 자세 축이 깊이에 의존하므로 **노출로 깊이 100% 성능 확보.**
- **함체(엔클로저)로 감싸** 미관 정리 + 케이블·발열 관리.

### ⚠️ Kinect 제약 (운영 반영 필수)
- **예열 40~50분** — 안정 측정까지. 개장 **1시간 전 전원**.
- **직사광 불가**(ToF) — 창측 배치 회피, 부스 실내 조명만.
- **하체 책상/거리 가림** — 상체 정밀 우선, 하체는 전신 잡힐 때만(자주 N/A).
- **정면 배치가 최정확.**

### ⚠️ 단종 이슈 (제품화·확장 시)
- Azure Kinect DK는 **2023.8 생산 종료.** 보유 유닛으로 **EXPO는 문제없음.**
- 스케일·고장 대비 = **Orbbec Femto Bolt**(동일 iToF 센서, Kinect SDK API 호환, 코드 이식 ~0). ⚠️ Femto Bolt는 **마이크 어레이 없음** → 지향성 마이크 별도(이미 계획).

## 3. 카메라 배치 (표정·자세·시선) `[중간]`

- **Kinect RGB 하나로 표정 + 상체 자세 동시 커버.** 별도 웹캠 불필요(미러 키오스크).
- **위치:** 미러 상단 노출 + 아래 틸트 → 얼굴(표정)·상체(자세) 잡힘. 전신(하체)은 사용자가 물러서야 함 → **상체 정밀 우선**(하체 조건부).
- **시선(머리 방향):** 카메라 이동(HW 캘리브레이션) 대신 **사용자 정렬 가이드**("거울 중앙에 얼굴을 맞춰주세요")로 정면 기준 고정 → parallax 우회.
- **홈 웹앱:** 사용자 웹캠 + MediaPipe(2D) — 미러보다 정밀도 낮음(간이), 자세 축 제외(Kinect 없음).

---

## 4. 마이크 `[높음]`

- **결정: 지향성(카디오이드) USB 마이크 별도.** Kinect 7-마이크 어레이는 백업.
- 이유: **코엑스 소음이 음성·STT의 최대 변수** → 음성 축 "생존조건". 지향성 마이크가 소음(SNR) 대응 유리.
- 사용자 입 방향으로 지향, 근접 배치.

⚠️ 실측: 코엑스 소음 환경 SNR + 하프미러/함체가 음향 차단하지 않는 배치.

---

## 5. 조명 `[중간]`

- **확산 LED 정면 조명** — 고른 정면광(얼굴·포즈 인식 품질), 그림자·역광 최소.
- ⚠️ **직사광·강한 IR 성분 조명 회피**(Kinect ToF 방해). 창측 배치 금지.
- 역광 금지(실루엣화 → 얼굴 인식 실패).

## 6. 컴퓨트 / GPU `[보류 — PC 사양 확인 후 확정]`

### ⚠️ 동시 부하 분석 (핵심)
```
대화 세션 중 (실시간, 동시):
  Kinect Body Tracking (~1-2GB) + MediaPipe 얼굴/포즈/손 (~0.5GB)
  + faster-whisper large-v3 (~2.5-3GB) + EXAONE 롤플레이 대화 생성(실시간)
세션 종료 후 (배치):
  EXAONE 저지 채점 + 음성 분석(parselmouth 등)
```
- **핵심 완화책:** 저지(무거운 채점)는 **세션 종료 후**라 대화 중 피크를 안 먹음 → 이 **시간 분리**가 살길. 단 대화 중 EXAONE 액터는 실시간이라 VRAM 점유.
- **VRAM 합산:** Kinect+MediaPipe+Whisper만 ~4-5GB. EXAONE 7.8B(Q4 ~4.5GB) 더하면 **8GB 초과**.

### Kinect Body Tracking 요건 `[높음, 공식]`
- **NVIDIA GTX 1070 이상**(NFOV_UNBINNED 30fps 5명 기준). **1명 추적은 훨씬 가벼움.** Windows는 DirectML로 CNN 추론(CUDA/TensorRT도 지원). **USB 3.0 포트 필수.**

### 옵션 (사양 확정 시 택1)
| 옵션 | 구성 | 장단 |
|---|---|---|
| **A** | 보유 8GB(4060급) + **EXAONE 2.4B** + Whisper 조정 | 됨, 대화 품질 약간↓. 비용 0 |
| **B** | **RTX 3060 12GB**(중고 ~30만원대) | 4070보다 싸고 VRAM 12GB → 7.8B 가능. 속도는 느림 |
| **C** | 부하 시간 분리 최적화 + 8GB | 저지를 종료 후로 철저 분리해 8GB 버팀. 실측 의존 |
| ~~4070 12GB~~ | ~~신품 100만원+~~ | 예산 버거워 보류 |

### ⚠️ 사양 확인 체크리스트 (알려주면 A/B/C 확정)
```
1. GPU 모델 + VRAM  ← 제일 중요
2. RAM 용량 (EXAONE + Whisper 동시 로드)
3. USB 3.0 포트 유무 (Kinect 필수)
```
※ faster-whisper를 large-v3 대신 medium으로 낮추는 것도 VRAM 절약 카드(한국어 정확도 trade).

## 7. 입출력 `[높음]`

- **NFC 리더(USB)** — 사원증 발급/인식. 태그엔 시리얼 UID만, 이름·직무는 서버 조회. 배정 테이블로 재사용.
- **80mm 열전사 프린터(ESC/POS)** — 퇴근 영수증(온디맨드, 관람객 소유·미저장). `python-escpos` + PIL 연동.

## 8. 함체 / 운영 `[중간]`

- **함체(엔클로저):** 65" TV+유리+Kinect(상단)+마이크+프린터+NFC+PC 통합, 케이블 은닉, 발열 환기구.
- **4일 연속 운영:** GPU 발열 관리(환기), Kinect 상시 전원 + 예열 유지, 크래시 시 **자동 재시작 스크립트**.
- **개장 1시간 전 전원**(Kinect 예열).
- 배선: USB 3.0(Kinect) + 마이크 + 프린터 + NFC + 디스플레이 + 전원.

---

## 9. IR 통합 주의 `[중간]`

- Kinect **노출 설치**라 필름 IR 투과 문제 **회피됨**(미러 뒤 아님).
- **IR 터치 프레임 ↔ Kinect IR:** 터치 IR(유리 표면 스침) vs Kinect IR(장면 투사)은 기하가 달라 간섭 적을 것으로 예상. ⚠️ **다중 IR 소스는 간섭 가능** → 실측 필요.

---

## 10. ⚠️ 반드시 실물 실측 (프로토타입)

1. **대화 중 4개 동시 GPU VRAM/FPS** ← 최우선(사양 확정과 직결)
2. 하프미러 필름 가시광 반사/투과(A4 샘플)
3. IR 터치 ↔ Kinect IR 간섭
4. 미러 앞 사용자 거리에서 얼굴·상체 화각
5. 지향성 마이크 코엑스 소음 SNR

---

## 11. 8월(선정심사) vs 10월(본전시) HW 단계

- **8월 — 시연영상 권장, 실물 키오스크 불필요** `[높음]`
  - Kinect+웹 데모를 **책상 세팅**으로 촬영. 미러는 목업/렌더/영상.
  - 핵심 = "4-Fit 작동" 시연영상 + 발표PDF. 완전한 키오스크 없어도 됨.
- **10월 — 실물 키오스크 조립**
  - 65" TV + 필름 + IR 터치 + Kinect(상단 노출+함체) + 지향성 마이크 + 조명 + NFC + 프린터 + PC.
