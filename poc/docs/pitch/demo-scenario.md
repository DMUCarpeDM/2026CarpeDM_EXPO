# 시연 영상 촬영 큐시트 — 선정심사(8/4)용 90초 편집본

> **라이브 시연은 없다.** 심사장 기자재에 기기 연결이 금지되어 시연은 이 영상과
> 정지 캡처로만 전달된다. 영상이 곧 완성 가능성 20점의 증거물이다.
> **촬영 마감 7/29(수)** — 편집·캡처 추출·슬라이드 삽입까지 역산한 마지노선.
> 역할: **체험자**(미러 앞, 촬영 대상) / **촬영·조작자**(카메라 + 비상 대응)
> 촬영 전 점검은 `docs/demo-checklist.md` 15분 루틴을 그대로 따른다.

## 산출물 4종

| # | 산출물 | 용도 | 사양 |
|---|---|---|---|
| 1 | **90초 편집본** | 발표 슬라이드 3에서 재생 | mp4(H.264) — 허용 포맷·용량 제한 미공지, `submission-checklist.md`에서 확인 |
| 2 | **정지 캡처 4컷** | 슬라이드 3에 직접 삽입 — **영상이 전부 실패해도 시연이 전달되는 최후 안전장치** | 아래 지정 컷 |
| 3 | (선택) 풀버전 3분 | Q&A에서 "더 보여달라" 대응 + 부스 대기화면 재활용 | 무편집 완주본 |
| 4 | 원본 소스 전체 보관 | 10월 부스 장애 백업, 작품집·홍보 재활용 | — |

### 정지 캡처 4컷 지정

1. **웨이크** — 잠든 거울(검정 + "다가와 보세요") 옆에 글로우 점등 순간 (before/after 나란히도 가능)
2. **역할극** — 체험자가 답변 중, 인식 자막이 실시간 표시되는 화면
3. **리액션** — 팀장 리액션 자막이 뜬 순간 ("좋아요. 그렇게 정리해서 말하면 돼요.")
4. **리포트** — 미러 시상식(총점 링) + 폰 상세 첨삭(무의식 습관 카드) 2분할

## 촬영 앵글 — 두 소스를 반드시 병행

| 소스 | 잡는 것 | 이유 |
|---|---|---|
| **외부 카메라** (삼각대, 미러 측면 45°) | 사람 + 거울 반사 + 화면이 한 프레임에 | 거울 체험은 화면 녹화만으로는 전달되지 않는다 — "반사 위에 UI가 뜬다"가 이 작품의 핵심 장면 |
| **화면 녹화** (세로 1080×1920) | UI 디테일·자막·리포트 | 캡처 4컷의 소스. 외부 캠과 타임코드 맞춰 교차 편집 |

## 초 단위 촬영 큐 (편집 기준 90초)

| 편집 시각 | 장면 | 체험자 행동 | 화면에서 일어나는 일 |
|---|---|---|---|
| 0:00~0:08 | 웨이크 | 두 걸음 밖에서 다가선다 | 잠든 거울 → 글로우 점등 + 인사 TTS |
| 0:08~0:18 | 온보딩 | 5분 카드 탭 → 동의 탭 → 출근 탭 | 3탭 온보딩 (자막: "출근까지 세 번") |
| 0:18~0:28 | 브리핑 | 화면 응시 (캘리브레이션) | 09:04 장면 자막 + 얼굴 링 |
| 0:28~0:40 | 팀장 질문 | 듣는 동안 **또렷하게 2~3회 끄덕임** | 팀장 TTS + 자막 |
| 0:40~0:55 | 답변 | 마이크 탭 → **준비된 답변**(아래) → 전달 | 인식 자막 실시간 표시 |
| 0:55~1:05 | 리액션 | 침묵하며 기다린다 | 리액션 TTS → 심화 질문 |
| 1:05~1:15 | 심화 답변 | 한 문장 답 → 전달 | 리액션 → 장면 전환 |
| 1:15~1:30 | 리포트 | QR 스캔 동작 | 시상식 요약 → 폰 상세 첨삭 |

### 준비된 답변 (외울 것 — excellent 리액션 보장)

> "안녕하십니까, 오늘 합류한 신입 개발자 ○○○입니다. 플랫폼팀에서 백엔드 운영
> 지원을 맡게 됐고, 오늘은 온보딩 문서 파악과 장애 대응 참관을 퇴근 전까지
> 마치는 게 목표입니다. 모르는 건 바로 여쭤보면서 배우겠습니다."

- 이름·역할·목표·협업 4요소를 모두 커버 → "좋아요. 그렇게 정리해서 말하면
  돼요" 계열 리액션 + 심화 질문이 이어진다.
- 심화 질문 2종의 한 문장 답도 외운다:
  · "지금 당장 할 수 있는 일?" → "네, 온보딩 문서에서 장애 대응 채널부터
    확인하고 알람 정리를 돕겠습니다."
  · "막히면 누구한테?" → "박서연 선임님께 먼저 여쭤보고, 정리해서 팀장님께
    보고드리겠습니다."
- 듣는 동안의 끄덕임은 리포트에 경청 카드를 띄운다 — "듣는 자세까지 본다"의
  실물 증거이므로 반드시 수행.
- 문장을 끝낸 뒤 1초 쉼은 감점이 아니라 완급 관용 — 여유 있게.

## 편집 원칙 (기술성 20점 직결)

| 원칙 | 이유 |
|---|---|
| 오류 메시지·버벅임·재시도 장면은 **잘라낸다** | "원활하고 자연스럽게 구동되는가"가 평가 문항이다 |
| 느린 구간은 잘라도 **배속은 금지** | 응답 시간 왜곡은 Q&A에서 잡힌다 — 실제 지연을 물으면 실측치로 정직하게 답한다 |
| 단계마다 짧은 자막 (웨이크→역할극→리포트) | 심사위원 다수가 비전공자 — 영상이 스스로 설명해야 한다 |
| 소리 포함 (TTS·체험자 음성) | 음성 대화가 핵심인데 무음 영상이면 전달 반감. 단, 심사장 재생 환경 미확인 — 자막 병기 필수 |

## 촬영 완료 체크 (테이크 확정 전)

- [ ] 준비된 답변으로 excellent 리액션이 실제로 나왔는가
- [ ] 외부 캠 프레임에 반사 + UI가 동시에 보이는가 (미러 없이 모니터 촬영이면, 최소한 화면 중앙이 비는 레이아웃 의도가 보이는가)
- [ ] 인식 자막이 오타 없이 찍혔는가 (STT 오인식 테이크는 재촬영)
- [ ] 끄덕임→경청 카드가 리포트에 떴는가
- [ ] 캡처 4컷이 모두 확보 가능한 테이크인가
- [ ] 90초 편집본 기준 각 장면이 위 표 시각에 들어오는가

## 심사 당일 재생 리스크 대응 (발표자 숙지)

1. **1차**: 심사장 PC에서 별도 제출한 영상 파일 재생
2. **2차**: PDF 내 링크 (네트워크·뷰어 의존 — 신뢰하지 않는다)
3. **3차**: 슬라이드의 정지 캡처 4컷으로 같은 내레이션 진행 — **사과는 하지 않는다.**
   "화면의 네 장면이 실제 체험 순서입니다"로 바로 이어간다
