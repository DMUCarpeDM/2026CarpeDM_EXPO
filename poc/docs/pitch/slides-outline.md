# 슬라이드 골격 — 12장 (중간심사용)

> 규칙: 장당 헤드라인 한 문장 + 시각 자료 하나. 본문 텍스트는 넣지 않는다 —
> 읽게 만드는 슬라이드는 발표자를 지운다. 다크 배경(#000) + 앱과 같은 액센트.

| # | 헤드라인 (슬라이드에 이 문장만) | 시각 자료 (구체적 지정) |
|---|---|---|
| 1 | **들여다보면, 회사가 시작되는 거울** | 제품 로고 + 미러 대기 화면 실사(잠든 거울, 검정에 "다가와 보세요" 한 줄) |
| 2 | 면접은 준비해도, 첫 출근은 아무도 연습 못 한다 | 취준생→입사 첫날 갭을 보여주는 단순 다이어그램 (면접 준비 ✓ / 첫 보고 ?) |
| 3 | 거울이 당신을 알아보고, 하루가 시작된다 | 웨이크 순간 연속 사진 3컷 (잠듦→글로우 점등→출근 CTA) |
| 4 | 월요일 09:04 — 장애가 터진 날의 신입 개발자 | 브리핑 화면 스크린샷 (09:04 장면 자막 + 연습 포인트 칩) |
| 5 | **상대가 내 말에 반응한다** | 면담 화면 스크린샷 + 리액션 자막 강조 ("좋아요. 그렇게 정리해서 말하면 돼요.") |
| 6 | 대답에 따라, 하루의 결말이 달라진다 | 분기 다이어그램: 같은 하루 → 결말 3종 (인정/격려/아쉬움) — 실제 결말 대사 인용 |
| 7 | 거울 뒤에서 AI 일곱이 일한다 | 7모듈 아키텍처 다이어그램 (시선·자세·표정·형태소·DSP·로컬LLM·오프라인STT → 4-Fit) |
| 8 | **API 키 0개 · 사용료 0원 · 영상 전송 0바이트** | 데이터 흐름도: 영상은 브라우저 안에서 끝나고 숫자만 서버로 (차단선 강조) |
| 9 | "손이 얼굴에 4초 머물렀어요" — 여기까지 봐주는 코치 | 리포트 화면 2분할: 미러 시상식(총점 링) + 폰 상세 첨삭(무의식 습관 카드) |
| 10 | 미러에서 체험하고, 폰으로 가져간다 | QR 마무리 화면 스크린샷 + 폰 목업 (체험 코드 = 익명 성장 추이) |
| 11 | 오늘 이미 동작한다 — 남은 건 몸을 만드는 일 | 좌: 테스트 255개(251 통과)·전 구간 시연 캡처 / 우: 하프미러 리그 도면 + 발주 타임라인 바 |
| 12 | **거울 앞에 서는 순간, 당신의 첫 출근이 시작됩니다** | 부스 렌더링(사람이 미러 앞에 선 실루엣) + 팀 CarpeDM 크레딧 |

## 심사 기준 커버 맵

- 작품성: 1, 4, 5, 9 (경험의 완성도)
- 기술성: 7, 8 (스택 깊이 + 프라이버시 설계)
- 창의성: 3, 6 (거울 문법 + 분기 서사)
- 발표력: 헤드라인-온리 슬라이드 구조 자체 + 라이브 시연
- 완성 가능성: 11 (동작 증거 + 남은 일의 구체성)

## 제작 메모

- 스크린샷은 전부 세로 1080×1920 실물 캡처 사용 (목업 아님을 은근히 드러낼 것)
- 5·6장이 심사위원 기억에 남는 두 장 — 리액션 대사와 결말 3종은 실제 시드 문장 그대로
- 11장 타임라인은 docs/hardware-plan.md §6과 일치시킬 것 (발표-문서 불일치는 감점 요인)
