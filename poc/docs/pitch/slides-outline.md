## PDF 제작 절대 규칙

- **애니메이션·화면 전환 전면 금지.** 순차 등장용으로 겹쳐 놓은 개체는 PDF에서 전부 겹쳐 보인다. 순차 설명이 필요하면 슬라이드를 분리한다.
- **모든 슬라이드는 정지 상태에서 그 자체로 읽혀야 한다.** 발표자가 없어도 읽히는가로 검사.
- 폰트 임베딩 필수 (또는 시스템 기본 폰트만 사용). 본문 최소 20pt.
- 다크 배경(#000)은 유지하되, 옅은 회색 텍스트 금지 — 심사장 프로젝터 밝기에서 대비 확인.
- 화면 비율(16:9/4:3) **미확인** — 확인 전까지 16:9로 제작하되 상하좌우 안전 여백 확보. → `submission-checklist.md`
- 영상은 3중 안전장치: ① 영상 파일 별도 제출 ② PDF 내 링크 ③ **핵심 장면 정지 캡처 3~4컷을 슬라이드에 직접 삽입.** 캡처가 없으면 재생 실패 시 완성 가능성 20점의 근거가 통째로 사라진다.
