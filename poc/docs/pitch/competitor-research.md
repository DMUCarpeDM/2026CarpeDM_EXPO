> 발표력이 동시에 무너지고, 조사가 되어 있으면 "합격 다음 날" 포지셔닝이 최강의
> 우군이 된다 (가상심사위원 리포트 기준 단일 최대 변동성 항목).

"저희만 생각했다"고 말하면 안 되는 이유. **차이점**: 전부 기업·기관이 구매하는
B2B이고, VR 장비·구독·관리자를 전제한다.

## 3. 좌표 — 우리가 서 있는 빈 칸

```
                 채용 전형(면접) 대비          입사 후 적응·훈련
              ┌───────────────────────┬───────────────────────┐
 개인이 바로   │ 뷰인터, 사람인 AI 모의면접,  │                        │
 쓰는 형태     │ JOBDA 연습, 에듀스        │      ← 비어 있음        │
              ├───────────────────────┼───────────────────────┤
 기관·몰입형   │ (AI역량검사 실전)          │ Yoodli, Mursion,        │
 설치·구독     │                        │ Bodyswaps, Virti (B2B·VR)│
              └───────────────────────┴───────────────────────┘
```

**4-Fit 미러팅의 자리**: 오른쪽 위+아래에 걸친 빈 칸 — **취준생·신입이 장비 없이
걸어와 서기만 하면 되는, 입사 첫날 역할극 + 비언어 코칭 키오스크.** 완전 로컬이라
기관(대학 취업지원 부서) 상설 설치에도 구독·API 비용이 없다.

## 4. 발표용 좌표 문장 3줄 (슬라이드 6 / 대본 (4))

1. "면접을 연습시켜주는 서비스는 많습니다 — 뷰인터, 사람인 AI 모의면접, JOBDA."
2. "전부 훌륭하지만 **합격에서 멈춥니다.** 합격 다음 날 아침은 비어 있습니다."
3. "해외의 직장 롤플레이 훈련(Yoodli·Mursion·Bodyswaps)은 VR 장비와 구독이 필요한
   기업용 B2B입니다 — **걸어와 서기만 하면 되는 거울은 없습니다.**"

## 5. Q&A 방어 시나리오

**"뷰인터도 표정·음성 분석하는데 뭐가 다릅니까?"**
> 분석 기술의 축은 같습니다 — 다른 것은 분석의 **대상과 목적**입니다. 뷰인터는
> 면접 합격을 위한 인상 분석이고, 저희는 입사 후 첫 보고·면담이라는 **업무 대화**
> 안에서, 반응하는 상대와의 역할극 중에 측정합니다. 측정이 목적이 아니라 연습의
> 부산물이라는 구조가 다릅니다.

**"Mursion 같은 게 이미 있지 않습니까?"**
> 예, 저희도 조사했습니다. Mursion은 시뮬레이션 스페셜리스트가 개입하는 기업용
> 고가 B2B입니다. 저희는 그 경험의 핵심(반응하는 상대와의 역할극)을 사람 개입
> 없이, API 비용 없이, 장비 없이 — 걸어와 서면 되는 키오스크로 만들었습니다.
> 그래서 대학 취업지원 부서가 상설 운영할 수 있는 단위 비용이 나옵니다.

**"그 서비스들 직접 써보셨습니까?"** ← 이 질문이 나오면 조사만으로는 못 버틴다
