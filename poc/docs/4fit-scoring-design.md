## 0. 확정된 토대

- **4-Fit 축 = 응답(Response) · 음성(Voice) · 표정(Expression) · 자세(Posture)** `[높음]`
  - 3번째 축 = 명세서 원본 시선(Eye) → 표정(Expression) 교체 확정. ⚠️ 명세서·리포트·대시보드의 "Eye-Fit" 일괄 수정.
- **시선(Gaze) = 점수 아님, 보조 신호** — 집중 게이팅·실시간 UI·이탈 넛지. 머리 방향 큰 이탈만.
- **채점 = LLM-as-judge(응답) + CV·음향 신호처리(음성·표정·자세).** 검증 전 "참고용" 표기.
  - **⚠️ 검증 = 우연 보정 지표(Krippendorff α / ICC), 절대 임계가 아니라 "사람–사람 일치 상한 대비"로 보고.** judge가 사람 상한 근접이면 충분. **멈춤 조건: 사람–사람 κ<0.6이면 과제 모호 → judge가 아니라 루브릭 수정.** 단순 일치율 금지(kappa deflation).
- **액터 ↔ 저지 분리**(자기선호 편향 차단).
- **판정 모델:** 8월 프롬프팅 EXAONE → 10월 파인튜닝(온디바이스). 상세 §8.
- **STT:** faster-whisper large-v3 + initial_prompt + VAD + 지향성 마이크. 상세 §7.
- **음성 툴킷:** parselmouth(Praat) + openSMILE eGeMAPS + librosa. 상세 §4.
- **표정 툴킷:** MediaPipe blendshape → (검증 매핑) AU. 상세 §5.
- **자세 툴킷:** Kinect Body Tracking(미러 3D) + MediaPipe Pose/Hands(홈 2D) + One-Euro filter. 상세 §6.
- **⚠️ 하드웨어 치명 이슈(자세·표정 공통):** **Azure Kinect DK는 2023.8 생산 종료(단종).** 이미 소유한 유닛으로 EXPO는 진행 가능. 단 스케일·제품화·고장 대비엔 **Orbbec Femto Bolt**(동일 iToF 센서, Kinect SDK API 호환 → 코드 이식 ~0). ⚠️ Femto Bolt는 7-마이크 어레이 없음 → 음성 축은 별도 지향성 마이크(이미 계획). Kinect 공통 제약: 예열 40~50분·직사광 불가(실내 전용)·정면 배치 최정확·하체 책상 가림.
- **콘텐츠 4계층:** 세계관→직무→상황(Scenario)→에피소드→채점기준(rubric_item은 scenario 종속). 프롬프트 버전 관리.
  - **⚠️ scenario 2필드:** `formality_target`, `directness_stance`. 상세 §3.

## 1. 채점 메커니즘 (공통) `[높음]`

- **채점 단위 = 에피소드** (5분=2개 / 10분=4개). ✅ 재검증 지지(MultiChallenge). ⚠️ 경계는 명시 규칙으로 고정 + 에피소드 간 일관성도 별도 신호 가능.
- **척도 = 혼합:** 상황 체크리스트=이진(1/0), 범용/비언어 신호=3점(관측조건 명시). 최종 0~100은 코드 합산. LLM에 "몇 점" 직접 금지.
- **시점 = 세션 종료 후 일괄 배치**(전시 안정성). 홈은 에피소드별 즉시 가능.
- **실시간 vs 사후 + 게이지:** 실시간 = 음성·표정·자세 3축 게이지 + 시선 넛지. **응답 게이지 = "맥락 분석 대기"로 의도적 비움** → 종료 후 정밀 점수로 채움. ⚠️ 비언어 실시간도 baseline 없어 "예측" → 사후가 진짜 점수.

```
대화 → (실시간: 음성·표정·자세 게이지 + 시선 넛지 / 응답=분석 대기)
종료 → 로딩 → 응답: 저지가 전사, 에피소드별 이진+3점, n회 반복 → 코드 결합
            → 음성/표정/자세: 품질·부위 게이팅 → 개인·기기 정규화 → 표준 지표
     → 0~100 + 에피소드별 + 종합 리포트
```

## 2. 응답(Response-Fit) — 확정본 `[높음, 재검증 지지]`

### 구조: 2층 하이브리드 + 가중치 30:70 + 범용 게이트
`[범용층 30]` 커뮤니케이션 뼈대 / `[상황층 70]` 시나리오별 체크리스트. 범용층은 **곱하기 게이트**(범용 적절성 미흡 시 상황 점수도 감점).
- ✅ **이진 체크리스트 분해 = 최신 표준.** CheckEval(EMNLP 2025): 모델 간 일치 +0.45, 사람 상관 +0.10. **MultiChallenge: 루브릭 유무가 다중턴 일치를 36%→93%로 가름.**

### ① 구인
> "긴장 상황에서 요점을 논리적으로·상황에 맞게 전달하는 능력". `[중간]`

### ② 신호
**범용층 4신호:** 명확성 · 구조 · **적절성**(상황·상대 적합 + 격식·완곡성(§3) + 책임회피 없나) · **공감표현**(인정·반영 발화, 정서 추론 ❌, 상황별 가중치).
- **필러 경계:** "음/어"·말더듬 = 음성 축 전담.

**상황층 체크리스트** `[높음]`: 장애대응(결론·근거·액션·ETA) / 실수보고(사실·영향·조치·재발방지).

### ③ 피처
판정↔산술 분리 · temperature 고정 + n회 반복(3~5) · **position swap(뒤집힘 10%↑면 기준 재작성)** · **길이 통제** · CoT(근거 먼저→판정, 원문 인용) · JSON 출력 · 범용층도 LLM 판정(구체 문장 앵커) · bge-m3 보조. (10월) **reference-guided grading**(시나리오별 golden 응답 대비).

### ④ 앵커 (게임화 방지)
체크리스트=하한, 통합적 질=상한. 장황함 통제(길이 무관, 짧고 정확 우대).
- 직접우선 우수: "결론부터, 로그인 5xx 18%↑, 롤백 진행하겠습니다"
- 완곡우선 우수: "도와드리고 싶은데 A건 마감이 걸려 오후엔 어려울 것 같아요. 내일 오전은요?"

### ⑤ 검증
사람 3인 라벨 vs judge → Krippendorff α, **사람–사람 상한 대비.** golden set: 균형 이진이면 50 traces면 κ 95% CI ±0.10~0.15, 희귀 클래스 200+. α 미달 시 "참고용".
- 현실 상한: 커뮤니케이션 자동 채점 **r≈0.70~0.75**(MIT Interview). ⚠️ 상업 벤더 "0.95+"는 마케팅.

## 3. 한국어 특화 (응답 적절성) `[중간~높음 · 차별화 핵심]`

**적절성 = f(격식 레벨, 직접성 스탠스)** — scenario가 두 값 제공.
- **격식:** 종결어미 — 합쇼체(-습니다, 상사)/해요체(-해요, 동료·가장 흔함)/반말(상사엔❌). ✅ 조작화 정합(연구가 합쇼체를 격식 KPI로). 종결어미=규칙, 미묘함=LLM.
- **직접성↔완곡성(역설):** 같은 특징이 상황따라 가점↔감점. "조금 어려울 것 같습니다" → 보고=회피(감점)/거절=정중(가점).
- **하위:** 호칭·쿠션어. **보류:** 정서·감정노동(내면 추론 ❌).
- **⚠️ 한국어 judge 실패(KUDGE):** 사실 오류·문화 오표현·비한국어 혼입 못 잡음 → **언어 일관성 페널티(HRET) + 문화·격식 오류 체크 명시.** 영어 평가력이 한국어 judge 성능 잘 예측.
- **DB:** scenario에 `formality_target`, `directness_stance`.

## 4. 음성(Voice-Fit) — 확정본 `[높음, 재검증 반영]`

### ⭐ 프레이밍
"자신감 점수" ❌ → **"전달 안정성·활기 관련 해석 가능한 음향 지표".** "자신감"은 근거 있는 항목만 조건부.
- 근거: 감정 직접 분류 일반화 실패 + valence 약함(arousal 79.7 vs valence 66.4 UAR). **프로소디가 어휘보다 무겁게 가중(Jiang&Pell 2017) → 응답과 독립 정보.**

### ① 구인
> "내용과 무관하게, 안정적이고 명료하며 활기 있게 전달하는 능력". ❌ "자신감 있는 사람인가". `[중간]`

### ② 신호 (⚠️ 방향 정정)
**방향 견고(지각 연구 지지):** 성량 안정·충분성(상대 intensity, 클수록) · 발화 속도(**음절/초**, 적정·일관, 불확실=느림) · 휴지 적절성(불확실=잦은 휴지) · 문미 억양(하강 vs 상승 — ⚠️ 한국어 상승 다기능, 문장유형·응답 연동).
**유창성 3분(Tavakoli&Skehan):** speed(조음속도)·breakdown(휴지 빈도·위치, >250ms)·repair(반복·자기수정). **필러는 하위.** 8월 speed+breakdown, 10월 repair.
**⚠️ 방향 불안정 — 해석 신호로만, 점수화 금지:** f0 범위/변동성(2017 vs 2015/2016 상반+성별 상호작용) · 평균 f0 수준(방향 robust하나 "목소리 낮춰라" 부적절+개인차 → 참고만).
**❌ jitter/shimmer 제외(강하게 지지):** Jiang&Pell(2017) 1차 데이터에서 불확실 발화가 오히려 HNR 높고 jitter 낮음. Feng&Jiang(2024) 재확인. 쓴다면 지속모음 "음질 참고용", CPP 우선.

### ③ 피처 (표준 툴킷 + 정규화)
- **추출:** parselmouth(Praat) = F0·intensity·휴지·HNR/CPP · **de Jong(2021) Praat 스크립트 = 유창성 표준** / openSMILE eGeMAPS = 표준 피처 병행 / librosa = 전처리·게이팅.
- **화자별 z-score 정규화**(피치 세미톤). baseline = 저긴장 구간. ⚠️ 한국어 조음속도 화자차 큼 → 절대 임계 금지, 화자 내 상대치.
- ⚠️ 도구 섞지 말 것(jitter ρ≈0.30). 한 도구 내 일관, 버전·파라미터 명시.
- **✅ openSMILE:** 당분간 사용(비상업 무료). **채점 제품은 parselmouth+librosa 기반**(소수 지표 완전 대체, eGeMAPS 88만 어려움), openSMILE는 연구 보조 → 상업화 자유. `extract_voice_features()` 어댑터. ⚠️ 도구 교체 시 α 재검증.
- (10월 보조) SSL 임베딩(wav2vec2/HuBERT 8~12층, 화자 정규화 층 융합) — 품질 점검·교차검증·예측 상한 참조용, 최종 점수 아님.

### ④ 앵커
우수: 충분·안정 성량 + 적정·일관 속도 + 의미단위 휴지 + 유창 / 미흡: 작거나 급변 성량 + 느리고 잦은 휴지 + 잦은 필러·자기수정. ⚠️ 피치 변동성 방향 단정 제거 · 문장끝 상승 무조건 감점 ❌.

### ⑤ 검증 + 게이팅
(a) 품질 게이팅(SNR·클리핑→재녹음) → (b) 화자 정규화 → (c) 소수 지표 → (d) 사람 α/ICC(**사람 상한 대비**). ⚠️ 한국어 규범 없음 → 자체 분위수/화자 상대값. 신호별 ICC<0.6이면 채점서 빼고 정보용.
**강함 = 표준 피처셋 + 물리→지각 α 검증 + "측정 불가" 인정 + 화자 정규화 + 유창성 3분.** 참고: GeMAPS(2016)·Jiang&Pell(2017)·Feng&Jiang(2024)·Tavakoli&Skehan/de Jong(2021). ⚠️ 인용 확인.

## 5. 표정(Expression-Fit) — 확정본 `[높음, 조사 근거]`

### ⭐ 프레이밍
"감정 상태" ❌ → **"상황에 맞는 표정 표현성·반응성의 물리 지표".** AU/행동 동역학 층에서 멈춤.
- 근거: Barrett(2019) — 얼굴 움직임은 감정 상태 보편 진단 못함. 서구-동아시아 차이.
- **⚠️ 가중치 = 4축 중 최저.** 표정↔역량 연결 최약 + 문화·성격차 큼(무표정≠무능). "부적절만 감점, 적정 범위 넓게".

### ① 구인
> "표정이 상황에 맞게 살아있고 반응하는가"(경직↔생동, 표정-발화 동기화). ❌ "무슨 감정인가". `[중간]`

### ② 신호 (감정 분류 ❌)
표정 표현성/변화량 · 표정-발화 동기화 · 미소 존재/타이밍(AU6+12, 남녀 편향 없음) · 경직/무표정("표정 변화 적음"으로만). **❌ 감정 분류 절대 금지**(Barrett). OpenFace 3.0·py-feat 감정 모듈 사용 금지(명시 규칙).

### ③ 피처 (⭐ blendshape→AU 검증 매핑)
- **주력 = MediaPipe blendshape → AU 변환**(2026 전문가 검증 매핑, 임상 10인 88% 만장/98% 다수). blendshape(웹캠·상업무료 Apache 2.0)+AU(해석 가능).
- **연구 보조 = py-feat / OpenFace 2.0**(AU 표준, ⚠️ 학술 전용). 감정 모듈 미사용.
- **개인별 중립(rest) baseline 정규화**(초반 저긴장 구간) + **시간적 동역학**(정적 프레임 금지). ⚠️ 랜드마크 신뢰도 게이팅.

### ④ 앵커
우수: 상황에 맞는 자연스러운 표정 반응 + 적절 미소 타이밍 / 미흡: 얼어붙음 or 부적절·과장. ⚠️ **무표정≠무능** → "표정 양"이 아니라 "상황 반응성", 적정 범위 넓게.

### ⑤ 검증 + 프라이버시
α + **한국 표정 데이터(EADFES 등) 대조** + **기기별 개별 α.** **⚠️ 얼굴=민감정보:** 온디바이스·원본 즉시 파기·특징치만. 동의 문구 명시.

### ⭐ Kinect vs 웹캠 (공통 RGB 파이프라인)
Kinect RGB(12MP)·웹캠 RGB → 둘 다 MediaPipe → 공통 특징. Kinect 깊이·IR=보너스(조명 강건·랜드마크 안정), 채점은 공통 RGB만. 기기별 품질 게이팅(웹캠 미달 "측정 불가", 미러 IR로 완화) + 기기별 baseline.
- ⚠️ 전시 체크: Kinect 직사광 불가·예열 40~50분(§0).

**강함 = blendshape→AU 검증매핑 인용 + 동역학만 + 공통 RGB + 인구통계 공정성(성별·연령+한국 데이터) + α.** 화려하게 앞세우면 붕괴 → "한계 알고 신중"이 성숙함.

## 6. 자세(Posture-Fit) — 확정본 `[높음, 조사 근거]`

### ⭐ 프레이밍
"자신감 있는 자세" 심리 판정 ❌ → **"안정적이고 상대를 향한 열린 신체 태도의 물리 지표".** 부적절·불안 신호만 감점, 좋은 자세 미화 X. **⚠️ 가중치 = 4축 중 최저(표정과 동급 또는 이하).**
- 근거: 자동 면접/발표 평가에서 **신체 시각 단서는 음성·언어보다 예측력 일관되게 약함**(Nguyen et al. 2014: 지원자 시각 특징 회귀 R² 음수 vs 음성 R²=0.317; 수동 코딩 expressiveness는 오히려 부적 상관 r≈-0.38). → 최저 가중치는 데이터가 지시.
- **⚠️ 파워 포즈 인과 금지** — Carney·Cuddy·Yap(2010) → Ranehill(2015, N=200) 재현 실패(자기보고 파워感만 유의, 호르몬·행동 무효), 원저자 Carney 입장 철회("파워 포즈 효과가 실재한다고 믿지 않는다"). **자세→심리/호르몬 인과는 논문에서 언급조차 금지.**

### ① 구인
> "안정적이고 상대를 향한 열린 신체 태도인가"(경직·위축·안절부절 없이). ❌ "자신감 있는 성격인가". `[중간]`

### ② 신호 (부적절 감지 원칙, 범위 축소)
**✅ 상체 (8월 핵심 3지표):**
- sway(과도한 상체 흔들림) · 몸통 정면 정렬(상대 지향) · **손-얼굴 자기접촉 빈도(self-adaptor)**
**🔶 손 (경직·불안만):** 자기접촉(안절부절) · 제스처 완전 부재(주머니·뒷짐 내내=경직). **❌ 제스처 "적정량/질" 채점 금지(정답 없음·문화 의존), ❌ 손가락 수준 금지.** 손-발화 동기화 = 10월 스트레치, 미확보 시 드롭. **경직만 약한 감점, 자연스러운 활용은 중립(가점 아님).**
**❌ 하체(짝다리·다리 꼬기):** 문화 의존+정답 부재+추적 신뢰도(책상 가림)로 방어 최약. **미러 전신 잡힐 때만 관측, 대부분 N/A 예상 → 8월 점수 반영 신중(게이지 위주), 10월도 신중.**
- 근거: self-touch↔불안 확립(Pang 2022 R²≈0.16, Mohiyeddini 2013 r≈0.33)이나 **효과크기 중간** → 개인 단정 X, baseline 대비 상대 신호만. sway는 **비단조**(불안=증가 vs freezing=감소) → baseline 대비 극단 이탈만.

### ③ 피처 + 신호처리
- 미러: Kinect(3D) 상체 관절 / 홈: MediaPipe Pose(2D). **손가락 수준 전면 금지**(self-occlusion, 손목/손끝 레벨만).
- **⚠️ One-Euro filter 필수**(Casiez CHI'12) — 관절 jitter 제거 안 하면 추적 노이즈를 "흔들림"으로 오판.
- **신체 크기 정규화**(어깨너비 등) + 개인 baseline. sway = 무게중심 변위·경로 길이.
- ⚠️ 2D는 깊이 모호 → **웹캠은 앞뒤 기울기·몸통 회전 금지**, 정면 개방각·좌우 sway만.

### ④ 앵커
우수: 안정 + 자연스러운 미세 움직임 + 상대 지향 + 개방 / 미흡: 과도·반복 흔들림 + 잦은 자기접촉 + 외면/위축. ⚠️ 조용한 자세≠무능(문화·체형·성격) · sway 단조 감점 금지(극단만).

### ⑤ 검증 + Kinect/웹캠 + 프라이버시
- α(**사람 상한 대비**), 한국인 평가자. ⚠️ 신체 주관 라벨은 α 낮게(0.4~0.7) → 물리 지표일수록 α↑, 낮은 지표는 제외.
- **부위별 독립 게이팅:** 검출 confidence 낮/가림이면 그 부위 N/A(감점 아님). 예: 홈 하체 N/A여도 상체·손 채점.
  - 미러(3D): 상체 정밀 + (전신 시)하체 + 손목 레벨. 홈(2D): 정면 개방각·좌우 sway·자기접촉만.
- **⚠️ 프라이버시:** 골격·영상 온디바이스·미저장(MediaPipe Apache2.0, Kinect SDK MIT — 상업 OK).

### 약점→보완 · 시니어 관행(7)
손 추적 최불안정(게이팅 최엄격+손목 레벨) · 안절부절 개인·문화차(개인 baseline) · 동기화 드롭 시 감점만 남음(경직만 감점) · 하체 대부분 N/A(전신 시만) · 역량 연결 최약+오작동 최고(가중치 최저+α, 안 되면 게이지 전용 강등).
시니어: 추적 신뢰도 1급 신호 · **시간 필터링(One-Euro)** · 신체크기 정규화 · 2D/3D 한계별 신호 분리 · 행동 정량화(분류 X) · 다부위 융합 · 프라이버시.
참고: Ranehill(2015)/Carney 철회 · Pang(2022)·Mohiyeddini(2013) self-touch · Nguyen(2014) · Casiez One-Euro(2012). ⚠️ 인용 확인.

## 8. 판정 모델 (저지) `[높음, 재검증]`

- 프롬프팅만 = 위험(전문 도메인 일치도 10~15%↓). 파인튜닝하면 in-domain 강함.
- **⚠️ 파인튜닝 judge = 범용 대체 아님** — 적대적 셋(LLMBar) 무작위 이하, 표면 편향 → **홀드아웃+적대적 검증 필수.** JudgeLM에선 CoT 파인튜닝이 성능 저하 사례 → CoT 포함은 실험으로.
- **레시피:** Prometheus 2(direct+pairwise, rubric 조건부, 7B 16GB) · M-Prometheus(다국어) · JudgeLM(swap aug·reference support). EXAONE 3.5로 파인튜닝.
- **⚠️ 판정자 패널(PoLL)은 한국어 역효과 가능**(KUDGE: 집계가 GPT-4o 단독보다 나쁨, 다중공선성) → 패널 대신 reference-guided + swap/반복. 쓰더라도 robust 집계 + 불일치 사람 검토.
- 한국어 벤치: KUDGE·LogicKor · **HRET(재현성·언어 일관성).** fallback은 액터의 것 → 저지는 JSON+이진+파인튜닝으로 낮춤.

## 11. 8월(설계 증명, ~7/28) vs 10월/논문

**8월 발표** — "거의 다 설계됐고 완성 가능"
- 응답: 문서화 + 액터/저지 분리 + 이진/3점 + **position swap + 길이 통제 + instance-level 루브릭 명시** + JSON + 격식·스탠스. **완곡우선 에피소드 1개 필수.**
- 음성: parselmouth + SNR 게이팅 + z-score + **유창성 speed+breakdown**. 실시간 3축 게이지.
- 표정: MediaPipe→AU 매핑 + 개인 중립 baseline + 기기별 게이팅. Kinect/웹캠 공통 RGB.
- 자세: **상체 3지표(sway·정렬·자기접촉)만** + **One-Euro filter** + 신체 정규화 + 부위별 게이팅. **손가락·제스처량·하체 채점 드롭**(하체는 게이지 위주).
- 검증: golden set 30~50 + **사람–사람 상한 함께 보고.**

**10월 / 논문** — rater 모집 전제
- **파인튜닝 EXAONE 저지(Prometheus2/JudgeLM) + 홀드아웃·적대적 검증 + reference-guided.**
- golden set 200+ · **per-criterion κ + IRT + calibration(ECE)** · pairwise · 편향 정량
- 한국어 judge 벤치(KUDGE/LogicKor) + HRET 재현성
- 음성: repair 유창성 + SSL 임베딩 보조 + 지표–지각 α
- 표정: 기기별 개별 α + 한국 데이터 대조 + 인구통계 공정성 + OpenFace/py-feat AU 대조
- 자세: 한국인 평가자 α(낮은 지표 제외) + sway 비단조 반영 + 손-발화 동기화 스트레치(미확보 시 드롭) + 문화 baseline 방어
- 완곡우선 시나리오 확장

⚠️ **rater 모집 = 최대 병목**(모든 축의 α·파인튜닝). 조기 착수.
