# Posture-Fit 개선 가이드 (Colab용)

## 이 문서에서 하는 일

MediaPipe가 만든 자세 집계값을 0~100점으로 바꾸는 Posture-Fit을 보정하는 실험임. 새 영상 AI를 처음부터 학습하는 작업은 아님. 적은 동작 데이터로 기존 점수 공식의 가중치와 측정 보류 기준을 더 안전하게 만드는 작업임.

## 먼저 알아둘 점

- MediaPipe 얼굴·포즈 랜드마크는 `poc/frontend`에서 계산함.
- PoC 서버의 `poc/backend/app/ai/nonverbal.py`가 집계값을 Posture-Fit 점수로 바꿈.
- 현재 주요 입력은 어깨 기울기, 고개 숙임 비율, 상체 흔들림, 자세 유지력, 프레임 수임.
- 전시 참가자의 영상은 저장하지 않음. 팀 내부 촬영은 지표를 뽑은 뒤 원본 영상을 지우는 방식으로 진행함.

## 준비할 데이터

50~200개 동작 세션이면 시작 가능함. 같은 사람이 여러 번 촬영했다면 학습과 최종 테스트에 섞이지 않게 해야 함.

필수 칸은 아래와 같음.

| 칸 | 뜻 |
| --- | --- |
| `sample_id` | 데이터 번호 |
| `person_group` | 같은 사람을 묶는 번호 |
| `source` | `internal` |
| `frames` | 분석된 프레임 수 |
| `avg_shoulder_tilt_deg` | 평균 어깨 기울기 |
| `head_down_ratio` | 고개를 숙인 비율 |
| `posture_sway` | 상체 흔들림 값 |
| `tilt_drift_deg` | 시간이 갈수록 기울어진 정도 |
| `target_score` | 팀 기준 정답 점수, 0~100 |
| `reason` | 점수를 준 이유 한 줄 |
| `measurement_status` | `measured` 또는 `withheld` |

## 동작 데이터 만드는 순서

1. 안정적인 자세, 약간 기운 자세, 오래 숙인 자세, 많이 흔들리는 자세, 시간이 지나며 무너지는 자세를 준비함.
2. 각 동작은 비슷한 시간과 카메라 위치에서 촬영함.
3. 너무 어둡거나 얼굴·상체가 잘리지 않은 영상인지 확인함.
4. MediaPipe로 집계값만 뽑아 표에 넣음.
5. 팀이 합의한 0~100점과 이유를 적음.
6. 원본 영상은 내부 확인 뒤 삭제하고, 지표 표만 남김.

## Colab에서 할 실험 순서

1. 사람 단위로 학습 70%, 보정 15%, 최종 테스트 15%를 나눔.
2. 현재 `score_posture` 공식으로 기본 점수를 계산함.
3. 프레임 수가 너무 적거나 값이 비어 있는 사례는 `측정 보류`로 분리함.
4. 단순 선형 회귀 또는 작은 트리 기반 회귀 모델로 보정 점수를 만들어 봄.
5. 기존 공식과 보정 모델의 MAE를 비교함.
6. 낮은 자세 점수를 높은 점수로 잘못 준 사례를 따로 확인함.
7. 새 방법이 더 낫지 않으면 기존 점수 공식을 유지함.

## 꼭 지킬 기준

- 사람의 체형, 장애, 문화적 자세 차이를 벌점으로 만들면 안 됨.
- 측정이 불안정하면 낮은 점수를 주지 말고 `측정 보류`로 처리함.
- 프레임 수가 적은 영상, 상체가 잘린 영상, 카메라 위치가 크게 다른 영상은 학습 데이터에서 분리함.
- 새 모델이 왜 낮은 점수를 줬는지 설명할 수 있어야 함.

## 이번 단계에서 하지 않는 것

- MediaPipe 자체를 파인튜닝하지 않음.
- 새 영상 분류 모델을 처음부터 학습하지 않음.
- Eye-Fit, Voice-Fit 점수는 건드리지 않음.
- 전시 참가자 원본 영상을 저장하거나 학습에 쓰지 않음.
