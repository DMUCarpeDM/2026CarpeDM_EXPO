# 퇴근 카드 — 감열 영수증 프린터 제작 가이드

> 체험이 끝나면 미러 옆에서 영수증이 *지익—* 하고 나온다: 4-Fit 점수, 오늘의 한 문장,
> 체험 코드 QR. 관람객이 실물을 들고 떠나는 전시 테이크아웃이자, 줄 선 사람들의 구경거리.
> 소프트웨어는 완성돼 있다 — 이 문서는 **부품 조달·배선·브링업**만 다룬다.

## 1. 부품 리스트 (총 4~7만원, 전부 "부품" 표기 가능)

| 품목 | 사양 | 예상가 | 규정 표기 |
|---|---|---|---|
| 감열 프린터 모듈 | 58mm 임베디드(패널형) TTL 시리얼, ESC/POS 호환 — CSN-A2 / QR204 / EM5820 계열 | 2.5~4만 | "감열 프린터 모듈(부품)" |
| USB-TTL 어댑터 | CH340 또는 CP2102, 5V 로직 | 3~5천 | "USB-시리얼 변환 모듈(부품)" |
| 전원 어댑터 | **DC 5~9V ≥2A** (모듈 사양 확인 — 인쇄 순간 전류가 크다) + DC잭-터미널 | 8천~1.5만 | "전원 어댑터(부품)" |
| 감열지 | 폭 58mm 롤 (지름 30~40mm, 모듈 홀더 크기 확인) 10롤 | 5천~1만 | "감열지(소모품)" |
| (선택) 점퍼선·케이스 재료 | 배선·미러 프레임 매립용 | ~1만 | "배선 재료" |

구매처: 디바이스마트·엘레파츠에서 "감열 프린터 모듈" 검색. **80mm가 아니라 58mm**인지,
**TTL(UART)** 인터페이스인지 확인할 것. (RS232 모델은 레벨 컨버터가 추가로 필요해서 피한다)

## 2. 배선 — 선 3개면 끝

```
감열 모듈            USB-TTL          전원 어댑터(5-9V 2A)
  TX  ───────────►  RX
  RX  ◄───────────  TX                ⚠ 모듈 전원은 USB-TTL의 5V 핀이 아니라
  GND ─────┬─────►  GND               반드시 별도 어댑터에서! (인쇄 헤드 전류를
  VH(전원+) │◄──────────────────────  USB가 감당 못해 줄이 갈라지거나 리셋됨)
           └──────────────────────►  GND (전원 GND와 공통 접지)
```

- TX/RX는 **교차**(모듈 TX → 어댑터 RX). 안 나오면 제일 먼저 스왑해 볼 것.
- GND는 어댑터·전원 모두와 공통으로 묶는다.

## 3. 브링업 (프린터 도착일 15분 코스)

```bash
cd poc/backend
# 1) 포트 확인 (macOS 예시 — 어댑터 꽂은 뒤)
ls /dev/tty.usbserial* /dev/tty.wchusbserial*
# 2) 테스트 카드 출력
.venv/bin/python scripts/print_receipt_test.py --port /dev/tty.usbserial-0001
```

카드가 나오면 끝. 서버 연동은 `backend/.env`에 두 줄:

```dotenv
MIRROTING_RECEIPT_DRIVER=serial
MIRROTING_RECEIPT_SERIAL_PORT=/dev/tty.usbserial-0001
# QR을 부스 LAN 리포트 URL로 보내려면 (비우면 QR에 체험 코드만 담김)
# MIRROTING_RECEIPT_QR_BASE_URL=http://192.168.0.10:5173
```

### 트러블슈팅 (흔한 순서)

| 증상 | 원인 | 조치 |
|---|---|---|
| 아무것도 안 나옴 | TX/RX 방향 | 두 선 스왑 |
| 아무것도 안 나옴 (스왑 후에도) | 보드레이트 | `--baud 19200`으로 재시도 (모듈 기본값이 9600/19200로 갈림) |
| 희미하거나 줄이 갈라짐 | 전원 부족 | USB 5V로 먹이고 있지 않은지 확인 — 별도 2A 어댑터 필수 |
| 위아래 밀리며 겹침 | 수신 버퍼 오버플로 | 이미 128행 밴드로 전송함 — 보드레이트를 낮춰(9600) 재시도 |
| 흰 종이만 스르륵 | 감열지 앞뒤 반대 | 롤 뒤집어 장착 (손톱으로 긁어 검게 되는 면이 인쇄면) |

## 4. 소프트웨어는 이미 준비돼 있다

| 구성 | 위치 |
|---|---|
| 렌더러(비트맵·ESC/POS)·드라이버 | `backend/app/services/receipt.py` |
| API (미리보기 PNG · 출력) | `GET/POST /api/sessions/{id}/receipt.png` · `/receipt/print` (세션 토큰 필요) |
| 브링업 스크립트 | `backend/scripts/print_receipt_test.py` |
| 테스트 | `backend/tests/test_receipt.py` (하드웨어 없이 전 경로 검증) |

한글은 전부 **Pretendard 비트맵으로 렌더**해서 보내므로 모듈의 한글 폰트/코드페이지와
무관하게 어떤 ESC/POS 모듈에서도 동일하게 나온다. 프린터 없이도
`MIRROTING_RECEIPT_DRIVER=file`(기본)로 두면 `media/receipts/`에 PNG 미리보기가 쌓인다.

## 5. 부스 운영 팁

- 모듈을 미러 프레임 하단(컨트롤 밴드 옆)에 매립하고 배출구만 노출 — "거울에서 영수증이 나온다".
- 감열지는 하루 1롤이면 충분(카드 1장 ≈ 12cm, 롤 30m ≈ 250장). 예비 3롤 이상 부스 보관.
- 감열지는 열에 약하다 — 직사광선 창가 보관 금지.
- 아침 리허설: `print_receipt_test.py` 1장 출력을 demo-checklist 아침 점검에 추가.
