## 지금 당장 중요한 것 세 가지

**1. 8/4 전에는 코드를 건드리지 않는다.** 통합은 전시 경로를 흔드는 변경이고, 발표에는 별도 프로세스(`:8002`) 데모 화면과 ① 문서면 충분하다.

**2. 아크릴 샘플이 오면 30분을 내서 ②를 돌린다.** 하프미러 뒤에서 850nm 뎁스가 동작하는지 아무도 안 쟀다. 통과/실패에 따라 **리그 골조 설계가 달라진다** — 조립 후에 알면 다시 짜야 한다.

**3. ③의 "인정" 톤에 팀이 동의하는지 먼저 확인한다.** Q29(아이컨택 규범은 개인화되지 않았다)·Q31(휠체어는 자세 측정 불가)은 약점을 먼저 인정하는 답변이다. 준비된 약점은 강점이지만, 발표자가 확신 없이 말하면 반대가 된다.
