# 연습 기록·사용방법 구조 개편

- 기록: v0 Chats의 검색·필터·정렬·목록 구조. 전체/최근(최대 10개)/즐겨찾기/진행 중/완료. 종류와 정렬 변경, 검색 초기화 제공.
- 기록 상세: 상황, 대화 내역, 피드백 탭. 저장된 데이터만 표시. 같은 상황 다시 연습은 홈 입력창에 원래 상황을 전달.
- 모든 연습 기록과 연습 기록은 동일한 목록으로 연결해 중복 제거.
- 사용방법: Perplexity Help의 검색·바로가기·주제 카드. v0 Quickstart 방식의 단계별 설명. 문서 상세는 주제 목록/본문/목차. 모바일 주제 목록 기본 접힘.
- 사용방법 URL: `?guide=all`, `?guide=quickstart`, `?guide=prompt`, `?guide=editor`, `?guide=records`, `?guide=troubleshooting`. 직접 진입 및 새로고침 지원.
- 일반 웹 대화는 기존과 같이 자동 결과 저장·4-Fit 분석을 실행하지 않음. 기록 기능이 자동 저장을 구현한 것으로 오해하지 않도록 사용방법에 명시.
- 기존 스마트미러 결과 보고서 진입은 유지.

검증: `node output/layout-qa/library-help-qa.mjs`에서 320/390/768/1440px 도움말 검색·결과 없음·초기화·상세 이동·새로고침, 기록 검색·즐겨찾기·상태 필터·상세 탭, 가로 넘침 없음 통과. 기록 데이터는 QA 전용 fixture. production 기록에는 예시 주입 없음. `npm run build`, `git diff --check` 통과. QA 캡처와 harness는 생성물로 커밋하지 않음.
