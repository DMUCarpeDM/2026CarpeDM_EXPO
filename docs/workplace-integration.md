# 직장 대화 통합 안내

GitHub main의 기존 구조에 로컬 직장 대화 기능을 선별해 통합했습니다.

## 포함한 변경

- 출근·업무·퇴근 3막, 12턴/20턴 연속 대화와 단계별 상황 안내
- 직장 대화 진입 단계 단축, 기본 난이도 보정
- 상대 반응 영상 5개와 감정 클립 선택 로직
- Gemini 선택 지원, 기존 OpenAI 기본 설정 유지
- 같은 장면을 유지하는 대체 대사와 생성/대체 통계
- 분석 중에는 결과 화면의 무조작 복귀 타이머를 걸지 않음
- 같은 평가 항목은 여러 진행 턴에서 반복돼도 한 목표로 집계

현재 관람객용 화면은 5분/12턴으로 시작합니다. 10분/20턴은 API 설정에서 지원하며 화면에 시간 선택 기능이 추가된 것은 아닙니다.

실행 DB, 녹음, API 키, node_modules, 가상환경, 다운로드한 분석 모델은 포함하지 않습니다.

## 동작 범위와 한계

Gemini 하루 계획은 외부 API 성공 시에만 생성합니다. 실패하면 준비된 팩으로 진행합니다.
답변 근거·모순 분석은 OpenAI 기반이며 키가 없거나 실패하면 미측정입니다.
영상 감정은 텍스트/평가 신호에 따른 연출이고 네 캐릭터가 공용 클립을 사용합니다.
Whisper와 E5 가중치는 별도로 준비해야 합니다.
`dialogue_fallback`은 프로세스 내 직장 연속 대화 통계로 재시작하면 초기화됩니다.

## 검증 방법

저장소 루트에서 다음을 실행합니다.

```sh
cd mvp
npm ci
npm test
npm run build
cd ../poc/backend
.venv/bin/python -m pytest -q
```

프론트 브라우저 테스트는 설치된 Chrome과 로컬 포트 사용 권한이 필요합니다.
테스트는 외부 AI 응답을 대체해 흐름을 검증하며 실제 모델 품질을 보장하지 않습니다.
실기 시연은 직장대화 시작 → 상황 안내 → 각 단계 답변 → 마지막 턴 완료 → 결과 순서로 확인합니다.
카메라·마이크 권한과 실제 음성 인식, 제공자별 API 생성은 별도로 확인합니다.
