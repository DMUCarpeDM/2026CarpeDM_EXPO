# 4-Fit 분석·점수·대화 엔진 최신 합의 통합본

기준일: 2026-09-11

상태: 설계 기준 문서. 구현·학습·서비스 적용 완료를 뜻하지 않음.

## 1. 이 문서의 사용 방법

현재 대화에서 합의한 내용을 우선한다. 이전 계획서와 충돌하면 이 문서를 따른다. 새로운 수치를 임의로 확정하지 않으며, 아직 확인하지 못한 내용은 마지막의 남은 작업에 모았다.

현재 요청 범위는 설계와 문서 정리뿐이다. 코드 작성·실행, 기존 모델 교체, 파일 삭제는 진행하지 않는다. 이전에 작성된 Colab 노트북은 별도 시제품이며 설계 확정이나 성능 입증의 근거로 삼지 않는다. 일자별 계획은 만들지 않는다.

4명이 응답·음성·표정·자세를 한 영역씩 담당한다. 단, 네 영역 모두 새 분류모델을 학습하는 구조는 아니다. 담당자 실명 배정은 아직 하지 않았다.

## 2. 전체 구조와 책임

사용자 음성·영상 → 영역별 분석 → 확인된 결과와 근거 → 별도 점수 계산 / 다음 대화 반영 / 종료 후 보고서.

| 구성 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 응답 분석 | 예시 답변과 의미 비교, 필수 내용 누락 확인, 군더더기·다시 말하기 분석 | 새 답변 분류기 학습, 모델 내부 점수 계산 |
| 음성 분석 | 목소리 크기·말하기 속도·긴 멈춤 계산 | 억양 분류, 음·어 반복 분석, 새 음성 분류기 학습 |
| 표정 분석 | 얼굴 이미지에서 5개 항목별 표정 유무 판단 | 감정·성격·태도 단정, 실시간 지적 |
| 자세 분석 | 정적 자세 5개와 좌우 반복 움직임 판단 | 자세 이름을 곧바로 감점으로 해석 |
| 점수 엔진 | 개발자가 정한 상황별 규칙으로 가감점 | 보정되지 않은 모델 출력값을 점수로 직접 환산 |
| 대화 엔진 | 역할과 목표를 유지하며 다음 발화 생성 | 분석 실패를 사용자 잘못으로 간주 |
| 모순 확인 | 앞뒤 발언의 명확한 불일치 판단과 확인 요청 | 응답 모델의 모순 클래스 학습 |

공통 결과 형식은 기존 초안을 재사용하되 최신 설계에 맞춰 수정해야 한다. 모든 영역에서 일률적인 확률 출력을 요구하지 않는다. 음성의 계산값, 응답의 유사도, 표정·자세의 모델 출력값은 서로 다른 의미다.

공통으로 연결할 정보는 영역, 측정 상태, 결과 항목, 시작·종료 시점 또는 답변 번호, 판단 근거, 사용한 기준의 버전이다. 구체적인 필드명·단위·오류 전달 규격은 통합 검토가 남아 있다.

## 3. 응답 분석

새 분류기를 학습하지 않는다. LLM(대규모 언어모델)이 질문과 개발자의 평가 기준을 바탕으로 좋은 답변·중간 답변·나쁜 답변의 예시를 여러 개 생성한다. 사용자 답변을 E5(문장 의미를 벡터로 바꾸는 모델)로 비교해 가장 가까운 유형을 찾는다.

문장 표현이 달라도 의미와 맥락이 비슷하면 인정한다. 단어가 겹친다는 이유만으로 정답 처리하지 않는다. 유사도가 낮거나 유형 간 차이가 작으면 판단을 보류한다. 보류 기준 수치는 검증 후 정한다.

필수 내용 누락은 예시 답변 유사도와 별도로 LLM이 평가 기준과 대화 기록을 확인한다. 충족했다고 판단한 내용에는 사용자 발언 근거를 연결한다. 누락은 사용자가 실제로 말하지 않은 내용이며, 예시와 표현이 다르다는 뜻이 아니다.

음·어 같은 반복 표현과 말을 중단하고 다시 시작하는 현상은 응답 영역에서 다룬다. 이를 위한 별도 목소리 데이터 녹음 과제는 만들지 않는다.

예시 생성 개수, 생성 결과 검수 방식, 누락·모순 판단 기준 및 평가용 사례는 추가 설계가 필요하다. 옛 문서의 13개 라벨 분류기 학습 계획을 현재 기준으로 사용하지 않는다.

## 4. 음성 분석과 마이크 테스트

학습형 음성 분류기 대신 계산과 규칙으로 크기·속도·긴 멈춤을 판단한다. 억양은 제외한다.

| 항목 | 계산 방향 | 주의점 |
| --- | --- | --- |
| 목소리 크기 | 유효 발화 구간의 RMS(신호의 평균적인 크기)를 세션 기준과 비교 | 실제 공간의 절대 소음 크기로 해석하지 않음 |
| 말하기 속도 | 발화된 음절 수를 실제 말한 시간으로 나눔 | 숫자·영어의 실제 발음 길이, 짧은 답변과 인식 실패 처리 필요 |
| 긴 멈춤 | VAD(발화 구간 감지)로 말 사이의 무음 시간 계산 | 답변 전 대기·말 사이 멈춤·답변 종료 후 무음을 구분 |

시뮬레이션 전에 팝업에서 마이크 테스트를 진행한다. 사용자는 자연스럽게 안내 문장을 읽고, 시스템은 발화 감지·입력 수준·잡음·클리핑(입력 신호의 잘림)을 점검한다. 장비는 전시용 고정 장비와 개인 PC를 모두 고려한다.

적절한 입력 범위를 맞추는 것이 목적이며, 기준 음성 파일과 물리적인 목소리 크기를 같게 만들려는 것이 아니다. 사용자가 억지로 크게 말하게 하기보다 마이크 거리·입력 설정을 조정한다. 통과한 발화를 해당 세션의 크기 기준으로 사용한다. 마이크 변경·연결 해제 후에는 재검사가 필요하다.

공공 음성은 속도·멈춤 분포의 참고 자료로 활용할 수 있지만, 장비가 다른 파일의 절대 음량을 그대로 비교하지 않는다. 입력 자동 조절·거리 변화·클리핑을 곧바로 고함이나 감점 사유로 해석하지 않는다.

마이크 테스트 길이·통과 범위, 크기·속도·긴 멈춤의 수치는 미확정이다. 옛 계획의 1.5초 멈춤이나 자체 녹음 수량을 최종 기준으로 승계하지 않는다. STT(음성의 텍스트 변환)의 임시 전송은 허용하되 추후 로컬 방식으로 변경할 수 있도록 책임을 분리한다.

## 5. 표정 분석

### 라벨과 데이터

| 라벨 | 판단 기준 | 원본 활용 방향 |
| --- | --- | --- |
| 미소 | 입꼬리가 위로 올라감 | RAF-AU AU12 |
| 눈썹 찌푸림 | 눈썹이 내려가며 미간 쪽으로 모임 | RAF-AU AU4 |
| 눈썹 올림 | 눈썹 안쪽 또는 전체가 올라감 | RAF-AU AU1 또는 AU2 |
| 눈 크게 뜸 | 윗눈꺼풀이 올라가 눈이 크게 열린 모습 | RAF-AU AU5 |
| 무표정 | 눈썹·눈·입에 뚜렷한 표정 움직임이 없음 | RAF-DB Neutral 후보를 검토 |

입술 누름은 제외한다. RAF-AU와 RAF-DB만 사용하며 Aff-Wild2와 시나리오 기반 3D 표정 데이터는 선택하지 않는다. 신청 메일은 사용자가 발송 완료했다고 알렸으며, 이 대화에서는 수령 완료가 확인되지 않았다. 이용 승인과 Colab·팀 내부 공유·추가 라벨링 조건도 확인 대상이다.

사진별로 각 라벨을 있음·없음·미확인으로 표시한다. RAF-DB의 감정 이름을 얼굴 움직임으로 자동 변환하지 않는다. 미확인은 해당 항목의 학습과 평가에서 제외한다. AI의 임시 라벨은 사람 검토를 거쳐 확정한다.

여러 움직임은 동시에 표시할 수 있다. 무표정은 다른 양성과 동시에 표시하지 않는다. 다른 네 라벨이 없다고 무표정으로 자동 처리하지 않는다. 목록 밖의 표정은 기타로 관리하고, 가림·흐림은 판단 불가로 구분한다. 이 둘은 학습할 핵심 5개 라벨에 추가하는 클래스가 아니다.

### 시간 기록 — 최신 확정 기준

| 항목 | 기준 |
| --- | --- |
| 기록 조건 | 같은 표정이 0.5초 이상 연속 감지 |
| 구간 연결 | 감지가 끊긴 시간이 0.5초 미만이면 같은 표정 구간으로 집계 |
| 새 구간 | 0.5초 이상 끊긴 뒤 다시 기록 조건을 충족하면 별도 집계 |
| 실제 지속시간 | 연결된 구간에서도 미감지 시간은 제외 |
| 가림·미검출 | 미측정으로 처리하며 앞뒤 구간을 연결하지 않음 |

동시에 나타나는 표정의 지속시간은 각각 계산한다. 구간 연결 규칙을 이유로 짧은 검출을 합산해 최초의 0.5초 연속 조건을 대체하지 않는다.

권장 기본 집계는 횟수보다 측정 가능한 시간 중 해당 표정이 나타난 비율을 우선한다. 횟수와 최장 지속시간을 함께 제시한다. 동시 표정 때문에 각 비율의 합이 100%를 넘을 수 있다. 전체 시간과 답변·청취 시간의 세부 집계 범위는 추가 명세 대상이다.

표정 자체를 감정·나쁜 태도로 단정하지 않는다. 실시간 역할 발화와 팁바에서 표정을 지적하지 않으며 종료 후 보고서와 별도 상황별 점수 규칙에서 다룬다. 기록 조건 충족이 곧 가감점 조건 충족을 뜻하지 않는다.

### 학습과 검증

얼굴 이미지 기반 전이학습과 항목별 다중 라벨 분류를 사용한다. 입력 품질이 부족하면 미측정으로 둔다. 라벨별 기준값은 검증 데이터로 결정하며 임의의 확률을 최종값으로 확정하지 않는다.

기존 시제품의 ResNet-18과 입력 설정은 첫 실험 선택이다. 실제 데이터 검증을 거친 최종 모델 선정으로 간주하지 않는다. 원본 라벨 형식, 양성·음성 수, 중복·인물 분리, 데이터 출처 차이에 대한 검토가 남아 있다.

## 6. 자세 분석

정적 라벨은 고개 아래로 숙임, 상체 좌우 한쪽 기울어짐, 상체 앞으로 기울어짐, 팔짱, 손을 얼굴에 댐의 5개다. 좌우 기울어짐은 하나의 항목으로 다룬다. 몸이 좌우로 반복 이동함은 시간 흐름이 필요한 별도 동작이다.

정적 자세는 정면에서 촬영한 이미지로 학습할 수 있다. 몸의 좌우 반복 움직임은 영상 또는 연속 프레임으로 분석한다. MediaPipe Pose(관절 위치 추출)의 특징을 활용해 자세 분류기를 학습하는 방향이다. 손·얼굴 접촉 구분을 위한 추가 특징 필요 여부는 샘플에서 점검한다.

자체 자세 촬영은 참여자 부담으로 폐기한 방향을 유지한다. 공공·외부 데이터에서 정적 라벨별 300장 수집을 요청했지만 완료된 수량이 아니다. 정상 자세·헷갈리는 자세 등 음성 예시도 필요하다. 여기서 음성 예시는 오디오가 아니라 해당 자세가 없는 비교 사진을 뜻한다.

공공 데이터는 후보만 조사된 상태이며 최종 선정·이용권한·라벨별 확보량은 미확정이다. 반복 이동의 영상 수, 방향 전환 횟수, 관찰 시간, 정적 자세 지속시간, 관절 결측 기준도 남아 있다. 표정의 0.5초 규칙을 자세에 자동 적용하지 않는다.

옛 문서의 뒤로 기울기·큰 제스처·끄덕임을 핵심 학습 라벨로 승계하지 않는다. 정면 촬영 조건은 카메라 방향을 의미하며 몸까지 항상 똑바로 세우라는 뜻이 아니다. 배경 제거를 요구하지 않는다.

## 7. 점수화 엔진

각 영역은 75점에서 시작하고 결과를 0~100점으로 제한한다. 개발자가 면접·직업훈련·직장 대화와 각 시나리오에 맞는 가감점 규칙을 정한다. 모델 안에서 가감점하지 않는다.

측정된 영역 점수의 산술평균을 구하고, 명확한 모순에 따른 전체 감점은 별도로 적용한 뒤 최종 범위를 제한한다. 미측정 영역은 0점으로 넣지 않고 평균에서 제외한다. 모두 미측정이면 점수를 제시하지 않는다.

좋은 행동이 확인돼야 가점하며, 문제가 없다는 이유만으로 계속 점수를 더하지 않는다. 지속되는 같은 문제를 매 프레임·매초 새로 감점하지 않는다. 최종 점수는 종료 후 공개한다.

라벨·상황별 실제 점수, 누적 상한, 같은 문제가 재발했을 때의 재감점 기준, 영역별 유효 측정량은 추가 설계 대상이다. 기존 표의 +5, -3 같은 숫자는 설명용 예시이지 최종 가중치가 아니다.

## 8. 모순 확인과 실시간 피드백

모순은 응답 분류모델의 별도 클래스가 아니다. 대화 기록과 발언 근거를 별도로 확인한다. 명확한 모순은 전체 점수 감점과 상사 역할의 확인 질문으로 연결한다. 애매한 차이나 사용자가 이유를 설명한 변경을 자동 모순으로 처리하지 않는다. 동일 사건은 중복 감점하지 않는다.

사용자가 범위를 줄이기 위해 제외한 감점 복구·취소 기능은 추가하지 않는다. 모순의 심각도와 감점 수치, 확인 질문 후 다음 진행은 세부 설계가 필요하다.

큰 핵심 누락, 명확하고 지속되는 자세·음성 문제는 다음 역할 발화에 영향을 줄 수 있다. 사용자가 말하는 동안은 팁바, 사용자의 답변이 끝난 뒤에는 상사 등 현재 역할을 유지한 자연스러운 응답으로 안내한다. 코치 역할로 바뀌어 대화를 끊지 않는다.

팁바와 역할 응답은 같은 문제 근거를 공유해 서로 다른 지적을 하지 않게 한다. 표정은 이 실시간 지적 대상에서 제외한다. 여러 문제의 우선순위, 알림 반복 간격, 분석 지연·실패 시 대화 진행 규칙은 남아 있다.

## 9. 시나리오 흐름과 종료

직업훈련·직장 대화는 개발자가 정한 목표와 충족 조건을 둔다. AI는 역할을 유지하며 필요한 내용을 사용자가 말할 수 있도록 대화를 이어 간다. 표현이 달라도 의미와 맥락이 같으면 인정하며 대화 기록을 함께 본다.

목표가 충족되면 자연스럽게 마무리하고 보고서로 이동한다. 사용자는 목표 달성 전에도 직접 종료할 수 있다. 목표 미달을 달성으로 바꾸어 표시하지 않는다.

면접은 특정 업무 목표 대신 준비된 주요 질문 6개 이상에 답했을 때 종료하는 방식이다. 후속 확인 질문을 주요 질문 수에 중복 포함하지 않는다. 정확한 질문 수, 무응답·건너뛰기 처리와 답변 완료 기준은 남아 있다.

진행이 막히면 질문을 쉽게 바꿔 최대 두 번 더 유도한 뒤 다른 조건으로 넘어가며, 충족하지 않은 조건은 남긴다. 모든 질문을 소진했는데 목표가 미달인 경우와 분석 서비스 오류 시 종료 처리는 추가 명세 대상이다.

## 10. 최종 보고서와 보관

보고서는 나의 문제점, 세션에서 자주 나타난 습관, 근거가 있는 장점 최대 3개, 관련 영상 구간, 개선 피드백, 가감점 이유를 보여준다. 근거가 부족한데 장점 3개를 억지로 만들지 않는다. 한 세션의 반복을 개인의 평소 성격이나 장기 습관으로 단정하지 않는다.

| 자료 | 보관 방향 |
| --- | --- |
| 사용자 원본 영상 | 사용자 컴퓨터의 임시 영역에서만 처리하고 결과 확인 후 해제·삭제 |
| 음성 | 음성 인식을 위한 임시 전송 허용. 추후 로컬 처리로 바꿀 수 있도록 분리 |
| 전사·측정값·점수 근거·보고서 | 서버에 결과 생성 후 5일 보관 후 자동 삭제 |
| 결과 접근 | 로그인한 본인만 허용 |

서버에 남는 보고서에서 이미 삭제된 원본 영상을 다시 볼 수 있다고 약속하지 않는다. 영상 삭제 후에는 텍스트와 측정 결과 중심으로 제공한다.

원본 영상 처리와 보고서 서버 저장을 혼동하지 않는다. 외부 음성 인식 제공자의 보관 정책은 별도 확인해야 하며 임시 전송 허용을 영구 보관 허용으로 확대하지 않는다.

문제·습관·장점의 선정 순서, 영상 구간 길이, 짧은 세션의 보고 방식, 중도 종료·창 닫힘·전송 실패 시 정리, 서버 삭제 실패·복제본 처리 등 세부 설계는 남아 있다.
