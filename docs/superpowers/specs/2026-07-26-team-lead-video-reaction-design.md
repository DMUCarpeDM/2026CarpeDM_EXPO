# 팀장 영상 반응 설계

## 목표

팀장 역할 연습에서 사용자 카메라가 크게 보이던 영역을 팀장 영상으로 바꿈. 사용자가 실제 상대와 대화하는 느낌을 받을 수 있게, 대화 순서와 답변 분석 결과에 따라 팀장 표정을 바꿈.

## 범위

- 팀장 역할(`manager`)에서만 적용함.
- 동료, 임원, 외부 파트너 역할은 현재 화면과 동작을 유지함.
- 사용자 카메라 화면은 크게 표시하지 않음.
- 카메라 권한과 4-Fit 분석은 기존처럼 백그라운드에서 계속 사용함.

## 영상 자산

| 상태 | 사용할 파일 | 표시 시점 |
| --- | --- | --- |
| 팀장 발화 | `팀장발화.mp4` | 팀장 질문을 읽거나 AI 음성이 재생되는 동안 |
| 듣기 | `팀장이야기듣는표정.mp4` | 사용자가 답변하는 동안 |
| 긍정 반응 | `text_Keep_the_exact_identit2.mp4` | 답변 분석이 좋은 경우 |
| 부정 반응 | `팀장화난표정.mp4` | 답변 분석이 부족하거나 위험한 경우 |

영상은 각각 약 10초이며, 현재 상태가 유지되는 동안 반복 재생함. 긍정·부정 반응은 짧게 보여준 뒤 다음 대화 상태에 맞는 영상으로 돌아감.

## 상태 전환

1. 팀장이 질문하는 중에는 발화 영상을 표시함.
2. 사용자가 답할 차례가 되면 듣는 표정 영상을 표시함.
3. 사용자가 답변을 제출하면 백엔드의 응답 분석 결과를 확인함.
4. 분석 결과가 `missing`, `short`, `risky`이면 화난 표정을 표시함. 그 외에는 웃는 표정을 표시함.
5. 반응 영상 표시가 끝나면 다음 질문의 발화 영상 또는 사용자의 답변 대기 상태로 전환함.

## 컴포넌트와 데이터 흐름

- `PracticePage`가 현재 대화 상태와 응답 분석 결과를 바탕으로 팀장 영상 상태를 결정함.
- 팀장 영상 재생만 담당하는 작은 전용 컴포넌트를 추가함. 영상 파일, 반복 재생, 무음 재생, 상태 변경 시 처음부터 다시 재생하는 일을 맡음.
- 기존 `useFaceTracking`은 사용자 카메라 스트림을 계속 받아 분석함. 다만 큰 화면의 `video` 요소는 팀장 영상 재생에 사용하므로, 분석 전용으로 보이지 않는 별도 video 요소를 유지함.
- 기존 질문, 답변 제출, 음성 녹음, 실시간 4-Fit 피드백, 대화 로그 API 흐름은 바꾸지 않음.

## 실패 처리

- 영상이 재생되지 않으면 팀장 초상화와 현재 상태 문구를 대신 표시함.
- 팀장 역할이 아니거나 영상 파일을 불러오지 못하면 기존 사용자 카메라 화면을 사용함.
- 분석 결과가 아직 없으면 듣는 표정을 기본값으로 사용함.

## 확인 기준

1. 팀장 역할에서만 큰 카메라 영역에 팀장 영상이 보임.
2. 팀장 질문, 사용자 답변, 좋은 답변, 부족한 답변에서 각각 지정한 영상으로 전환됨.
3. 다른 역할의 화면과 기존 4-Fit·대화 API 흐름이 바뀌지 않음.
4. 영상 재생 실패 시 연습 화면이 멈추지 않고 초상화 대체 화면을 표시함.
