# 역할 페르소나와 Ollama 필수 대화 파이프라인 설계

## 목표

연습 상대 역할을 동료, 상사, 임원, 외부 파트너 네 가지로 단순화함. 각 역할은 성격, 직책, 말투를 가지며 기본·압박·초압박 난이도에 따라 질문 태도가 달라짐.

시뮬레이션은 로컬 Ollama 대화 모델이 준비되었을 때만 시작함. 외부 AI API와 템플릿 단독 대화는 사용하지 않음.

## 역할

| 내부 ID | 화면 이름 | 기본 페르소나 |
| --- | --- | --- |
| `colleague` | 동료 | 같은 팀의 기획자. 친근하고 협조적이며 함께 해결 방법을 찾음. |
| `manager` | 상사 | 팀장. 결과와 우선순위를 중요하게 보고 짧고 분명하게 말함. |
| `executive` | 임원 | 사업 책임자. 기대 효과, 위험, 결정 근거를 중요하게 봄. |
| `partner` | 외부 파트너 | 협력 회사 담당자. 일정, 약속, 담당 범위를 중요하게 봄. |

화면 이름만 단순화하고 내부 ID는 유지함. 기존 프론트 선택·세션 API 연결이 깨지지 않음.

## 난이도별 태도

| 역할 | 기본 모드 | 압박 모드 | 초압박 모드 |
| --- | --- | --- | --- |
| 동료 | 편안하게 함께 정리함 | 빠진 내용을 바로 확인함 | 짧은 시간 안에 선택을 요청함 |
| 상사 | 차분하고 분명하게 질문함 | 근거와 마감 시간을 확인함 | 결론, 담당자, 기한을 바로 물음 |
| 임원 | 큰 방향과 기대 효과를 질문함 | 숫자, 위험, 대안을 요구함 | 결정 이유와 책임 범위를 즉시 확인함 |
| 외부 파트너 | 협력적으로 일정을 조율함 | 약속한 날짜와 담당을 확인함 | 지연 영향과 즉시 가능한 대안을 요구함 |

기본 모드에는 압박 질문을 넣지 않음. 압박 모드는 에피소드마다 한 번의 추가 확인 질문을 허용하고, 초압박 모드는 같은 확인에 짧은 응답 시간·결론 우선 규칙을 더함.

## 대화 파이프라인

```text
역할 + 시나리오 + 난이도 선택
        ↓
백엔드가 Ollama와 exaone3.5:2.4b 준비 상태 확인
        ↓
준비됨: 시나리오 구조 + 역할 페르소나 + 난이도 규칙을 Ollama에 전달
준비 안 됨: 세션 생성 거절, 프론트 시작 버튼 비활성화
        ↓
Ollama가 한국어 질문 한 문장 생성
        ↓
사용자 답변 분석 → 다음 질문 생성 + 팀장 영상 반응에 결과 전달
```

## Ollama 프롬프트 구성

각 질문 생성 요청에 다음 정보를 함께 보냄.

1. 역할의 이름, 직책, 기본 성격, 말투
2. 선택 난이도에 맞는 태도와 금지·강조 규칙
3. 현재 에피소드의 상황, 학습 목표, 확인할 항목
4. 사용자의 직전 답변과 이미 대화한 내용
5. 출력 규칙: 한국어 존댓말, 질문 한 문장, 역할에 맞는 말투, 장문 설명 금지

템플릿 대본은 질문의 사실과 학습 목표를 제공하는 재료로만 사용함. Ollama가 답하지 못하면 템플릿 문장으로 대체하지 않고, 해당 대화를 재시도할 수 있게 실패를 알림.

## Ollama 필수 규칙

- 사용 모델은 로컬 `exaone3.5:2.4b`임.
- 외부 AI API는 호출하지 않음.
- 프론트는 `/api/health`에서 `dialogue_provider=ollama`와 대화 모델 준비 상태를 확인함.
- 백엔드 세션 생성 API도 같은 상태를 다시 확인하고, 준비되지 않았으면 `503`을 반환함.
- 대화 중 Ollama 요청이 실패하면 다음 템플릿 질문으로 넘어가지 않음. 오류 문구와 재시도 동작을 제공함.

## 팀장 영상 반응 연결

답변 분석의 `excellent`, `covered`, `missing`, `short`, `risky` 결과를 팀장 영상 상태에 전달함.

- `excellent`, `covered`: 웃는 표정 영상
- `missing`, `short`, `risky`: 화난 표정 영상
- 팀장 질문 중: 발화 영상
- 사용자 답변 중: 듣는 표정 영상

팀장 영상은 `manager` 역할에서만 사용하며, 다른 역할은 기존 화면을 유지함.

## 구현 경계

### 백엔드

- 캐릭터 시드에 역할별 기본 페르소나와 난이도별 태도를 추가함.
- 임원과 외부 파트너에 맞는 시나리오·에피소드를 추가하거나 기존 에피소드를 역할에 맞게 정리함.
- 세션 생성과 다음 질문 API에서 Ollama 준비 상태를 강제함.
- Ollama 대화 제공자는 역할·난이도 정보를 포함한 시스템 프롬프트를 사용함.
- 템플릿 제공자는 장면 순서·질문 목표만 계획하고, 화면에 출력할 질문의 폴백으로 사용하지 않음.

### 프론트엔드

- 역할 선택 레이블을 동료·상사·임원·외부 파트너로 변경함.
- 미리 보기와 시작 버튼에서 Ollama 미준비 상태를 명확히 표시하고 시작을 막음.
- 팀장 역할 연습 화면에서 팀장 반응 영상 상태를 표시함.

## 확인 기준

1. Ollama가 꺼져 있으면 프론트와 백엔드 모두 새 시뮬레이션 시작을 막음.
2. Ollama가 준비되면 선택한 역할과 난이도에 맞는 시스템 프롬프트로 질문을 생성함.
3. 기본 모드에서는 압박 질문과 시간 압박이 나오지 않음.
4. 압박·초압박 모드는 역할별 태도에 맞는 더 강한 확인 질문을 생성함.
5. 외부 AI API 호출이 없음.
6. 팀장 역할에서 답변 분석 결과가 팀장 영상 표정 전환에 연결됨.
