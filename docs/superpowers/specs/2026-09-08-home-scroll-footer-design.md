# Home 스크롤 효과와 공통 푸터

## 승인된 방향

면접·직업훈련·직장대화 Home 3종에만 적용한다. 현재 색상, 폰트, 버튼, 콘텐츠 폭을 유지한다. 모드 선택·준비·실제 시뮬레이션·결과 화면과 서비스 동작은 변경하지 않는다.

## 푸터 구조

현재 Home에는 하단 시작 CTA만 있으므로 CTA를 유지하면서 공통 푸터를 추가한다. 첨부 이미지의 배치만 참고한다.

- 상단 왼쪽: Mirror-Ting 브랜드와 짧은 서비스 설명, 짧은 구분선.
- 중단: 3열 링크 그룹. 현재 서비스에서 작동하는 모드 선택, 연습 시작, Home 내 설명·과정·FAQ 등의 이동 대상으로 구성한다.
- 하단: 전체 폭 구분선, 왼쪽 저작권 정보, 오른쪽 실제 제공되는 보조 탐색.
- 존재하지 않는 회사·정책·보안 페이지나 임의 연락처는 만들지 않는다. 기존 연결 대상이 없는 법적 링크는 생략한다.
- 현재 Home의 표면·텍스트·구분선 토큰을 재사용하고 참고 이미지의 파란 전체 배경은 복사하지 않는다.
- 모바일에서는 링크 그룹을 세로로 재배치하고 하단 정보도 줄바꿈한다.

## 움직임

Motion 공식 스크롤 예제를 참고하고 이미 설치된 framer-motion을 재사용한다. 라이브러리 업그레이드나 유료 예제 도입은 하지 않는다.

- 섹션의 제목·설명·시각 자료: 처음 화면에 진입할 때 한 번만 opacity와 작은 수직 이동으로 등장한다. 초기 기준은 이동 20px, 지속 0.5초다.
- 같은 행의 카드: 약 0.08초 간격으로 등장하며, 누적 지연은 0.24초 이하로 제한한다.
- Hero 핵심 정보는 스크롤을 기다리지 않고 처음부터 읽을 수 있게 한다.
- 데스크톱 푸터: 본문이 올라가며 뒤에 놓인 푸터가 드러나는 reveal 구성을 사용한다. 스크롤을 가로채거나 인위적으로 느리게 만들지 않는다.
- 작은 화면 또는 푸터가 뷰포트보다 높은 경우 일반 문서 흐름으로 전환해 내용이 잘리지 않게 한다.
- 동작 줄이기 설정에서는 이동·스크롤 연동 효과를 없애고 콘텐츠를 즉시 표시한다. 키보드로 진입한 요소는 항상 보이고 조작할 수 있어야 한다.

## 변경 경계

HomePage와 Home 전용 스타일, 필요한 작은 Home 전용 모션·푸터 컴포넌트만 변경한다. 모드별 기존 섹션 순서와 하단 CTA는 유지한다. 전역 토큰과 공통 버튼 기본값을 수정하지 않는다.

## 검증

1. 기존 단위 테스트와 프로덕션 빌드 통과.
2. 세 Home에서 첫 화면, 중간 섹션, 푸터까지 실제 스크롤 확인.
3. 카드의 등장 순서와 재스크롤 시 반복되지 않는 동작 확인.
4. 데스크톱·모바일에서 가로 넘침, 푸터 잘림, 링크 클릭 가림이 없는지 확인.
5. 키보드 탐색 및 동작 줄이기 환경에서 내용과 링크에 접근 가능한지 확인.
6. 시뮬레이션 및 다른 화면 파일에 변경이 없는지 diff 확인.

## 설계 자체 검토

적용 화면, 토큰 유지, 푸터 콘텐츠와 링크 정책, 모바일 대체 동작, 접근성과 검증 범위를 명시했다. 새 페이지 제작과 추가 이미지 생성은 범위에서 제외한다.
