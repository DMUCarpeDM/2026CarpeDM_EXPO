## 세 줄 결론

1. **라이브 시연 불가** — 심사장 기자재에 기기 연결 금지. 시연은 사전 녹화 영상 + 정지 캡처로만 전달된다.
2. **남은 기간에 코드를 쓰지 않는다** — 점수는 촬영·측정·프레이밍에서 나온다 (발표력 20점이 최대 회수처).
3. **실질 완성 마감은 9월 말** — "10월 초 최종 출품 가능 여부 확인" 게이트가 8/4 이후에 하나 더 있다.
