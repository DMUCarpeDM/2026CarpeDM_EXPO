## 1. 방법론과 이 리포트의 한계

### 1.1 패널 구성 근거

실제 심사위원단(학생처장 1 + 학생부처장 1 + 학부장 6 + 외부 3 = 11명)의 **비율을 유지한 채 50인으로 확대**했다.

| 계층 | 실제 | 비율 | 가상 50인 | 세부 |
|---|--:|--:|--:|---|
| 본부 보직 라인 | 2 | 18% | **9** | 학생처·교무·산학·홍보·혁신지원 축 |
| 학부장 계열 | 6 | 55% | **27** | 기계 4 / 로봇자동화 5 / 전기전자통신 5 / 컴퓨터 5 / 생활환경 4 / 경영 4 |
| 외부 심사위원 | 3 | 27% | **14** | A-1 전자·IT제조 4 / A-2 IT·SW 2 / A-3 HR·채용 1 / B 타대교수 4 / C 유관기관 3 |

- **J01·J02·J10·J14·J19·J24·J29·J33 8인은 실존 심사위원**이며, 축·전공·보직은 `2026_EXPO_심사위원_분석.md`의 [확인] 정보만 사용했다.
- **나머지 42인은 합성 페르소나**다. 실존 교수와 혼동될 이름을 짓지 않았고, 계열·축으로만 식별한다.
- 외부 14인의 시나리오 배분(A 7 : B 4 : C 3)은 심사위원 분석 문서의 확률 추정(A 가장 높음, B·C 중간)을 따랐다.

### 1.2 채점 모델

```
개인 점수 = 합의 기준선(BASE) + 축별 가감(delta) + 개인 엄격도(severity) + 발표력 개인 편차
```

- **합의 기준선**: 리포지터리 실사(§2)에서 확인된 사실만으로 산정한 5영역 baseline.
- **축별 가감**: 각 심사위원의 전공·보직이 걸리는 지점에 명시적 가감. 예 — 황일규 교수는 평가 신뢰도 연구자이므로 준거타당도 0건에 기술성 −4.0.
- **엄격도**: 전 영역 일괄 가감. 실제 패널에서 가장 큰 분산원이다. 외부위원·전공 판정자는 −, 학생 격려 동기가 있는 내부 보직자는 +.
- 계산은 `panel50.py`로 재현 가능하며 원자료는 `panel50.json`에 있다.

### 1.3 이 리포트가 하지 않는 것

| 항목 | 이유 |
|---|---|
| 실제 선정 확률(%) 제시 | 나머지 32팀의 점수 분포를 **모른다**. 커트라인 추정은 근거 없는 숫자가 된다 |
| 실존 심사위원의 성향·인격 추정 | 공개 직무·전공·연구 이력에서만 도출 |
| 외부 심사위원 3인의 실제 신원 | 비공개. 시나리오 확률만 사용 |
| 세부 배점(요소별 소배점) | 미공개. 균등 배분 가정 |

> **신뢰도 총괄**: 패널 구성 비율 [확인] / 실존 8인의 축 [확인] / 리포지터리 실사 결과 [확인·파일 근거] / **개별 점수값은 [추론-중]**. 점수의 절대값이 아니라 **영역 간 격차와 순위**를 읽는 데 쓸 것.

## 4. 냉철한 분석 — 여섯 가지

### 4.1 이 작품은 지금 "기술이 약한 작품"이 아니라 "기술을 증명 못 하는 작품"이다

기술성 표준편차 1.69는 5영역 중 최대다. 같은 작품을 두고 HCI 계열 교수는 13.1점, AI/ML 계열 교수는 6.8점을 준다. **작품이 흔들리는 게 아니라 판정자의 정보량이 흔들린다.**

실사 결과 실체는 상당하다 — numpy 자체 DSP, 270개 테스트, 골든 하네스, 결정성 검증, 3잡 CI. 이건 2학년 팀 작품 기준으로 상위다. 그런데 이 중 **어느 것도 발표에 들어가 있지 않다.** 반대로 밖에서 보이는 간판은 "AI 기반"인데 실제로는 학습 모델이 0개다. 즉 **가진 것은 안 보이고, 없는 것만 보이는 상태**다.

**처방은 기능 추가가 아니라 간판 교체다.** "AI가 평가합니다"를 "규칙 기반 판정 + 임베딩 의미매칭 + LLM 문장 개인화의 3층 구조"로 바꾸면, 정직해지면서 동시에 기술 난도가 올라간다. 팀 자체 감사 문서(`11-ai-weakness-audit.md:87-97`)가 이미 같은 결론에 도달해 있다 — **실행만 안 됐다.**

### 4.2 발표력 20점은 잃는 게 아니라 아직 안 집은 것이다

8.2/20. 5영역 중 최하위이며, 유일하게 **100% 통제 가능한 영역**이다.

여기가 이 리포트에서 가장 중요한 산술이다. 남은 7일 동안:
- 코드를 써서 기술성 10.6 → 12를 만드는 것: **+1.4점, 성공 확률 낮음**
- 대본을 3회 측정해 4분 40초로 확정하는 것: **+3.2점, 성공 확률 100%**

**같은 시간에 두 배 이상의 기대값이다.** 그런데 팀은 어제(7/26)까지도 커밋을 하고 있었다.

### 4.3 외부 3인이 진짜 관문이다 — 그리고 준비가 가장 안 돼 있다

외부 그룹 평균 49.7은 세 그룹 중 최저다. 원인은 단일하다: **선행 서비스 조사 0건**(W10).

가장 낮은 점수를 준 5명 중 4명이 외부위원이며(J42 41.5 / J43 45.0 / J44 45.0 / J41 45.5), 이들의 감점은 전부 같은 뿌리에서 나온다 — "이미 있는 것 아닌가"에 답할 자료가 없다.

**J43(HR·채용 플랫폼 임원)이 단일 최대 변동성이다.** 확률은 낮지만 오면 발표의 생사를 혼자 정한다. 창의성 7.1/20까지 떨어지는데, 조사만 돼 있으면 같은 사람이 트랙 B에서 75.4점을 준다. **반나절 작업으로 ±30점이 움직이는 유일한 항목이다.**

### 4.4 "합격 다음 날"은 살아 있는 축이다 — 단, 시나리오 1개로는 증명이 안 된다

창의성은 상승 여력이 가장 적은 영역(+2.5)이다. 주제가 이미 고정됐기 때문이다.

유리한 점: 평가표의 감점 조항 "보편적인 대중화된 소재는 아닌가"에서 **AI 면접은 직격 대상이지만 입사 후 적응은 아니다.** 작년 EXPO 출품작이 AI 면접이었다는 사실도 오히려 유리하다 — 같은 심사위원들이 "또 그거"라고 느낄 대상이 우리가 아니다.

불리한 점: **시나리오가 1개다.** "직장생활 시뮬레이션"이라 부르는데 실제로는 "신규 서비스 출시 일정 조율" 한 장면뿐이고, 계획서 PDF에 적힌 5종과 어긋난다(W7). 질의응답에서 "몇 가지 상황을 다루나"가 나오면 이 격차가 그대로 드러난다.

> **7일 안의 현실적 해법**: 시나리오를 늘리지 말고 **"에피소드 6개 · 캐릭터 5인 · 체크리스트 기반 판정"으로 정확히 말한다.** 숫자를 부풀리는 순간 회계 전공(황규진)과 창업 실전(황일규)이 동시에 반응한다.

### 4.5 완성가능성은 이미 가진 증거를 안 쓰고 있다

10.5/20. 그런데 평가 문항은 "현재 완성도"가 아니라 **"완성 가능성"**이다. 두 번째 질문("10월까지 완성할 수 있는가")의 근거는 첫 번째 질문의 상태이고, **이 팀은 실제로 돌아가는 시스템을 갖고 있다.** 화면 10개가 배선돼 있고 CI가 3잡을 돌리고 있다.

문제는 이걸 보여줄 **영상이 없다는 것 하나뿐이다.** 라이브 시연이 금지된 심사장에서 영상이 없으면, 돌아간다는 사실을 증명할 수단이 **0**이다.

반대 방향 리스크도 있다. 준비일정 문서가 짚은 대로 **10월 초 "최종 출품 가능 여부 확인"이라는 두 번째 게이트**가 존재한다. 학생처장·부처장이 심사위원인 이유는 여기에 있다 — 10월에 부스 공백이 생기면 그건 운영 사고다. **하드웨어 미확보(W9)는 8/4보다 10월에 더 큰 문제가 된다.**

### 4.6 조용한 지뢰 — 커밋의 96.5%가 1인이다

`git shortlog` main 기준 114커밋 중 108건(94.7%)이 한 사람이고, 나머지 6건이 다른 한 명이다. 전체 브랜치로 넓혀도 172건 중 166건(96.5%)으로 비율은 같다. **발표자로 지정된 곽민우는 커밋 이력에 없다.**

세 곳에서 동시에 터진다:

1. **"팀원별로 무엇을 담당했습니까"** (외부 B 교수 J47, 확률 중간) — 실제 기여 분포를 말하면 도제식 팀 프로젝트라는 P.D.Lab 서사가 흔들린다.
2. **"이 부분은 누가 만들었습니까"** — 발표자가 답 못 하면 발표력 세부항목 4(질의응답)가 직격당한다.
3. **목적 2(P.D.Lab 제도 홍보)** — 학교가 전시하려는 건 작품이 아니라 "팀티칭 기반 도제식 교육이 작동한다"는 증거다. 1인 프로젝트는 그 증거가 되지 못한다.

> **처방**: 코드 기여율을 숨기지 말고 **역할을 재정의**한다. 문서·시나리오 설계·부스 기획·측정 설계·발표는 코드가 아닌 기여다. 실제로 `docs/plan/` 12개 문서와 `poc/docs/` 20여 개 문서가 존재한다. 이걸 역할 분담표로 만들면 답변이 성립한다. **단, 하지 않은 일을 했다고 말하면 안 된다** — 외부 B 교수는 학생 지도가 직업이라 금방 안다.

> ★가장 냉정. 'AI 기반'이라는 작품명과 실제 구현(규칙+임베딩+LLM 문장 다듬기)의 간극을 정확히 짚는다. 간판을 실체에 맞추면 오히려 신뢰를 얻는다.

**J43 · 외부 A-3 HR·채용 플랫폼 임원** (A 45.0 → B 75.4)
> ★단일 최대 변동성. 국내외 유사 서비스를 실명으로 안다. 팀이 선행 서비스 조사를 안 한 상태에서 이름을 대면 창의성·작품성·발표력이 동시에 붕괴. 반대로 '입사 첫 3개월'은 시장에서 실제로 비어 있는 구간이라 조사만 돼 있으면 최강의 우군.

**J44 · 외부 B 타대 교수 (AI/SW)** (A 45.0 → B 73.3)
> '무엇으로 측정했고 비교군은 무엇인가'. 준거타당도 0건이 가장 정확하게 저격당하는 자리.

**J45 · 외부 B 타대 교수 (교육공학)** (A 51.5 → B 79.7)
> '연습하면 실제로 늘었나'. Study C(학습효과)가 설계서에만 있고 실행 0건.

**J46 · 외부 B 타대 교수 (HCI)** (A 52.5 → B 81.1)
> 취준생 인터뷰·사용성 테스트 기록이 없다. 문제 정의의 근거가 팀의 추정인지 데이터인지를 묻는다.

**J47 · 외부 B 타대 교수 (학생지도)** (A 50.0 → B 78.9)
> ★조용한 지뢰. 커밋 172건 중 166건이 1인에게 집중돼 있다. '팀원별로 무엇을 했나'에서 P.D.Lab 도제 서사 자체가 무너질 수 있다.

**J48 · 외부 C 산업진흥기관 인사** (A 59.5 → B 85.3)
> 청년 취업은 정책 우선순위. '본교 도입 → 타 전문대 확산' 한 줄이 그대로 득점.

**J49 · 외부 C 창업지원기관 심사역** (A 54.5 → B 82.0)
> '누가 돈을 내는가' 한 문장. B2C 취준생이 아니라 B2B 대학·기업 온보딩이 현실적.

**J50 · 외부 C 지자체 청년정책 담당** (A 58.5 → B 84.8)
> 조기퇴사·직장 적응 실패라는 사회 문제 정면. 로봇팔은 이 사람에게 서사를 못 주지만 우리는 준다.

## 10. 마지막 한 문단

이 팀은 **작품이 부족해서 위험한 게 아니라, 가진 것을 증명할 자료가 하나도 없어서 위험하다.** 270개 테스트도, 자체 구현한 음성 DSP도, 파기 로직까지 갖춘 개인정보 설계도, 심사장에서는 존재하지 않는 것과 같다. 반대로 "AI 기반"이라는 이름표는 실체보다 크게 걸려 있어서, 아는 사람 앞에서는 감점 요인이 된다.
