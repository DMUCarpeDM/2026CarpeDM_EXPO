# 시연 전 15분 점검 체크리스트 (전시 당일 아침)

## 1. 기기 (5분)
- [ ] 미러 PC 전원 · 세로 1080×1920 해상도 확인
- [ ] 웹캠 연결 — 미러 상단 중앙, 렌즈 청소
- [ ] 마이크 입력 레벨 확인 (시스템 설정에서 말해보고 미터 확인)
- [ ] 스피커 볼륨 — 부스 소음 기준으로 TTS가 1m에서 또렷하게
- [ ] 터치 동작 확인 (모서리 4곳 + 중앙)

## 2. 소프트웨어 (5분)
- [ ] 백엔드 기동: `cd backend && ./.venv/bin/uvicorn app.main:app --port 8000`
- [ ] 프론트 기동: `cd frontend && npm run dev -- --host` (또는 빌드 서빙)
- [ ] **(권장 필수) Ollama 기동 확인**: `ollama list`에 exaone3.5:2.4b(리액션 개인화)와
      nomic-embed-text(의미 매칭) — 없어도 폴백으로 완주하지만 **Response 품질이 크게
      다르다**. 임베딩이 없으면 패러프레이즈 답변("고객께 양해를 구하겠습니다")이
      키워드 미스로 '누락' 판정돼 억울한 교정 후속이 나갈 수 있다. 전시 PC엔 반드시 설치
- [ ] **(Ollama 있으면 필수) 의미 매칭 임계값 보정**: `python scripts/calibrate_semantic.py`
      — 임계 0.66은 개발 맥 기준이라 전시 PC에서 반드시 재보정
- [ ] 오프라인 자산 확인: `npm run setup-offline` 완료 여부
      (전시장 인터넷 불안정 대비 — MediaPipe wasm/모델 로컬 서빙)
- [ ] `VITE_PUBLIC_ORIGIN`을 미러 PC의 LAN 주소로 설정했는지
      (QR이 localhost면 폰에서 안 열린다) — 폰으로 QR 실제 스캔 1회
- [ ] Chrome 전체화면(F11) + `/kiosk` 진입 → 미러 모드 자동 활성

## 2.5 측정 보정 (최초 설치 시 1회)
- [ ] **떨림 임계값 육성 보정**: 안정된 목소리로 1턴 진행 → 리포트에 "피치 흔들림"
      행이 뜨지 않아야 정상. 뜨면 `voice_fit.py`의 TREMOR_*_FLOOR 상향
      (현재 값은 합성 신호 보정치 — 실제 육성 검증 필요)
- [ ] **쉼 위치 관용 확인**: 문장을 끝낸 뒤("~하겠습니다.") 일부러 1.5초 쉬고
      다음 문장 시작 × 2회 → 침묵 감점·머뭇거림 지적이 없어야 정상.
      반대로 문장 중간에 1.5초 멈추면 "멈칫" 인용이 떠야 정상 (Vosk 정렬 필요)
- [ ] **홍채 보상 방향 확인**: 고개를 30° 돌린 채 눈으로 카메라 응시 → 라이브
      오라 '시선'이 정면 유지로 표시되면 보상 정상 작동
- [ ] **수직 홍채 확인**: 고개를 고정한 채 눈만 아래로 3초 → 라이브 오라 '아래'
      이탈 표시. 실눈을 뜨고 정면 응시 → 이탈로 오인하지 않아야 정상(구제 동작).
      오탐 시 `useNonverbal.ts`의 EYE_Y_DELTA(0.25) 상향
- [ ] **얼굴 다인 가드 확인**: 답변 중 다른 사람이 카메라 앞으로 끼어들기 →
      체험 정상 완주 + 시선·표정 지표에 튀는 값이 없어야 정상
- [ ] **시선 히트맵 좌우 방향 확인**: 1턴 동안 의도적으로 왼쪽을 오래 응시 →
      웹 리포트 Eye 카드 히트맵에서 달아오른 열을 기록. 부호가 확인되면
      `report.py` `_gaze_map`의 '옆' 중화 코멘트를 좌/우 명시로 승격 가능
- [ ] **습관 감지 확인**: 팔짱 5초·턱 괴기 5초 → 리포트 무의식 습관 카드 등장 확인
- [ ] **깜빡임 기저선 확인**: 브리핑을 평소처럼 보고 안정된 1턴 진행 → 리포트에
      깜빡임 지적이 없어야 정상. 뜨면 `report.py`의 급증 배율(1.6×)·바닥(20회) 상향
      (현재 값은 문헌 기반 추정치 — 실인물 보정 필요)
- [ ] **제스처 판정 확인**: 자연스럽게 손짓 섞어 1턴 → 경직/과다 카드 없어야 정상.
      차렷 자세로 1턴 → 경직 카드 등장 확인. 오탐 시 `report.py` 활동 임계
      (0.05/0.7)·에너지(0.5m/s) 조정
- [ ] **체중 이동 확인**: 서서 좌우로 체중 옮기며 1턴 → 무게중심 카드 등장.
      안 뜨면 `hip_sway` 임계(0.1) 하향, 평범하게 서 있는데 뜨면 상향
- [ ] **3D 기울기 확인**: 몸을 45° 비틀고 어깨는 수평 유지한 채 1턴 → 어깨 기울기
      지적이 없어야 정상 (2D 폴백이면 오판 가능 — 리포트 world_ratio 확인)
- [ ] **다인 가드 확인**: 답변 중 뒤로 사람이 지나가게 하기 → 체험 정상 완주 +
      자세 지표에 튀는 값이 없어야 정상
- [ ] **끄덕임 감지 확인**: 상대가 말하는 동안 또렷하게 3번 끄덕이기 → 리포트에
      경청 카드 등장. 가만히 들었는데 뜨면 `useNonverbal.ts`의 NOD_MIN_SWING(0.04) 상향
- [ ] **듣기 리닝 확인**: 브리핑 위치에서 상체만 앞으로 기울여 듣기 → 경청 카드,
      한 발 물러서 듣기 → 물러남 관찰이 각각 뜨는지. 걸어서 위치가 바뀌는 동선이면
      리닝 오인 가능 — 바닥 발자국 스티커로 서는 위치 고정 (운영 대책)
- [ ] **진정성 미소 판정 확인**: 1턴을 눈까지 활짝 웃으며 진행 → 습관 카드가
      "입꼬리만…"으로 뜨면 오탐이므로 `useNonverbal.ts`의 eyeSquint 임계(0.35) 하향.
      반대로 무표정에서 입꼬리만 올린 채 1턴 → "눈까지 함께 웃는" 칭찬이 뜨면 상향
      (현재 값은 문헌 기반 추정치 — 실인물 보정 필요)
- [ ] **샘플링 부하 실측 (측정 정밀도 결정)**: 운영자 패널 → 측정 정밀도를 10Hz로
      올리고 5분 세션 완주. 작업관리자에서 CPU가 지속 90%↑거나 리액션 TTS가 끊기면
      5Hz(기본)로 복귀, 여유가 있으면 10Hz 유지 → 깜빡임·끄덕임 과소집계가 줄어든다.
      MediaPipe 2종 + Ollama exaone 동시 구동 기준으로 판단 (전시 PC 실사양 의존)
- [ ] **안경 착용자 검증**: 안경 쓴 팀원으로 1턴 → 시선(홍채)·표정(blendshape)이
      과도하게 흔들리거나 미측정되지 않는지. 렌즈 반사가 심하면 부스 조명 각도 조정
      (LED를 얼굴 정면이 아닌 측상방으로) — 실인물 다양성 검증
- [ ] **마이크 품질 = 리포트 품질 확인**: 구즈넥 마이크로 1턴 vs 노트북 내장으로 1턴 →
      리포트의 "쉼 위치/떨림/성량 인용" 근거가 구즈넥에서 더 풍부하게 나오는지.
      오디오가 얇으면 Voice가 말속도 근사 하나로 줄어든다 (마이크가 AI 정확도 예산)

## 3. 리허설 주행 (5분)
- [ ] 대기 화면에서 다가가기 → 거울이 깨어나는지 (안 되면 터치 폴백 확인)
- [ ] 온보딩 3탭 → 브리핑에서 얼굴 링 활성(카메라 인식) 확인
- [ ] 1턴 음성 답변 → 상대의 **리액션**이 먼저 재생되는지
- [ ] **잘한 답에도 대화가 이어지는지**: 모범 답변 후 장면이 바로 안 끝나고
      심화(또는 기본 난이도 세션당 1회 압박) 질문이 나오는지 (상황당 2턴 기본)
- [ ] 라이브 오라가 시선 이탈에 반응하는지 (고개를 옆으로 돌려본다)
- [ ] 리포트: 하루의 결말 → 총점 → 4-Fit → **심층 분석에 '압박 내성' 카드가
      뜨는지**(기본 난이도에서도 압박 1턴 덕에 성립) → QR까지 탭 진행
- [ ] 90초 방치 → 대기 화면 자동 복귀
- [ ] 운영자 제스처(우상단 3초 롱프레스) → 패널 열림

## 문제 발생 시
| 증상 | 조치 |
|---|---|
| 음성 인식 안 됨 | Chrome인지 확인 → 오프라인이면 Vosk 폴백이 자동 동작 (정지 후 전달) |
| 카메라 거부됨 | 주소창 권한 아이콘 → 허용 → 새로고침. 체험은 카메라 없이도 진행됨 |
| 화면이 웹 모드로 보임 | `/kiosk` 재진입 (미러 모드 재활성) |
| 다음 체험자 준비 | 운영자 패널 → 세션 초기화 |
| 분석 멈춤 | 리포트 화면의 "분석 다시 시도" 또는 운영자 패널 → 초기화 |
