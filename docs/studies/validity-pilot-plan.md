## 2. 팀 결정 사항 — 권장 기본값 (설계서 §9)

바로 진행할 수 있게 기본값을 제안한다. 다르면 팀이 덮어쓴다.

1. **평정자 확보** → 취업지원센터 컨설턴트 1인 + 면접/발표 코칭 강사 1인을 1순위. **불가 시** 1인 + 팀 외부인
   자기평정 1인으로 축소하고 "평정자 신뢰도 한계"를 명시(ICC 계산은 2인 이상 필요).
2. **루브릭 소유자** → 기획/서사 트랙 1인이 [`expert-rating-form.md`](expert-rating-form.md) 검수·인쇄·캘리브레이션 진행.
3. **표본 공급** → 동아리 내부만이면 **범위 제한**으로 상관이 축소돼 보인다. **최소 절반은 외부**(타 학과·지인)로,
   실기기 주간 방문자를 우선 활용. 배경(경력 유무)을 사전 설문으로 층화해 `group` 열을 채운다.
4. **사전 등록** → 아래 §4 성공 기준을 **지금 고정**해 사후 해석 편향을 차단(이 문서 커밋이 곧 사전등록).

## 3. 블라인드 짝짓기 프로토콜 (무결성 핵심)

평정자에게 **4-Fit 점수가 새면 검증이 무효**다. 아래를 지킨다:

1. 운영자가 `/admin/export.csv`를 내려받는다 → `session_id`·4-Fit 점수 포함(이미 익명, `client_key` 제외).
   이 파일은 **분석자만** 보관한다.
2. 각 세션의 **응답 자료**(리포트/DB의 `response_text`, 필요시 녹취)를 `session_id`만 라벨로,
   **무작위 순서**로 정리한다. 평정자에게는 이 응답 자료만 전달 — **점수·신원·회차는 가린다**.
3. 평정자가 [채점 폼](expert-rating-form.md)으로 매겨 `ratings.csv`를 만든다(`session_id` 기준).
4. 분석자가 병합·분석:
   ```bash
   backend/.venv/bin/python docs/studies/analyze_validity.py \
       --fit export.csv --ratings ratings.csv --out results.csv
   ```
   (`analyze_validity.py`는 `session_id`로 병합하고 평정자 평균을 4-Fit과 짝짓는다.)

## 4. 성공 기준 — 사전 등록 (사후 편향 차단)

- **주력(H1)**: Response-Fit·Voice-Fit ↔ 대응 전문가 구성 **Spearman ρ ≥ 0.4** & BH 보정 후 **95% CI 하한 > 0**
  → *"예비 지지"*. 그 미만이면 **정직하게 "추가 검증 필요/관찰 강등"** 으로 서술한다(숨기지 않는다).
- **평정자 신뢰도**: **ICC(2,k) ≥ 0.7** 이어야 상관을 해석한다. 미달이면 캘리브레이션 재실시가 우선.
- **기지-집단**: 경험자 총점 > 초심자, **Cliff's δ > 0**(pilot n에서는 방향성 확인 수준).
- **제외(사전 등록)**: Eye/Posture는 문화·신경다양성 교란으로 **점수 타당성 검증 대상이 아니다** —
  '관찰 지표 해석 타당성'으로만 다룬다(코드의 '관찰 격리' 원칙을 데이터로 뒷받침).

## 6. 참가자 동의 (연구 이용 — 기존 동의 게이트 확장)

> 본 체험의 익명 응답이 **측정 타당성 연구**에 사용될 수 있음에 동의합니다. 영상 원본은 저장되지 않으며
> (집계 지표만), 이름·연락처 등 식별 정보는 수집하지 않습니다. 동의는 언제든 철회할 수 있습니다.

미성년·비참여 배경 인물 촬영은 배제하고, 저성과 참가자에게는 디브리핑을 제공한다(설계서 §5·§6).

## 7. 심사장에서의 사용법

pilot이 중간 상관을 보이면: **"예비 검증에서 전문가 평가와 Response-Fit이 중간~강한 상관(ρ=△),
표본을 확대 중"**. 약한 Fit은 숨기지 말고 **"관찰 지표로 정직하게 프레이밍"** — 이 정직함 자체가
완성도·신뢰의 신호다. "숫자의 근거가 뭐냐"는 질문에 **"손으로 튜닝했다"가 아니라 "전문가와 검증했다"**
로 답할 수 있는 것 — 이것이 로봇·챗봇 팀이 못 대는 대상급 답변이다.
