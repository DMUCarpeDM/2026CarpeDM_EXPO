# 소개 영상 반복 및 중앙 원거리 추적

- 밝은 조명·연청바지 소개 영상으로 교체하고 HTML video loop로 영상과 음성을 반복한다. 체험 시작 클릭 시 즉시 정지한다.
- 카메라는 1920×1080, 30fps를 ideal로 요청한다. 지원하지 않는 카메라는 브라우저가 가능한 해상도를 선택한다.
- MediaPipe Pose는 최대 두 후보에서 중앙 인물을 고른다. 인물이 작거나 미검출이면 중앙 65% 영역을 확대해 재검출하며, 2D 좌표는 원본 영상으로 복원하고 3D 월드 좌표는 해당 인물의 결과와 함께 유지한다. 손 미검출도 같은 영역에서 재검출한다.
- 얼굴 미검출 시 중앙 확대를 사용하며, 여러 얼굴이 비슷하게 중앙에 있으면 표정 측정을 보류한다.
- 기존 5% 어깨 폭 기준을 2.5% 및 최소 24px로 변경했다. 어깨 신뢰도 조건은 유지한다.
- 실제 MediaPipe/Chrome 테스트에서 인물 높이 85%, 45%, 30% 거리 모사 입력을 검출했다. 45%·30% 입력의 복원 어깨 폭은 약 4.1%·2.7%로 기존 5% 기준에서 제외되던 값이다. 실제 카메라의 미터 단위 거리는 현장 검증이 필요하다.
- 직장 시나리오 캐릭터 데이터는 모두 여성으로 지정한다. 현재 소비·저축 시나리오 고정 및 5턴은 유지한다.
- 준비 녹음 생성 스크립트의 입력을 실제 시연용 4개 첫 대사로 변경했다. 현재 API 키의 payment_required 오류로 새 녹음 생성은 사용자 요청에 따라 보류했다. 기존 녹음 manifest는 변경하지 않는다.
