# 미러 평가 수정 및 재시험

## 수정한 4개 문제

1. 관련 답변의 누락 감점 -2 → -0.5. 완전 이탈 첫 -1, 반복 -2는 유지. 모든 맥락 정책에서 한 항목의 누락 감점이 이탈보다 커지지 않는지 검사했다.
2. 자유 대화의 내부 체크리스트를 명시적으로 질문한 항목으로 넘기지 않는다. 따라서 숨은 목표 미충족을 감점하지 않는다. 고정 질문의 누락 판정은 질문 원문 인용, 알려진 목표 ID, 확신도 0.9 이상을 요구한다. 의미 해석 자체의 정확성은 LLM 한계가 남는다.
3. 개선점은 improvements만 사용하며 headline으로 대체하지 않는다. 잘한 점·개선점 배열을 모두 표시한다. 근거가 없으면 없음으로 표시하고 빈 코칭 카드는 숨긴다.
4. 근거를 확인한 분석 완료는 가감점 사건이 없어도 중립 기준점 75를 반환한다. 불확실·실패는 null. 실제 LLM의 빈 JSON은 완료로 보지 않고 전체 답변 인용과 completed 상태를 요구한다.

새 채점 버전은 interaction-score-v4다. 기존 저장 보고서는 다시 쓰지 않았다.
