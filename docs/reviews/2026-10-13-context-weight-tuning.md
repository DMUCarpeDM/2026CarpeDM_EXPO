## 시나리오 선택과 AI 상황 판단은 다르다

코드는 준비된 시나리오 3개 중 **1개를 무작위 선택**하고, 같은 장면에서 사용자 답변 5회를 진행한다. AI가 시나리오를 선택하는 구조는 아니다.

AI는 현재 상대 대사, 시나리오 배경, 같은 장면·인물의 최근 대화 최대 6회, 제출된 답변을 읽고 **지금 필요한 대화의 맥락**을 분류한다. 실시간 관찰에서는 아직 확정되지 않은 사용자 답변을 제외한다. 따라서 새 답변의 내용에 따라 실시간 참고 점수와 최종 판단이 달라질 수 있다.

실제 Vertex AI로 첫 대사만 검사한 결과:

| 준비된 시나리오 | 이번 검사에서 분류된 시작 상황 | 대화 중 가능한 변화 |
|---|---|---|
| 업무 자료를 받은 첫날 | 업무 설명 | 구체적인 도움 요청, 이해한 내용 확인 |
| 자료에서 발견된 수치 오류 | 갈등·오류 대응 | 오류 해결 후 수정 절차를 정리하는 업무 설명 |
| 퇴근 직전 들어온 추가 업무 | 갈등·오류 대응 | 압박이 해소된 뒤 일정·우선순위 협의 |

분류 결과를 시나리오 전체에 고정하지 않는다. 표의 시작 상황은 이번 검사 결과이며 모델 판단의 보장값이 아니다.

## 상황별 배율

**기본 사건 점수 × 아래 배율 = 해당 사건의 가감점**이다. 상황을 선택했다는 이유만으로 가점이나 감점이 생기지 않는다. 영역 점수의 종합 평균 비율과는 별개의 값이다.

| AI 상황 | 판단 기준 | 응답 | 목소리¹ | 표정² | 자세 |
|---|---|---:|---:|---:|---:|
| `neutral` 일반 대화 | 일반 인사·확인 또는 불명확한 상황 | 1.00 | 1.00 | 1.00 | 1.00 |
| `serious` 갈등·오류 대응 | 명확한 항의, 실수 지적, 해결되지 않은 갈등, 안전 문제 | 1.10 | 1.05 | 1.00 | 1.00 |
| `supportive` 지원 요청 | 위로, 구체적인 도움이나 지원을 주고받는 상황 | 1.05 | 1.05 | 0.75 | 0.85 |
| `technical` 업무 설명 | 절차 설명, 일정·우선순위·업무 범위 조율 | 1.10 | 1.00 | 0.75 | 0.75 |
| `casual` 가벼운 대화 | 상대도 함께 이어가는 가벼운 잡담 | 1.00 | 0.90 | 0.75 | 0.75 |

1. 현재 `voice-measure-v2`는 음량·속도·멈춤 측정값만 제공한다. 채점 기준 검증 전이므로 목소리 점수는 `null`이며 배율만으로 점수를 만들지 않는다. 목소리 배율은 점수 사건을 반환하는 기존 음성 분석 경로에만 적용된다.
2. 현재 표정 점수 사건은 심각한 상황의 지속된 미소 신호뿐이다. 나머지 상황에 표정 배율이 있어도 새 표정 감점을 만들지 않는다. 검증 전 모델의 참고 점수이며 실제 감정이나 태도를 확정하지 않는다.

기존 serious 배율은 응답 1.2 / 목소리 1.2 / 표정 1.3 / 자세 1.2였다. 표정을 가장 크게 증폭하던 구성을 없애고, 응답 내용을 중심으로 최대 1.1배만 조절한다. 업무 설명에서는 자세의 영향도 낮췄다.

## 기본 가감점과 누적 제한

| 관찰된 근거 | 적용 정책 |
|---|---|
| 구체적으로 관련 있는 답변 또는 목표 충족 | 기본 +1 × 응답 배율. 단순 수락은 가점 없음 |
| 질문에서 명시적으로 요구한 항목의 누락 | 기본 −0.5 × 응답 배율. 자유 대화의 숨은 체크리스트는 누락 감점하지 않음 |
| 답변 전체가 완전히 무관함 | 첫 −1, 반복 −2. 상황 배율로 할인하거나 증폭하지 않음 |
| 근거가 확인된 설명 없는 모순 | 사실당 −1, 최대 −3. 같은 사실 중복 제외, 해당 답변의 응답 가점 제외 |
| 자세 신호 | 사건당 기본 −1 × 자세 배율. 여러 신호를 합쳐 답변당 최대 −2, 세션 최대 −6 |
| 심각한 대화 중 지속된 미소 신호 | 유효 표본 4개 이상·지속 3초 이상일 때 −0.5. 답변당 최대 −0.5, 세션 최대 −1.5 |
| 미측정 또는 응답 분석 보류 | 해당 영역 점수 `null`. 다른 턴의 유효한 측정 근거가 있으면 그 근거만 누적 |

측정된 영역의 기준점은 75다. 기존 일반 영역 상한인 가점 +8, 감점 −15와 규칙당 반복 3회 제한은 유지하며 자세·표정에는 위의 더 작은 상한을 추가한다. 이탈은 반복 3회 제한의 예외다. 모순 최대 −3은 일반 응답 감점 상한과 별도로 적용된다. 면접·카페의 별도 응답 채점 정책은 유지한다.

예를 들어 serious에서 관련 답변 가점은 +1.1, 명시 항목 누락은 −0.55다. 심각한 상황의 미소 1건은 기존 −1.3에서 −0.5가 된다. 자세 신호 5개가 동시에 검출되더라도 합산 −2까지만 적용하며, 나머지 관찰 기록은 점수 0으로 남긴다.

## 분류 및 점수 적용 규칙

- 사용자 혼자 무관한 농담을 했다고 업무·오류 대응 상황을 잡담으로 바꾸지 않도록 프롬프트를 보완했다.
- 정당한 업무 거절, 관련 확인 질문, 일정 협의 자체는 갈등으로 보지 않는다.
- 이미 해결된 오류를 과거 배경만 보고 계속 심각한 상황으로 유지하지 않는다.
- 분류는 알려진 종류, 모델이 반환한 확신도 0.9 이상, 대화 원문에 실제 존재하는 인용을 요구한다. 확신도는 모델의 자기 보고값이며 실측 정확도가 아니다.
- 실패·불확실·알 수 없는 종류는 기본 배율을 사용한다. 미소 감점은 serious의 분류가 완료됐을 때만 허용한다.
- AI와 저장된 임의 숫자 대신 서버의 상황별 배율표로 점수를 계산한다. 정책 버전을 올려 이후 계산에 적용하며 저장된 완료 보고서를 일괄 수정하지 않았다.
- 종합은 점수가 있는 영역의 기존 평균을 유지한다. 검증 전 표정 참고 점수도 현재 종합 계산에 포함되므로 현장 검증이 필요하다.

## 어디를 수정하면 되는가

- 시나리오 3개와 설명: `poc/backend/app/seed/workplace-exhibition.json`
- 상황 종류·분류 프롬프트·배율: `poc/backend/app/services/context_scoring.py`의 `SYSTEM`, `POLICIES`
- 기본 사건 점수·누적 상한: `poc/backend/app/services/interaction_scoring.py`의 `POINTS`, `NONVERBAL_PENALTY_LIMITS`
- 실제 응답의 관련성·목표·모순 근거 판단: `poc/backend/app/services/response_judgment.py`

새 상황 종류를 추가할 때는 분류 프롬프트와 배율표뿐 아니라 결과 화면의 `mvp/src/features/smart-mirror/lib/mirrorReport.js`에 표시 이름도 추가해야 한다.

## 검증 결과

- 백엔드 관련 테스트 **141개 통과**. 5가지 배율, 이탈·모순의 고정 감점, 자세의 답변별/세션별 상한, 표정 누적 상한, 중복 관찰 제외, 불확실 분류, 실제 API의 관찰→답변→결과 점수, 음성 점수 보류를 확인했다.
- 4개 영역 결과 API: 응답 **76.1**, 자세 **74.0**, 표정 **74.5**(참고), 목소리 **null**. 종합 **74.9**. 잘한 점과 개선점도 유지됐다.
- 실제 Vertex AI에 가상 문구 **11건**을 전송했다. 첫 대사 3건을 확인하고, 기대 분류를 정한 8건은 모두 일치했다. 오류 해결 후 전환·무관한 농담·정당한 일정 협의도 포함한다.
- 테스트 근거: `.omo/evidence/context-weight-review/live-context-results.json`. 실제 사용자 녹음이나 카메라 원본은 보내지 않았다.
- 이번 배율은 과도한 변동을 줄이는 보수적인 운영 조정이다. 사람의 정답 평가와 비교해 통계적으로 보정한 가중치는 아니다. 위 11건만으로 전체 분류 정확도를 입증하지 않는다.
