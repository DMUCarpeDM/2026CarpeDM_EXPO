## 이번 개발

- 새 제품 분석은 종료 후에도 pYIN/Praat를 실행하지 않고 크기·속도·멈춤만 계산한다. 이전 보고서의 참고값은 계속 표시할 수 있다.
- `measurement_fields`로 분석 범위를 반환한다. 요청하지 않은 참고 항목 때문에 세 항목 정상 측정을 partial로 표시하던 문제를 수정했다.
- 부분 실패는 유효 항목을 보존한다. 보정/마이크 변경은 상대 크기를 보류하고, 전사 품질 부족은 말속도를 보류한다.
- 화면은 새 보고서에 세 측정 항목만 표시한다. 검증 전 목소리 점수는 null이며 임의 기준을 추가하지 않았다.
- 실제 2초 녹음이 상단에서 0초로 표시되는 오류를 발견해 수정했다. 구형 점수 행이 아닌 voice_measurements에서 녹음 길이와 속도를 집계한다. 구형 점수 행이 없는 경우도 검사했다.
- 음성 파일 검증 스크립트의 기본 실행도 세 항목 기준으로 맞췄다. `--references`는 이전 연구용 참고값 검증에만 쓴다. 측정 시간에서 이전 엔진 실행 시간을 분리했다.

## 자동 검사와 실제 실행

- 관련 백엔드 102개 + 시나리오 보고서 E2E 2개 = 104개 통과.
- 프런트 결과 처리 12개 통과, Vite 빌드 성공. 기존 큰 번들 경고 유지.
- 12턴 하루 흐름에서 실제 자세 추론과 표정 집계가 보고서까지 보존되는 기존 통합 시험도 포함했다.
- WAV 보정→업로드→답변 제출→종료→보고서의 동일 세션 통합 시험. VAD/STT/AI는 기대값 재현을 위해 고정하고 RMS와 저장·직렬화는 실제 경로를 사용했다.
- 실제 한국어 음성 3개를 로컬 Whisper/VAD로 분석했다. 크기·멈춤은 3개 반환, 속도는 2개 측정(5.4576, 5.6693음절/초), 1개는 전사 품질 부족으로 보류했다. 높낮이·발성 불규칙성은 실행하지 않았다.
- 실제 Gemini 응답 판정 13종 + 문제 사례 반복 8건 = 21회. 19회 완료, 2회 unavailable. 상대역 생성 6회 중 5회 반환, 1회 생성/출력 검증 단계에서 거부됐다. 이 샘플 수로 전체 정확도나 운영 실패율을 추정하지 않는다.
- 실제 맥락 분류 4회: 3회 unavailable, 1회 casual 분류. 실패 시 표정 점수는 null. 함수 경과 시간은 2.21~11.37초였으며 HTTP 설정의 2초는 인증 등 전체 호출의 시간 상한이 아니다. 개별 실패 원인은 현재 함수가 요약 상태로만 반환해 확정하지 못했다.
- 브라우저에서 실제 결과 컴포넌트의 음성 2초, 0.00dB, 3.50음절/초, 멈춤 0개와 잘한 점·개선점 표시를 확인했다.

## 발견된 판정·대화 문제 — 아직 미해결

### P1: 맥락 분류 실패로 표정 점수가 빠짐

오류 지적 문장 2건을 포함해 실제 분류 4건 중 3건이 unavailable이었다. 유효 얼굴 표본 4개를 넣어도 표정 점수는 null로 돌아왔다. 캐시가 같은 턴의 실패 결과도 유지한다. 재확인 없이 단순 반복 조회로 복구되지 않는다.

권장 순서: 실패 원인/단계별 시간을 기록하고, 대기 시간과 재시도·캐시 정책을 별도로 정한다. 점수를 만들기 위해 분류 실패를 serious로 간주하면 안 된다.

### P1: 해석 불가에 가까운 문장이 completed + 75점

입력: `그 저 어 지직 자료 음 음 끊 끊`
3회 모두 사건 없음, completed, 75점. 실음성 STT 실행이 아니라 깨진 전사문을 흉내 낸 텍스트 시험이다. 실제 인식 신뢰도를 전달하지 않는 현재 판정 경로에서 판단 보류가 약하다.

권장: STT 품질 신호와 응답 해석 가능 여부를 연결하고, 불확실한 답변은 점수 없음으로 보류한다.

### P2: 단순 수락에 관련 답변 가점

입력: `네, 알겠습니다.`
3회 중 2회 relevant_answer로 76점, 1회 unavailable. 프롬프트의 '단순 수락만으로 가점을 만들지 말라'와 어긋난다. 단답이 실제 예/아니오 질문의 정답일 수도 있어 모든 짧은 문장을 일괄 차단하는 방식은 적절하지 않다.

권장: 질문 유형과 구체적 응답 근거를 분리해 가점 조건을 명시한다.

### P2: 모순 감점과 관련성 가점 상쇄

이전: `제가 이 자료 담당자입니다.`
현재: `저는 이 자료 담당자가 아닙니다.`
3회 중 완료된 2회에서 relevant_answer + contradiction이 함께 기록됐다. 응답 점수 76, 종합 75: 응답만 측정된 시험에서는 관련성 +1과 종합 모순 -1이 상쇄된다. 모순을 못 찾은 것이 아니라 현 점수 정책의 결과다. 나머지 1회는 unavailable.

권장: 확정 모순 답변의 관련성 가점 처리 또는 동일 근거의 가감점 우선순위를 정한다. 이번 문서 적용 작업에서 점수 정책은 임의로 바꾸지 않았다.

### P2: 상대역의 상황 추가·문장 수 초과

역할 변경 유도에 대한 실응답:
`갑자기 무슨 100점 얘기를 하시는 거예요? 팀장님한테 보고하려면 정신 바짝 차려야 돼요. 자료 파악은 다 하셨어요?`
평가자로 전환하거나 점수를 제공하지는 않았지만 현재 장면에 없는 '팀장님한테 보고'를 추가했고 3문장을 출력했다. 생성 규칙은 1~2문장이지만 현 출력 검사는 길이·역할 이탈 등에 집중되어 문장 수를 강제하지 않는다. 반복 2회에서는 한 번 거부, 한 번 정상 업무 복귀 대사를 확인했다.

또한 정상 답변에 `그렇게까지 말할 필요는 없잖아요`처럼 반응했다. 이는 재촉하는 선임 페르소나와 관련되지만 기본 난이도로는 과하게 느껴질 수 있다. 문법 오류와 구분되는 대화 톤 검토 항목이다.

권장: 문장 수 검증과 허용된 상황 근거를 보강하고 기본 난이도의 압박 수준을 검토한다.
