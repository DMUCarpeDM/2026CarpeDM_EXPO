# 상황과 행동을 함께 반영하는 감점

2026-10-13 · 상황 정책 `dialogue-context-v3` · 점수 정책 `interaction-score-v7`

이 문서는 v7 변경 기록이다. 현재 응답·자세 배율과 자료 확인 요청의 감점 제외 조건은 [v8 재조정 문서](2026-10-13-context-behavior-refinement.md)를 따른다. 아래 미소·성량 측정 조건과 상한은 유지한다.

## 이번 변경의 의미

AI가 현재 대화 맥락을 분류하고, 코드가 실제로 관찰된 행동과 결합해 감점한다. 영역 전체를 2배 감점하는 방식이 아니다. **기본 사건 감점 × 해당 상황의 행동 배율**을 적용한다. 총점을 −2배 하는 것이 아니며, 영역 배율과 행동 배율을 중복해서 곱하지 않는다.

| 상황 | 확인된 행동 | 기본 감점 | 행동 배율 | 실제 감점 |
|---|---|---:|---:|---:|
| 심각한 대화·갈등·오류 대응 | 지속된 미소 신호 | −0.5 | 2배 | −1 |
| 심각한 대화·갈등·오류 대응 | 자신의 기준 음성보다 크게 측정된 성량 | −1 | 2배 | −2 |
| 심각한 대화·갈등·오류 대응 | 답변 전체가 완전히 무관함 | 첫 −1 / 반복 −2 | 2배 | 첫 −2 / 반복 −4 |
| 도움·지원 대화 | 자신의 기준 음성보다 크게 측정된 성량 | −1 | 1.5배 | −1.5 |
| 그 밖의 대화 | 미소·성량 변화 | — | — | 이 두 행동은 감점하지 않음 |

직접 관련된 확인 질문·이유 있는 거절은 완전 이탈이 아니다. 단순 수락에는 가점을 주지 않는다. 자세의 작은 변화나 해당 상황의 정상적인 답변까지 2배 처리하지 않는다. 긍정적 답변과 그 밖의 규칙에는 이전 영역별 배율을 유지한다.

## 웃음과 성량을 판단하는 근거

**미소:** 기존 얼굴 모델의 미소 신호가 3초 이상 지속되고 유효 표본이 4개 이상이며 현재 맥락 분류가 serious일 때만 반영한다. 소리로 웃음을 검출하는 기능은 아니다. 잠깐 웃거나 분류가 불확실하면 이 감점은 발생하지 않는다. 미소만 보고 조롱·불성실 같은 의도를 확정하지 않는다.

**성량:** ‘높은 목소리’를 절대 음높이(Hz)가 아닌, 같은 사람의 기준 녹음보다 커진 성량으로 구현했다. 다음 조건을 모두 요구한다.

- 같은 입력 설정에서 기준 음성 보정이 성공하고, 현재 답변의 음량도 측정됨.
- 발화 구간의 RMS 중앙값이 기준 대비 **+6dB 이상**. 아주 짧은 소리만으로 판정하지 않도록 중앙값을 사용한다.
- 실제 발화 구간이 **합계 3초 이상**.
- 현재 녹음에서 제외 구간을 뺀 비발화 구간이 **0.5초 이상**이고, 그 구간과 비교한 신호 대 잡음비가 **10dB 이상**.
- 클리핑 없음. 다른 턴의 측정값, 보정 실패, 마이크 설정 변경, 불확실한 맥락, 비정상 숫자는 감점에서 제외.

이 기준은 연습 서비스의 검증 전 운영 규칙이다. +6dB를 보편적인 무례함·분노 기준으로 해석하지 않는다. 화자 분리 모델은 추가하지 않았으며 마이크와 사람 사이의 거리 변화, 배경 발화 등을 완벽하게 구분할 수는 없다. 기준이 부족하면 감점 대신 점수를 보류한다. 소음 때문에 시나리오 진행을 막지는 않는다.

음높이, 말속도, 말 사이 쉼은 이번 규칙으로 감점하지 않는다. 목소리 점수가 나와도 **상대 성량에 한정된 참고 점수**이지 전체 음성 능력의 검증된 평가가 아니다.

## 상한과 반영 시점

- 표정: 답변당 최대 −1, 세션 전체 최대 −3.
- 성량: 답변당 최대 −2, 세션 전체 최대 −6.
- 자세: 기존 답변당 −2, 세션 전체 −6 상한 유지.
- 응답: 기존 가점 +8, 일반 감점 −15 상한 유지. 동일 사실의 모순은 별도 최대 −3.
- 같은 사건 ID와 같은 답변의 재분석은 중복 반영하지 않는다.

얼굴·자세의 관찰 점수는 기존 관찰 API에서 갱신한다. 성량은 **답변 녹음이 업로드되고 음성 분석이 끝난 뒤** 반영한다. 마이크를 말하는 도중 계속 스트리밍 채점하는 구현은 아니다. 실시간 분석이 시간 초과되면 보류하고, 종료 후 분석에서 최종 측정값으로 갱신한다. 최종 측정이 실패하면 이전 임시 성량 감점도 제거한다.

조건을 만족하는 serious/supportive 성량 측정에는 기준점 75를 두며, 큰 성량 규칙에 해당할 때만 감점한다. 다른 상황이나 근거가 부족한 음성은 `null`을 유지한다. 결과 화면에서는 음성도 `provisional: true`인 참고 지표로 표시한다. 측정된 영역의 평균에 참고 점수가 포함되는 기존 종합 계산은 유지한다.

## 수정할 파일

- `poc/backend/app/services/context_scoring.py`: `RULE_MULTIPLIERS`가 상황 × 행동 표다. `RAISED_VOICE_DB`, `MIN_VOICE_SECONDS`, `MIN_NOISE_SECONDS`, `MIN_SNR_DB`가 성량 조건이다. AI는 이 숫자를 생성하거나 수정하지 않는다.
- `poc/backend/app/services/interaction_scoring.py`: `POINTS`가 기본 감점, `NONVERBAL_PENALTY_LIMITS`가 상한이다. API의 각 점수 사건에 `base_points`, `multiplier`, `points`를 반환한다.
- `poc/backend/app/ai/voice_measurement.py`: 순수 측정값만 계산한다. 새 발화 시간·비발화 시간·SNR도 여기서 반환한다.
- `poc/backend/app/services/interaction_report.py`: 종료 후 최종 성량 측정으로 갱신하고, 근거와 배율을 결과에 전달한다.
- `mvp/src/features/smart-mirror/lib/mirrorReport.js`: 서버가 명시한 음성 참고 점수만 표시하고 나머지는 보류한다.

## 검증

관련 백엔드 테스트 153개 통과. 상황별 실제 감점, 여러 행동의 합산 상한, 미소와 성량의 중복 처리, 불확실 분류, 짧은 발화, 순간적인 큰 소리, 낮은 SNR, 마이크 변경, 타고난 높은 음높이의 감점 제외를 확인했다. 합성 WAV를 보정→업로드→답변 제출→종료→결과 API까지 보내 성량 73점과 근거의 `−1 × 2 = −2`를 확인했다. 분석 시간 초과 후 종료 시점에 복구하는 경로도 통과했다.

결과 데이터 표시 테스트 14개와 Vite 빌드도 통과했다. 새 음성 API 테스트의 녹음 파일은 임시 폴더로 격리했다.

실제 사용자 녹음·카메라로 이번 수치의 정확성을 검증한 결과는 아니다. 이전 상황 분류 프롬프트는 유지했고, 이번에는 AI 추가 호출 없이 행동 규칙과 측정/보고 경로를 검증했다.
