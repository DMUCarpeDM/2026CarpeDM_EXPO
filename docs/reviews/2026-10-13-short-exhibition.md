# 스마트미러 단축 시연과 대화 맥락 분석

## 시연 구성

스마트미러 진입 시 `exhibition: true`를 전송한다. 일반 웹 서비스의 기존 출근·업무·퇴근 흐름은 유지한다.

준비된 시나리오 3개 중 하나를 세션 시작 시 무작위로 선택한다. 선택된 한 상황에서 사용자 답변 5회를 받고 종료한다. 같은 세션의 인물·상황·대화 이력은 끝까지 유지한다. 새 시연에서 다시 선택하며 직전 시연과 다른 상황임을 보장하지는 않는다.

| 기존 순서 | 준비된 시나리오 | 대화 내용 |
| --- | --- | --- |
| 1 | 업무 자료를 받은 첫날 | 자료 확인·이해한 방향·필요한 도움 정리 |
| 7 | 자료에서 발견된 수치 오류 | 사실 확인·영향 범위·수정과 재발 방지 |
| 14 | 퇴근 직전 들어온 추가 업무 | 긴급도 확인·오늘과 내일의 범위 조율 |

시나리오의 제목, 상세 설명, 다섯 번 대화의 방향은 `poc/backend/app/seed/workplace-exhibition.json`에서 수정한다. 영상, 첫 대사와 채점 기준은 기존 `workplace-conversation.json`의 해당 장면을 사용한다. 화면에 보여주는 상황 설명과 AI에게 주는 상황 설명은 같고, 미리보기도 같은 설정 파일을 읽는다.

요약 화면에는 무작위 선택 방식이나 후보 개수를 설명하는 부연 문구를 표시하지 않는다. 상황 제목과 배경·상대 요구·아직 확인되지 않은 정보를 나누어 보여준다. 2:3 세로형 실버 일러스트를 사용하며 장면 전환 애니메이션은 없다. 제목은 ‘오늘의 대화’, 부연설명은 ‘상황을 살펴보고, 평소처럼 대화해 보세요.’다. 화면 맨 위의 2px 흰색 직선은 개요 안내의 경과 시간에 맞춰 차오르고 일시정지와 탭 비활성화 시 함께 멈춘다. 이전 문구는 `2026-10-13-overview-copy-backup.md`에 보관한다.

개요 안내 5초와 필수 마이크 확인은 유지한다. 장면 사이 상황 안내 팝업은 없다. 별도 하루 계획 생성은 생략하고 첫 대사는 준비된 문구를 사용한다. 이후 네 대사는 같은 상황의 대화 로그를 바탕으로 생성한다. 모순 확인용 추가 턴으로 전체 횟수를 늘리지 않는다. 같은 평가 목표를 반복 달성해 중복 가점이 붙지 않도록 평가 ID를 유지한다.

## AI에 대화 로그를 주는 방법

대화 로그를 주는 것이 적절하다. 다만 역할극 인물, 맥락 분류기, 평가기는 구분한다.

1. 역할극 인물: 자기 장면과 직접 들은 말만 받고 평가표·점수는 보지 않는다.
2. 맥락 분류기: 현재 상황·AI 대사·같은 장면의 최근 6개 대화·제출 답변으로 일반 대화/갈등·오류/지원 요청/업무 설명/잡담 중 하나를 고른다. 로그는 인용 데이터이고 내부 명령으로 취급하지 않는다.
3. 평가기: 실제 질문과 사용자 답변의 근거를 확인하고 코드의 기존 제한된 가중치를 적용한다. 다른 독립 장면의 답변을 현재 장면의 모순 근거로 섞지 않는다.

분류 확신도가 0.9 미만이거나 인용 문구가 실제 대화에 없으면 판단 보류한다. 모델 호출 실패 시 중립 가중치로 처리한다. 카메라 영상이나 녹음 원본을 이 분류 요청에 보내지 않는다.

## 네 영역의 의미와 한계

- 응답: 첫 질문·직전 발화·장면 맥락과의 관련성, 목표 수행, 근거 있는 모순을 확인한다. 단순 수락은 가점 없이, 인식 오류는 판단 보류한다.
- 자세: 실제 측정된 자세 신호와 해당 장면의 가중치를 연결한다. 측정이 없으면 미측정이며, 이상 신호가 없다는 이유만으로 태도가 좋다고 단정하지 않는다.
- 표정: 기존 표정 신호는 현장 검증 전 참고값이다. 사람의 실제 감정·성격을 추정하지 않는다. 기존 심각한 상황의 지속 미소 참고 규칙은 유지하지만 새로운 감점 기준은 추가하지 않는다.
- 목소리: 측정 가능한 크기·속도·멈춤 기록을 장면과 함께 제공한다. 검증된 적합성 점수 기준이 없으므로 임의 점수·감점을 만들지 않는다.

`judgment.context_assessment`와 결과의 `speech_stats.context_assessments`에 영역별 관찰 상태를 남긴다. 후처리에서 확보한 목소리 측정값도 결과에 반영한다. 결과 화면의 기존 네 영역 카드에 맥락 설명을 표시한다.

## 검증

- 이번 변경의 백엔드 관련 테스트 41개와 프론트 관련 테스트 29개 통과. 프로덕션 빌드 통과.
- 브라우저에서 세 시나리오의 제목·상세 설명과 무작위 안내 문구 제거를 확인했다. 현재 세로 미리보기에서 화면 잘림이나 넘침이 없으며 이미지 원본은 1024×1536이다.
- 제목과 부연설명을 복구하고 최상단에 2px 흰색 진행선을 추가했다. 타이머 테스트 5개 통과. 브라우저에서 진행선이 일시정지 중 유지되고 재개 시 증가함을 확인했다. 낮은 화면에서는 카드 아래에 조작 버튼이 배치되도록 최소 행 높이를 보장한다.
- 준비된 시나리오가 3개인지, 세션마다 1개만 선택되는지, 같은 상황과 평가 ID를 유지하는지, 복구 후에도 바뀌지 않는지, 다섯 번째 응답 후 종료하는지 검증했다.
- API 테스트에서 후속 대사 생성과 응답 평가가 이전 응답 이력을 누적해서 받는지 확인했다. 이 테스트는 가상 답변과 모델 대체 응답을 사용한다.
- 실제 Vertex AI 맥락 분류는 이전 검증에서 가상 오류 보고 대화 1건을 serious로 분류했다. 이번 변경에서 실제 마이크로 5회 대화하는 전체 현장 검증을 수행한 것은 아니다.
