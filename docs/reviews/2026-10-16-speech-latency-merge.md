# speech-latency와 로컬 수정 병합

2026-10-16, 원격 `6701eff`를 main `c98478e`와 로컬 수정에 병합했다.
로컬 수정은 병합 전 `9281c60`으로 보존했다. env, 녹음, 캡처, 테스트 출력 폴더는 커밋하지 않았다.

| 겹친 파일 | 병합 결과 |
|---|---|
| useFaceTracking.js | 로컬의 시연자 고정·머리 크롭 얼굴 검출을 유지하고 원격의 좌우 재검색·500ms 영상 정지 감지를 반영 |
| useExpressionTracking.js | 얼굴 검출은 로컬처럼 별도 경로로 유지. 원격의 늦은 표정 결과 폐기 동작은 시연자 존재 세대 번호로 구현 |
| usePracticeTranscription.js | 로컬 서버 STT 폴백과 원격 재시도·발화 종료 기준 2초 자동 전송을 함께 유지 |
| PracticePage.jsx | 녹음 준비를 인식 시작보다 먼저 수행하고 턴별 초안·녹음을 분리. 이전 답변은 자막으로 다시 노출하지 않음 |

도트 반지름 `.85 × 1.25`, 얼굴 선 두께 `2.5 × 1.15`를 유지했다.
원격의 무조건 중앙 얼굴 선택은 전시장의 다른 사람에게 전환될 수 있어 적용하지 않았다.
시연자가 없어지면 마커를 지우고, 같은 시연자가 기존 위치 근처로 복귀해 일관되게 검출돼야 재연결한다.
얼굴만 검출됐다는 이유로 다른 사람의 얼굴을 기존 시연자에 연결하지 않는다.
관련 Chrome 테스트도 이 조건과 실제 크롭 좌표계를 사용하도록 수정했다.

3컬럼 최신 이미지, USB 우선/OS 기본 입력 폴백, 2개 시나리오·5회 답변,
시나리오 평가 세분화·누락 보충 처리·영역별 비중 및 표정·음성 점수 수정도 유지했다.
원격 AI 역할 유지 프롬프트는 로컬의 맥락 연속성 지침과 함께 적용했다.
