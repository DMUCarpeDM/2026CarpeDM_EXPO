# ElevenLabs 전용 음성 및 영상 수정

- 프로젝트의 Iris 런타임·모델·설치 환경·어댑터·사전 음성과 전용 테스트를 삭제했다. 사용자 홈의 공유 모델 캐시는 변경하지 않았다.
- 첫 대사는 기존 Yuna MP3, 후속 대사는 ElevenLabs 스트리밍을 사용한다. 스마트미러에서는 브라우저나 다른 제공자 음성으로 자동 전환하지 않는다.
- 실제 ElevenLabs 응답: `payment_required`, `Free users cannot use library voices via the API.` 현재 키의 계정이 Free로 판정되어 Rangi 사용이 차단된다. 가입 계정과 API 키 계정의 일치 여부를 확인해야 한다. 오류를 HTTP 402로 구분해 전달한다.
- 소개 영상: 새 Vertex 생성본에도 중복 인물이 생겨 채택하지 않았다. 기존 영상의 7초 이후 두 번째 인물 진입 부분을 제거하고 7초 프레임을 1초 유지했다. 기존 전체 음성 트랙은 유지했다.
- 영상 전환: 두 버퍼 사이 투명도 전환을 제거하고 한 영상만 표시한다. 안내 영상의 10초 반복 재생을 제거했다.

과거 Iris 도입 문서는 변경 이력을 위한 자료이며 현재 실행 구성에는 사용하지 않는다.
