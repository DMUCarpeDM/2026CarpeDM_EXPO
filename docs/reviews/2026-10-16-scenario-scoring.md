# 시나리오 평가·영역별 비중·표정·목소리 개선

검증일: 2026-10-16. 새 점수 엔진: `interaction-score-v11`.

## 변경한 네 가지

1. 원문 전체와 일치하는 높은 확신도의 맥락 이탈을 모호함보다 먼저 처리한다. `vague`와 `off_topic`이 함께 나와도 이탈 근거가 유효하면 감점한다. 음성 인식 오류·평가 불확실·부분적으로 관련된 답변은 이 규칙으로 감점하지 않는다.
2. 자기소개는 이름/호칭·업무 상태·오늘 목표, 회식은 참석 의사·참석 조건·공개 범위/의사 정정으로 나눈다. 현재 질문에서 실제로 요구한 내용의 원문 근거가 있을 때만 누락 감점한다. 선택 항목, 개인정보 세부 사유, 이미 답한 항목은 누락 감점하지 않는다. 후속 답변에서 목표를 충족하면 같은 목표의 이전 누락 감점도 해제한다.
3. 시나리오의 `rubric_weights`를 최종 총점과 실시간 점수에 연결했다. 직장 대화는 응답 40%, 목소리 25%, 표정 20%, 자세 15%다. 미측정 영역은 점수 없이 제외하고 측정된 영역의 비중을 재계산한다.
4. 표정은 얼굴 검출 여부만으로 끝내지 않고 일반 표정·미소 신호와 대화 상황을 함께 반영한다. 목소리는 시나리오별 말속도, 반복된 긴 쉼, 동일 마이크의 앞선 발화와 비교한 성량 변화를 반영한다.

## 평가 항목

| 시나리오 | 항목 | 인정·보호 기준 |
|---|---|---|
| 자기소개 | 이름·호칭 또는 공개 범위 | 가명·호칭·이름 비공개 의사도 인정 |
| 자기소개 | 담당 업무의 현재 상태 | 아는 업무뿐 아니라 미배정·모름·관련 확인 질문도 인정 |
| 자기소개 | 오늘 목표 또는 목표를 위한 확인 | 구체적인 행동 한 가지 또는 목표를 정하려는 관련 질문 |
| 회식 | 현재 참석 의사 | 참석·불참은 동등, 조건을 밝힌 미정도 인정 |
| 회식 | 참석 판단 조건 | 시간·범위 확인/조율, 선택 항목이라 미언급 감점 없음 |
| 회식 | 공개 범위/의사 정정 | 비공개·재권유 거절·마음 변경 설명, 선택 항목이라 미언급 감점 없음 |

단순한 “네, 알겠습니다”는 가점하지 않는다. 원문에서 확인되지 않는 목표 달성은 점수를 만들지 않는다. 첫 질문의 문구나 사전 TTS는 변경하지 않았다. 현재 2개 시나리오와 5회 답변 흐름은 유지했다.

## 표정·목소리 규칙

이 값들은 전시 연습을 위한 초기 기준이며, 모델 정확도를 새로 검증한 결과나 보편적인 사람의 정상 기준은 아니다. 얼굴·음성으로 감정, 성격, 업무 능력을 추정하지 않는다.

- 표정: 최소 4개 얼굴 표본을 사용한다. 일반 표정 출력이 0.7 이상이고 미소 출력이 0.7 미만이면 작은 가점을 준다. 미소를 필수로 요구하지 않는다. 인사/회식의 일반·가벼운·지원 대화에서 미소 출력 0.7 이상과 3초 이상 지속 신호가 함께 있을 때도 작은 가점을 준다. 실제 심각한 업무 맥락의 지속 미소는 기존의 제한된 감점 규칙을 적용한다. 출력값은 확률로 보정된 정확도나 감정 점수가 아니다.
- 말속도: 자기소개는 초당 2.5~6음절, 회식 의사 전달은 2.5~7음절을 사용한다. 심각한 용건은 상한 5.5, 업무 설명은 상한 6으로 조정한다. 실제 오디오와 전사 정렬이 측정된 경우에만 적용한다.
- 긴 쉼: 자기소개는 2.5초, 회식은 3초 이상의 **말 사이 공백이 3회 이상** 반복될 때 반영한다. 녹음 앞뒤 대기와 AI 재생 제외 구간은 기존 측정기에서 제외한다. 한 번의 생각할 시간은 감점하지 않는다.
- 성량: 사전 녹음을 다시 요구하지 않는다. 표준 설정에서는 같은 세션·장치·입력 설정의 첫 유효 발화를 비교 기준으로 사용한다. 해당 기준 턴 자체는 비교 감점하지 않으며, 이후 발화에서 상대적인 증가만 확인한다. 실제 개인 사전 녹음이 있으면 기존 개인 기준을 쓴다.
- 비교 품질: 발화 3초 이상, 비발화 구간 0.5초 이상, SNR 10dB 이상, 자동 음량 조절 꺼짐, 잘림 없음, 같은 캡처/장치/설정을 확인한다. 장치 변경·잡음·원본 부족은 비교 감점하지 않는다. 핀마이크 위치와 입력 볼륨을 일정하게 유지해야 비교가 의미 있다.
- 동일 기준 대비 6dB 이상 증가의 상황별 배율은 가벼운 대화 0.25, 일반 대화 0.5, 업무 설명 1, 지원 대화 1.5, 심각한 대화 2다. 최종 직장 점수 단위에서 해당 사건의 감점은 각각 0.5/1/2/3/4점이며 다른 음성 감점이 겹치면 턴·세션 상한을 적용한다. 태도나 감정 판정은 아니다.
- 최종 직장 점수 범위 55~89와 미측정 값 `null`은 유지한다.

### 실제 평가 API 시험과 제한

실제 설정된 Vertex Gemini 평가 API에 가상 질문/답변만 보냈다. 상대 대화 생성이나 실제 STT/TTS 시연이 아니라 **평가 API 검증**이다. 운영 설정의 대기시간은 변경하지 않았다.

- 운영과 같은 20초 대기: 실제 모델 호출 8회 중 1회 판정 완료, 7회 판정 불가. 5번째 단순 수락 2건은 API 호출 없이 중립 처리했다.
- 진단용 60초 대기: 실제 모델 호출 8회 중 5회 판정 완료, 3회 판정 불가. 5번째 단순 수락 2건은 API 호출 없이 중립 처리했다.

진단에서 `ReadTimeout`을 확인했다. 응답한 사례에서는 이름만 답한 경우 업무·목표 누락, 업무 미배정 설명의 인정, 후속 목표 보충, 회식 조건 확인·비공개 거절의 인정이 확인됐다. 맥락 이탈 실제 호출은 시간 초과여서 해당 사례의 실제 모델 판정 통과를 주장하지 않는다. 이탈과 모호함이 동시에 반환되는 코드 경로는 회귀 테스트로 확인했다.

즉 **코드·보고서 경로 검증은 통과했지만 실제 API 전체 검증은 부분 완료**다. 시간 초과는 가점·감점을 임의로 만들지 않고 미측정으로 남는다. 표정 모델 정확도 검증 및 API 지연 해결은 이번 수정의 완료 항목이 아니다.
