# 선배 말투와 반복 표현 재조정

2026-10-15. Owner asked for less automatic deference and fewer generic repeated conclusions.

## 변경

- 전시 시스템 규칙에서 인정·자기반성·합의의 중복 강조를 줄이고, 구체적인 마지막 말에 자신의 입장에서 반응하도록 수정했다.
- 동의하지 않아도 더 캐묻지 않을 수 있다는 구분을 명시했다. 거절 뒤 금액·이유·관리계획을 요구하지 않는 경계는 유지한다.
- 페르소나의 완성 대사 예문을 제거했다. 선배의 판단·짧은 말·못마땅함을 유지하며 상담사식 친절·칭찬·일반론으로 끝내지 않도록 했다.
- 전시 상대역 생성 temperature .45 → .65. 일반 면접/훈련 상대역은 .45 유지. 반복의 원인을 특정 토큰으로 입증한 것은 아니며, 샘플링만으로 다양성을 보장하지 않는다.
- 3턴/소비 상황만 활성/원문 응답 전달 계약 유지. API passthrough 검사에 남아 있던 5턴 기대값을 3턴으로 맞췄다.

## 검증과 한계

- 실제 OpenAI GPT-4o, 승인된 가상 답변 세 흐름으로 두 번 비교했다. 최종 생성 후속 발화 6개에 각자 방식이라는 문구는 없고 거절 뒤 재질문도 없었다.
- 일반적인 이해/차이 설명은 일부 남는다. 마지막 발화들에서 알겠어요와 더 묻지 않겠다는 표현이 유사하게 반복됐다. 반복이 완전히 해결됐다고 주장하지 않는다.
- 반존대를 지시했으나 일부 결과가 전부 반말 또는 전부 해요체다. 말투 준수는 아직 불안정하다. 의미를 보존하기 위해 생성문을 강제 치환하지 않았다.
- 단위/API 검사 42 passed. 이전 변경 전에도 실패하던 contradiction 즉시 채점 검사 1개는 제외했다.
- git diff --check 통과. 실행 서버 재시작. 카메라·마이크·TTS 종단간 검증은 하지 않았다.
