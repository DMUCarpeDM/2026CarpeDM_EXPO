# 사적인 질문 시연으로 전환

- 전시 후보: 연애, 주말 일정, 소비/저축. 기존 원본 15개 팩은 보존하고 전시 설정의 첫 대사·목표를 독립적으로 사용한다.
- 3개 중 1개 선택, 사용자 답변 5회. 상대는 박선임.
- 공개·거절 모두 허용. 비공개·화제 변경·초대 거절을 이탈/누락으로 감점하지 않도록 actor 및 판단 프롬프트 수정. 공개량이나 수락 자체는 가점 아님.
- 개인 질문 거절만으로 심각한 대화로 분류하지 않는다.
- 테스트: 시나리오/actor/응답 판정 51개 통과, 자세 지표 28개 통과, 프론트 빌드 통과. 추가 context 테스트 1개는 외부 AI 호출을 대체하지 않아 API 키 누락으로 503; 해당 테스트를 제외한 묶음 58개 통과.
- 실제 브라우저: 새 주말 질문 설명 화면 진입 확인. 카메라 640x480, readyState=4, 재생 중. Pose status=ready, poseTracked=true, calibrating=false 확인. 현재 추적 실패는 재현되지 않음.
- Pose/Hand 초기화와 추론 실패가 조용히 무시되던 곳에 진단 로그 추가. 개인정보/영상은 로그에 넣지 않음. DOM 진단 속성으로 준비/감지/보정 상태 확인 가능.
- 파일 누락 없음: 로컬 pose heavy(29MB), hand(7.5MB), face(3.6MB). 어깨 미감지 또는 유효 표본 부족은 점수 보류를 유발한다. 과거 사용자의 장애 원인은 현재 정상 상태만으로 확정하지 않음.

- 실제 Gemini 가상 거절 3건 재검증: 기존 업무형 페르소나가 기획안 등을 만들어내는 문제를 확인하여 전시 장면 전용 actor_persona를 전달하도록 수정. 최종 3건 모두 공개를 강요하지 않고 사용자가 원하는 화제를 요청함. 결과: .omo/evidence/private-scenarios/replies.json.
