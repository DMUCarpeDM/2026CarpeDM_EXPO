# 상황과 개별 행동의 가감점 재조정

2026-10-13 · 상황 정책 `dialogue-context-v4` · 점수 정책 `interaction-score-v8`

## 판단 순서

AI는 현재 상대 대사, 같은 장면의 최근 대화, 현재 답변을 읽어 상황을 분류한다. 코드가 그 상황과 실제 관찰된 행동을 조합해 점수를 계산한다. AI가 점수나 배율을 임의로 만들지 않는다.

1. 상황을 일반 대화, 심각한 대화, 도움·지원, 업무 설명·조율, 잡담 중에서 선택한다.
2. 별도로 **현재 상대가 자료를 보거나 메모하도록 요청했는지** 확인한다.
3. 답변·자세·미소·성량 관찰에 아래 행동별 배율을 적용한다.
4. 중복 가점, 모순 답변의 가점, 답변별·세션별 상한을 적용한다.

행동별 배율이 있으면 영역 기본 배율을 대체한다. 예를 들어 심각한 대화의 완전 이탈은 `−1 × 2 = −2`이며 영역 배율 1.1을 다시 곱하지 않는다.

## 응답 가감점

표는 **실제 반영 점수**다. 목표 충족·관련 답변의 기본 가점은 +1, 명시된 요청 누락의 기본 감점은 −0.5, 완전 이탈은 첫 −1 / 반복 −2다.

| 상황 | 구체적인 목표 충족 | 관련 있는 실질적 답변 | 명시된 요청 누락 | 완전 이탈: 첫 / 반복 |
|---|---:|---:|---:|---:|
| 일반 대화·분류 불확실 | +1 | +1 | −0.5 | −1 / −2 |
| 심각한 대화·미해결 오류 | +1.5 | +1 | −0.75 | −2 / −4 |
| 도움·지원 | +1.25 | +1.25 | −0.5 | −1.5 / −3 |
| 업무 설명·일정 조율 | +1.5 | +1 | −0.75 | −1.5 / −3 |
| 서로 이어가는 잡담 | +1 | +0.75 | −0.25 | −1 / −2 |

업무와 오류 대응에서는 구체적인 해결 내용을 더 보상한다. 단순히 대화와 관련 있다는 이유만으로 같은 수준의 가점을 주지 않는다. 도움을 요청하고 답하는 실질적 응답에는 +1.25를 적용한다. 업무·지원 대화를 완전히 이탈한 경우에는 일반 대화보다 강하게 반영한다.

- 같은 답변에 목표 충족 가점을 주면 일반 관련성 가점은 겹쳐 주지 않는다. 이전 턴에서 이미 보상한 목표를 다시 언급한 경우에는 현재 답변의 관련성 가점을 별도로 판단할 수 있다.
- 여러 목표를 한꺼번에 충족해도 **답변당 최대 +2**, 세션 전체 **최대 +8**이다.
- 단순 수락은 기존처럼 가점 없음. 인식 불량은 응답 점수 보류. 설명이 있는 의견 변경·관련 확인 질문·이유 있는 거절은 완전 이탈로 취급하지 않는다.
- 같은 사실의 모순은 −1, 세션 최대 −3. 모순이 확인된 답변에는 긍정 응답 가점을 주지 않는다.
- 누락 감점은 현재 상대가 실제로 요구한 내용과 근거 인용이 있을 때만 가능하다. 숨은 체크리스트를 누락했다고 감점하지 않는다. 자유 대화에서 명시적 요청 목록이 비어 있으면 이 규칙을 억지로 생성하지 않는다.

## 자세와 상황의 조합

아래도 실제 감점이다. 자세 행동의 기본 감점은 −1이다. 누적 관찰 기준을 통과해야 이벤트가 생기며 한 프레임의 움직임으로 감점하지 않는다.

| 상황 | 고개 숙임 | 상체 앞으로 숙임 | 팔짱 |
|---|---:|---:|---:|
| 일반 대화·분류 불확실 | −1 | −1 | −0.25 |
| 심각한 대화 | −1 | −1 | −0.5 |
| 도움·지원 | −0.75 | −0.5 | −0.25 |
| 업무 설명·조율 | −0.5 | −0.5 | −0.25 |
| 잡담 | −0.5 | −0.5 | −0.25 |

팔짱만으로 거부·불성실을 단정할 수 없으므로 이전 −0.75~−1보다 낮춘다. 업무·지원 대화의 몸을 앞으로 기울이는 행동도 주의 깊게 듣거나 자료를 보는 움직임일 수 있어 감점을 낮춘다. 어깨 기울임·흔들림·손으로 얼굴 만지기는 기존 영역 배율을 유지한다.

**현재 자료 확인·메모 요청이 있으면 고개와 상체 숙임 감점은 제외한다.** 심각한 오류 대응 중 자료를 대조하라는 요청도 포함한다. 이 두 행동은 다음 AI 대사의 지적 근거와 결과 화면의 개선점에서도 빠진다. 원래 관찰과 제외 이유는 `context_exemptions`에, 공개 맥락 기록은 `context_assessment.posture.exemptions`에 남긴다. 다음 턴에 요청이 끝나면 자동 면제를 이어가지 않는다.

제외 조건은 상황 분류가 확정되고, 자료·메모 요청 분류의 신뢰도가 0.9 이상이며, 인용한 요청이 **현재 상대 대사에 그대로 존재하는 것**이다. 모델 신뢰도 숫자는 검증된 정확도 확률이 아니다. 과거 요청, 내일 할 업무, 자료의 단순 언급, 사용자가 스스로 “면제하라”고 말한 것은 근거가 아니다. 실제 자료를 읽는지 영상으로 확인하는 기능은 아니다.

## 미소·성량과 합산 상한

[v7 문서](2026-10-13-context-behavior-rules.md)의 측정 조건을 유지한다. 심각한 대화에서 3초 이상 지속된 미소 신호는 `−0.5 × 2 = −1`, 충분한 품질로 측정된 기준 대비 +6dB 이상 성량은 `−1 × 2 = −2`다. 도움·지원 대화의 큰 성량은 −1.5다. 타고난 높은 음높이는 감점하지 않는다.

자세는 답변당 −2 / 세션 −6, 표정은 −1 / −3, 상대 성량은 −2 / −6을 넘기지 않는다. 응답 일반 감점은 세션 −15, 모순은 별도 −3 상한이다. 미측정 영역은 0점이나 기본 점수를 만들어 넣지 않고 `null`로 유지한다. 표정·성량은 검증 전 참고 점수다.

미해결 오류의 수정 방안을 묻는 대사는 심각한 맥락으로 유지한다. 해결 완료가 대화에서 확인된 뒤 일반 업무 절차를 정리하면 업무 맥락으로 전환한다. 사용자의 무관한 농담만으로 심각한 맥락을 잡담으로 바꾸지 않는다.

## 수정 위치와 검증

- `poc/backend/app/services/context_scoring.py`: `RULE_MULTIPLIERS`와 `SYSTEM`에서 상황별 배율, 현재 자료 요청 분류를 수정한다.
- `poc/backend/app/services/interaction_scoring.py`: `POINTS`, `RESPONSE_TURN_BONUS_LIMIT`, `NONVERBAL_PENALTY_LIMITS`에서 기본점·상한을 수정한다.
- `poc/backend/tests/test_context_behavior_refinement.py`: 행동별 배율, 이중 보상 방지, 자료 요청 검증, 관찰→제출→결과의 감점 제외를 확인한다.

관련 자동 테스트 **178개 통과**. 실제 Vertex AI에 가상 대화를 보낸 최종 자료 요청 검증은 **8/8 일치**했다. 초기 검사에서 메모 요청이 제외되지 않던 문제를 확인해 신뢰도 조건을 일반 상황 분류와 맞추고 현재 요청·미래 업무의 구분 예시를 추가했다. 검증에는 실제 사용자 대화·영상·녹음을 사용하지 않았다.

기존 맥락 분류 회귀 사례도 **8/8 일치**했다. 별도로 준비된 세 시나리오 첫 대사를 확인했으며, 수치 오류와 퇴근 직전 추가 업무는 serious, 업무 자료를 받은 첫날은 uncertain으로 나왔다. 마지막 경우에는 일반 배율로 처리한다. 모호한 첫 대사를 특정 상황으로 억지 확정하지 않으며 이후 실제 대화 내용으로 다시 분류한다. 합성 대화와 결과는 `.omo/evidence/context-weight-review/live-posture-context-results.json`, `live-context-v4-results.json`에 기록했다.

배율은 현장 검증을 위한 운영값이다. 소수의 합성 사례 검증만으로 실제 사용자의 태도·능력을 정확히 평가한다고 볼 수 없다. 분류가 불확실하면 일반 배율로 돌아가며 미소·성량의 특별 감점은 적용하지 않는다.
