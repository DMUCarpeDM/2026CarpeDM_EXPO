## 목소리 null의 뜻

현재 목소리 엔진은 음량, 말속도, 쉼을 측정한다. 그러나 이 측정값을 몇 점으로 바꿀지 검증된 기준이 아직 없으므로 `score_status: criteria_pending`과 `score: null`을 반환한다. 0점도, 무조건 녹음 실패도 아니다. 측정 항목 자체가 null이면 해당 항목의 status와 reasons를 따로 확인해야 한다. 예를 들어 보정이 없으면 상대 음량이, 전사 품질이 낮으면 말속도가 보류될 수 있다.

응답 점수의 null은 의미를 판단할 수 없는 전사 또는 분석 실패로 채점하지 않았다는 별개의 뜻이다.

## 실제 AI 재검증 상태와 한계

사용자가 Google Vertex AI에 가상 테스트 데이터 전송을 명시적으로 승인한 뒤 실제 재검증을 완료했다. 실제 사용자 녹음이나 카메라 데이터는 보내지 않았다.

- 첫 실행의 응답 13사례: 11사례 기대 충족, 업무상 거절 1사례 분석 불가로 보류, 부정 표현 1사례 목표 충족 오판 발견.
- 추가 수정: `확인받지는 않겠습니다`처럼 목표 행동을 명시적으로 부정한 인용에는 목표 충족 가점을 주지 않도록 검증을 추가했다. 대조절 앞의 다른 행동 거절과 뒤의 긍정 약속은 구분한다. 이 보완은 의미 분석 전체를 대체하지 않는다.
- 수정 후 7사례 × 2회 = 14회 모두 기대 충족: 정상 답변 77 / 수락 75 / 업무상 거절 76 / 목표 행동 거절 76(관련 응답 +1만, 목표 가점 없음) / 깨진 전사 null / 모순 74 / 명시적 정정 76. 수락·명백한 잡음은 외부 모델 호출 전 로컬에서 처리한다.
- 실제 맥락 분류 4사례: 심각한 상황 2개는 serious로 분류되어 가상 지속 미소 표본 적용 시 표정 73.7. 잡담 75. 일반 업무 요청은 확신 부족으로 uncertain이었지만 표정 75를 유지했다. 표정 표본은 테스트용 집계값이며 실시간 카메라 정확도 검증은 아니다.
- 독립 대사 검증 4사례 모두 기대 충족: 없는 팀장 보고·새 마감·평가자 대사 차단, 근거 있는 자료 확인 대사 유지. 검사 호출은 약 0.83~1.60초.
- 생성 대사 자체는 여전히 형식 검사 실패와 보수적 대체가 발생했다. `live-repeats.json`의 내부 생성 함수 4회 중 3회는 DialogueGenerationError였다. 최종 사용자 대사 반환 경로 3회는 모두 오류 없이 안전한 확인 대사로 교체했다. 생성된 점심·파스타 제안과 근거 없는 친밀감 요구는 노출되지 않았다. 다만 3회 모두 같은 확인 문장으로 대체되어 자연스러움은 남은 개선점이다. 소요 시간은 1.58 / 1.81 / 2.91초이며 TTS 시간은 포함하지 않는다. 상세는 `actor-public-results.json`에 기록했다.

증거: `.omo/evidence/judgment-fixes/live-before-negation-fix.json`, `live-repeats.json`, `context-results.json`, `grounding-results.json`, `actor-public-results.json`.

상황 근거 검사는 추가 AI 호출이므로 대사 생성 시간이 늘어날 수 있다. 검증 실패 시 대사를 보수적으로 교체하므로 표현이 반복적일 수 있다. 의미 분석의 모든 오판을 완전히 제거했다고 보장할 수는 없다. 표정 점수도 검증 전 참고값이며 감정이나 태도를 확정하는 값이 아니다.
