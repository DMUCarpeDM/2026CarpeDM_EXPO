# 상단 계정 버튼 및 요금제

상단 알림·프로필 드롭다운을 로그인·가입 버튼으로 바꾸고, 데스크톱/모바일 메뉴에 요금제를 추가했다.

요금제는 Plus → Pro → Business → Enterprise 순서다. 데스크톱은 4열, 태블릿은 2열, 모바일은 1열이다. 가격·사용량은 확정되지 않아 공개 예정으로 표시했다. 기업 두 플랜은 준비 중으로 표시하며 결제나 신청을 받지 않는다. Enterprise는 서비스 제공사가 중견·대기업별 요구에 맞춰 직접 개발·구축할 예정임을 안내한다.

로그인·가입은 기존 `/api/auth/login`, `/signup`, `/me`를 사용한다. 인증 정보는 현재 탭의 sessionStorage에 보관하고, 일반 웹의 세션 생성에만 Bearer 헤더로 전달한다. 스마트미러의 자동 체험에는 전달하지 않는다. 로그아웃 시 인증 정보와 현재 방문자 상태를 정리한다. 서버 인증 구현과 기업용 기능은 변경하지 않았다.

검증: 1440/1066/768/390px에서 요금제 열 수, 기업 버튼 비활성, 개인 연습 진입, 로그인·가입 이동, 로그인 오류·성공·로그아웃을 브라우저에서 확인했다. 인증 요청은 테스트에서 모의 응답을 사용했으며 실제 계정을 만들지 않았다. 별도 API 계약 검사로 Content-Type과 Authorization 병합을 확인했다. 최종 대상 테스트 27개 통과, 별도 프롬프트 반응형 테스트 통과. 프로덕션 빌드 `/private/tmp/mirror-pricing-final-20261018` 성공.
