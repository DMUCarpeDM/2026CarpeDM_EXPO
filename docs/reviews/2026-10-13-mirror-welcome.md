# 영상 첫 화면과 Iris 안내 음성 — 2026-10-13

- NFC 아이콘·설명 카드를 제거하고 기존 아침 장면의 박선임 영상을 화면 전체에 표시한다. 자막, 타이틀, 상태바는 표시하지 않는다.
- 안내 문구: “안녕하세요. 시연해 보실래요? NFC 태깅해 주시면 시연으로 넘어가요.” Iris 합성에는 NFC를 “엔에프씨”로 입력했다.
- 실제 로컬 Iris로 합성한 `welcome-iris.wav`를 번들에 포함한다. 입장마다 재합성하지 않는다. 안내 종료 후 듣기 영상으로 전환하고 화면 이탈 시 오디오를 중단한다.
- 화면 클릭·키보드 Enter/Space는 기존 준비 화면으로 진행한다. NFC는 기존 리더 폴링을 유지하며 유효한 카드는 결과 연결 정보를 보존한다. 미등록·조회 실패 카드는 클릭과 같은 익명 체험으로 진입해 잘못된 카드에 결과를 연결하지 않는다.
- F5/새로고침은 기존 미러 reload 초기화 경로를 통해 이 첫 화면으로 복귀한다.
- Chrome 키오스크 실행 스크립트에 `--autoplay-policy=no-user-gesture-required`를 추가했다. 일반 브라우저의 첫 방문 자동재생 허용은 브라우저 정책에 따라 다르다.

## 음성 끝부분

합성 결과를 사후에 자르는 코드는 확인되지 않았다. 새 안내 원본의 길이는 4.64초이고 로컬 Whisper에서 마지막 “넘어가요.”가 4.06~4.52초로 인식됐다. 별도 여유 단어를 발화시키는 대신, Iris WAV 응답의 모든 원본 PCM 샘플을 보존하고 끝에 0.6초 무음을 추가했다. 안내 배포 파일은 총 5.24초다.

이 조치는 재생 종료 여유를 확보한다. 모델이 합성 단계에서 단어 자체를 누락한 기존 파일을 무음 추가만으로 복원하지는 못하며, 기존 모든 문장의 합성 누락 원인이 해결됐다고 단정하지 않는다. Whisper는 “시연”을 “시원”으로 전사했으므로 발음은 실제 청취 확인도 필요하다.

## 검증

- backend Iris 합성·사전 WAV·런타임 계약 테스트 13개 통과. 원본 샘플 보존과 정확히 600ms 무음 추가 검증.
- frontend 음성 재생·NFC 커서 테스트 12개 통과. 프런트엔드 프로덕션 빌드 통과.
- 실제 브라우저에서 1280×720 영상 전체 화면, 안내 오디오 5.24초 완주, 듣기 영상 복귀, 클릭 후 준비 화면 이동, 다음 화면에서 새로고침 후 첫 화면 복귀 확인.
- 듣기 영상이 기존 버퍼에 있을 때 loadeddata 이벤트가 다시 발생하지 않아 말하기 영상에 머무르던 문제도 수정.
- 관련 브라우저 회귀 테스트의 새 화면 기대값을 갱신했다. CLI 브라우저 테스트 실행은 개발 서버 포트 바인딩 권한 제한으로 시작하지 못했고, 성공으로 집계하지 않는다. 실제 UI 검증은 Codex 브라우저 도구로 별도 수행했다.
- 실물 NFC 리더 태깅은 이번 작업에서 수행하지 않았다. 공용 태그 시뮬레이터는 다른 열린 미러 탭에도 이벤트를 전달하므로 실행하지 않았다.
