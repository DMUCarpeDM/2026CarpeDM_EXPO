# 개인 소비 시나리오 · OpenAI 실제 대화 로그

2026-10-15 · 모델 gpt-4o

가상의 사용자 답변만 사용했다. 첫 AI 대사는 준비된 문구이며, 이후 두 대사는 실제 OpenAI 응답 원문이다. 사용자 세 번째 답변 뒤 체험이 종료되므로 별도의 네 번째 AI 발화는 없다. 실제 카메라·마이크·TTS·점수 분석은 이 테스트에 포함하지 않는다.

## 바로 거절

### 1턴

**박선임 (준비된 첫 대사):** 월급 받으면 어디에 좀 써요? 난 저축부터 해야 한다고 보는데.

**가상 사용자:** 제 소비나 저축 이야기는 하고 싶지 않아요. 조언도 괜찮습니다.

### 2턴

**박선임 (OpenAI 실제 생성):** 알겠어요. 그럼 조언 없이 다른 이야기를 하죠.

**가상 사용자:** 네, 돈 이야기는 여기까지만 하고 싶어요.

### 3턴

**박선임 (OpenAI 실제 생성):** 알겠어요. 다른 이야기나 해요.

**가상 사용자:** 제 의사를 이해해 주시면 좋겠습니다.

사용자 3회 답변 후 종료.

## 판정

- 세 흐름 모두 거절 뒤 금액·비율·이유·계획을 요구하는 재질문이 없었다.
- 반존대 혼합은 일부 공개 및 의견 차이 흐름에서 확인했다. 바로 거절 흐름은 존댓말 위주라 일관된 반존대라고 주장하지 않는다.
- 각자 방식이라는 말이 반복되고, 게임도 사는구나처럼 사용자가 한 말을 되짚는 부분이 다소 기계적이다.
- 표본 세 흐름이며 모델 응답은 매 호출 달라질 수 있다. 프롬프트 준수의 보장은 아니다.
- 첫 검증에서는 상담사식 마무리와 4문장 대사가 나와 해당 지침을 보완했다. 초기 로그는 consumer-dialogue-live-20261015-initial.json에 보존했다.
- 변경한 프로젝트 프롬프트와 가상 답변의 OpenAI 전송은 이번 사용자 메시지에서 명시적으로 승인됐다.

## 구현 및 자동 검증

- 전시 계획을 3개 답변 칸으로 제한하고 활성 소비 장면의 목표·의도를 시작/경계 조율/마무리로 재구성했다. 기존 세션의 저장된 진행표는 소급 변경하지 않는다.
- `.venv/bin/python -m pytest tests/test_workplace_exhibition.py tests/test_fixed_workplace_scene.py tests/test_settings_shared_env.py -q`: 15 passed. 실제 세션 API를 테스트 클라이언트로 호출해 세 번째 답변에서 종료되고 AI 후속 생성은 두 번인 것을 검증했다.
- `npm run build`: 통과. 기존 큰 번들 경고는 남는다.
- `git diff --check`: 통과.
- 실행 환경의 공유 `.env`에 앱 밖의 IRIS_AUTOSTART 항목이 있어 Pydantic 설정 로딩이 막혔다. 앱은 사용하지 않는 항목을 무시하도록 설정했고, 알려진 항목의 잘못된 값은 계속 거부하는 회귀 검사를 추가했다. `.env` 값이나 자격증명은 수정하지 않았다.
- 백엔드 8001 재시작. 실제 세션의 카메라·마이크·TTS 종단간 테스트는 하지 않았다.
- 재시작한 실제 로컬 API 확인: `/api/health` HTTP 200, dialogue_ready=true, degraded=false. 개인정보 없는 미저장 테스트 세션 32를 생성해 total=3, title=개인 소비를 간섭하는 선배, 새 opening_line 반환을 확인했다. 이 확인에서는 답변·음성·분석을 제출하지 않았다.
