# 요약 화면 문구 백업

## 이전 문구

- 시연 제목: 짧게 만나는 직장 대화.
- 시연 부연설명: 6개 상황 중 3개를 무작위로 만나고, 한 번씩 답해요.
- 일반 모드 제목: 회사에서 보내는 하루.
- 일반 모드 부연설명: 출근부터 퇴근까지, 세 장면을 미리 살펴봐요.

이전 시연 부연설명은 지금의 ‘준비된 3개 중 1개 선택’과 다르므로 기록으로만 보관한다.

## 현재 적용 문구

- 제목: 오늘의 대화
- 부연설명: 상황을 살펴보고, 평소처럼 대화해 보세요.

무작위 선택 방식은 화면에 설명하지 않는다. 선택된 시나리오의 상세 상황 설명은 카드에 유지한다.
