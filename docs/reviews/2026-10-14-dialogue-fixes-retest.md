# 시나리오 대화·평가 수정 및 실제 AI 재검증 — 2026-10-14

## 범위와 결과

Google Vertex AI의 gemini-3.5-flash-lite와 실제 서비스 API로 검증했다. 가상 사용자 답변만 전송했으며 카메라·마이크 원본은 사용하지 않았다. 상대역 응답을 미리 정한 문장으로 바꾸는 코드는 추가하지 않았다.

- 확장 검증: 4개 시나리오 × 2개 응답 경로 × 5턴 = 40턴. 거절, 일부 공개, 조건부 도움, 짧은 수락, 역할 변경 요구, 명시적 정정, 앞선 발언과 모순되는 주장, 잡음 후 재입력을 포함했다.
- 생성 설정 수정 후 재검증: 4개 × 5턴 = 20턴. 응답 평가 20/20 완료, 정상 답변 감점 0건, 모든 세션이 정확히 다섯 번째 답변에서 종료됐다.
- 맥락 분류: 16건 분류 완료, 4건 불확실하여 중립 배율 적용. 불확실한 상황을 억지로 심각한 대화로 바꾸지 않는다.
- API 응답 시간: 평균 6.35초, 최대 14.11초. 평가·상황 분류·후속 대사 생성을 포함하며 TTS 합성·재생은 제외한다.
- 회귀 테스트 183개 통과. 마지막 최신 발화 우선 처리 변경 후 관련 테스트 36개 추가 통과.

## 수정한 부분

1. **평가 출력 반복**: 낮은 생성 온도에서 같은 문장을 길게 반복하다 출력 한도를 소진하는 응답을 실제로 재현했다. Gemini 3 계열에는 권장 temperature=1.0을 적용했다. 응답 평가에는 JSON 스키마와 필수 필드를 지정했다. 기존 원문 인용 검증은 유지한다.
2. **평가 시간 제한**: 응답 평가 8초 → 최대 30초, 맥락 분류 5초 → 최대 20초로 변경했다. 프로젝트의 전체 Gemini 제한이 더 짧으면 그 제한을 따른다. 네트워크 장애까지 성공으로 꾸미지 않으며, 실패한 평가는 여전히 점수를 보류한다.
3. **잘못된 배경 전달**: 원본 15개 에피소드의 업무 상황 대신 현재 선택된 시연 장면의 상황을 맥락 분류에 전달한다.
4. **개인 질문 우회·화제 전환 충돌**: 비공개 의사를 밝힌 뒤 다른 개인 질문으로 바꿔 묻는 지침 충돌을 정리했다. 사용자가 먼저 제안한 주제로만 이어가도록 보강했다.
5. **화자 혼동·취소한 약속 재사용**: 대화 기록에 ‘당신의 이전 발화’와 ‘사용자의 답변’을 명시하고, 마지막 사용자 발화를 별도로 강조했다. 최근 거절이 이전 조건부 도움 의사를 취소했다면 예전 약속을 되살리지 않는다.
6. **내용 없는 도움 요청**: 부탁할 작업을 ‘함께 사용할 안내문의 오탈자 확인’으로 설정했다. 전문 지식 없이 이해할 수 있고, 작업을 물으면 즉시 설명할 수 있다. 정해지지 않은 분량·마감·소요 시간은 만들지 않는다.

생성 설정 근거: [Google Gemini 3 개발 가이드](https://ai.google.dev/gemini-api/docs/gemini-3?hl=en)는 낮은 temperature가 반복·성능 저하를 유발할 수 있어 기본값 1.0을 권장한다.
