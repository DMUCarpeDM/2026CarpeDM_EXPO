## 확인 범위와 발견 사항

브라우저 실제 체험 화면은 사전 마이크 확인 단계에 있어 자동으로 진행하지 않았다. 음성 입력·자막·TTS를 포함하는 종단 간 검증은 완료하지 않았다. A안 화면 표시는 동일 요약 컴포넌트를 사용하는 미리보기에서 확인하고, 실제 대화는 실행 중인 서버의 새 세션에 가상 텍스트 답변을 제출해 확인했다.

미리보기 flow/main.jsx가 기본 에피소드의 character_id와 question_intent를 가져와 주말 시나리오에서 최동료·퇴근 목표를 잘못 표시한다. 이는 A안 본문과 별개인 미리보기 데이터 조합 문제다. 실제 전시 계획은 park_senior와 전시 목표를 사용한다. 이번 요청은 검증이므로 코드는 변경하지 않았다.

거절 뒤 캐묻기는 없었으나 "개인 일정을 밝히고 싶지 않다면 ... 제안은 취소"는 참석 불가보다 정보 비공개를 취소 이유로 연결하는 뉘앙스가 있다. 후반 두 대사는 짧은 수용으로 반복적이다. 성격 적용은 확인됐지만 모든 턴의 자연스러움이 완벽하다고 판단하지 않는다.
