# 극단적 태도에 대한 대사 앞부분 반응

시연 상대역의 system prompt와 이번 발화 안내를 수정했다. 추가 분류 API 없이 기존 대사 생성 안에서 마지막 답변의 표현을 먼저 판단한다. 매우 적극적인 협조에는 구체적인 행동에 대한 만족/반가움, 명백한 욕설·조롱·인신공격·위협에는 해당 표현에 대한 불쾌함/말투 수정 요구를 첫 문장에 말한 뒤 남은 용건으로 이어간다.

보통 수락, 단호하거나 정중한 거절, 비공개, 모름, 짧은 대답은 극단적인 태도로 취급하지 않는다. 표정·목소리·성격을 추측하지 않는다. 사용자가 다시 거절하거나 명확히 중단을 요청하면 추가 요구나 재초대를 하지 않는다. 사람 자체나 능력, 점수를 평가하지 않는다. 실제 점수 계산/판정 모듈은 변경하지 않았다.

태도 분류는 별도 저장하거나 외부에 노출하지 않는 모델 내 판단이며 결정적 분류기가 아니다. 부정확한 음성 전사에는 오판 가능성이 있다. 추가 API 호출이나 강제 응답 재작성은 넣지 않았다.

검증: 관련 백엔드 43개 통과, 기존 점수 즉시 이벤트 기대 검사 1개 제외. 실제 OpenAI API를 두 시나리오 × 적극적 협조/명백한 공격/단순 거절 6개 사례로 점검하고 한 차례 보완했다. 최종 사례 로그: output/persona-attitude-20261015.json. 개발 백엔드 8001 재시작 완료.

소수 사례 검증으로 모든 생성 결과를 보장하지 않는다. 긍정 자기소개 사례에서 1~2문장 지시를 넘어 긴 답변이 나온 사례가 있어 길이 지시는 여전히 모델 의존이라는 제한이 있다.
