# 음성 분석 개정안 구현 기준

기준: `docs/word/음성분석엔진_라이브러리기반_개발계획서_2026-09-17.docx`의 9월 17일 개정안.
범위: 새 체험의 녹음 입력부터 음성 측정·보관·보고서·대화 소비 경로까지. 기존 체험의 점수 의미는 바꾸지 않는다.

## 구현 완료 조건

- [x] 추가 학습 없이 Silero VAD, librosa RMS/pYIN, Praat, 기존 faster-whisper를 실제 실행한다.
- [x] 서버 입력 WAV의 시간축·샘플레이트를 기록하고 VAD용 16kHz 모노 분석본을 만든다. 무음 제거·음량 정규화를 하지 않는다. 브라우저는 기존 MediaRecorder 녹음을 Web Audio에서 PCM WAV로 변환하므로 마이크 원시 PCM과 동일하다고 보장하지 않는다.
- [x] 마이크 테스트에서 주변 소음과 기준 발화를 확인한다. 같은 프레임과 RMS 중앙값으로 답변의 상대 dB를 계산한다.
- [x] 마이크/입력 설정 변경·재연결 시 기준을 무효화하고 재검사를 안내한다. 자동 음량 조절의 실제 적용 상태를 확인한다.
- [x] Whisper 원문과 단어 시각으로 음절 수를 계산한다. 숫자·영어·낮은 전사 품질은 속도를 보류한다. 간투어·반복은 원문 발음량에 포함하되 습관 분석은 응답 영역에만 둔다.
- [x] 발화 사이 멈춤의 시작·끝·길이를 보관한다. 앞뒤 여백, AI 발화, 앱 일시정지 구간은 사용자 멈춤에서 제외한다. 녹음은 답변 업로드·응답 대기 전에 종료한다.
- [x] 높낮이 곡선·중앙값·변화 범위와 유효 구간의 Praat jitter/shimmer를 참고값으로 전달한다. 기존 F0 기반 떨림 지표와 구분한다.
- [x] 각 항목의 measured/uncertain/unmeasured, 사유, 품질, 버전, 세션·답변·보정 ID를 저장한다. 부분 실패는 유효한 다른 항목을 보존한다.
- [x] 미측정은 null, 미확정 라벨은 null이다. 높낮이·발성 불규칙성·간투어를 음성 감점이나 목소리에 대한 AI 지적으로 사용하지 않는다. 답변 내용에 대한 기존 피드백은 별도다.
- [x] 계산과 점수 규칙은 분리한다. 검증된 정책이 없으면 수치만 보고하고 음성 점수는 null로 둔다. 재분석은 같은 답변 결과를 교체한다.
- [x] 답변 분석 대기 상한과 실패 처리를 둔다. 분석이 늦으면 지적 없이 대화를 진행한다.
- [x] 보고서에 수치·측정 불가 이유·참고값을 표시하고 기존 결과와 구별한다.
- [x] 실제 음성 실행, 합성 신호 수학 검증, API 권한·연결·재처리 테스트, 브라우저 흐름, 빌드를 확인한다.

체크는 소프트웨어 구현과 아래 자동 검증을 뜻한다. 전시 장비에서의 성능 승인이나 감점 기준 확정을 뜻하지 않는다.

## 검증 및 운영 기준

감점 경계(크기·속도·긴 멈춤)는 미확정이다. 기존 1.2초/3.5~5.5음절 기준을 승계하지 않는다.
초기 신호 품질 설정은 코드와 버전으로 명시하고 검증용 설정으로 취급한다. 마이크 합격은 적절한 발성이나 화자 식별의 인증이 아니다.
전시장/개인 PC에서의 실제 마이크 거리·소음·다른 사람 목소리·스피커 혼입 및 수동 경계 검수는 별도 현장 검증 기록으로 남긴다.
측정 오차·경계 오차·정밀도·재현율·측정 가능 비율은 근거 없이 성능 수치로 제시하지 않는다.

## 진행 기록

- 2026-09-22: 현재 macOS Python 3.14 가상환경에 librosa 0.11.0, praat-parselmouth 0.4.7, silero-vad 6.2.1 설치 및 실제 실행 확인.
- 새 체험에 `voice-measure-v2`를 적용한다. 시작 전 주변 소음 2초와 기준 문장 10초를 녹음하며, 실패하면 재검사 또는 직접 입력으로 진행한다. 브라우저 입력 설정이 확인되지 않으면 임의로 정상 처리하지 않는다.
- 음성 업로드 대기 상한은 4초, 다음 대사 전 측정 대기 상한은 2초다. 이는 음성 작업의 상한이며 LLM·TTS 등 전체 응답 시간을 보장하는 값은 아니다. 늦은 작업은 세션 상태를 뒤늦게 쓰지 않으며, 최종 분석에서 다시 계산한다.
- 새 결과는 `RoleplaySession.rapport`와 보고서의 `speech_stats.voice_analysis`에 저장한다. 기존 NOT NULL 점수 컬럼에 가짜 점수를 넣지 않는다. 점수 버전은 `interaction-score-v2`로 구별한다.
- 검사 녹음은 임시 파일로 처리한 뒤 삭제한다. 미저장 동의에서는 최종 분석 후 답변 녹음과 중간 전사문을 지우고, 보고서 인용 사본은 기존 `media_retention_days` 정책에 따라 파기한다. 현재 기본값은 7일이며 이번 작업에서 보관 정책 자체는 바꾸지 않았다.

## 마이크 확정 후 진행할 현장 검증

사용자 확인(2026-09-22): 주변 소음이 조금 있으며 마이크는 아직 미정이다. PC 사양과 스피커 사용 여부도 확인되지 않았다.

- [ ] 선정된 PC·마이크, 거리, 입력 설정, 실제 자동 음량 조절 상태를 기록한다.
- [ ] 같은 장비에서 평소/작은/큰 목소리, 느림/평소/빠름 발화, 자연스러운 멈춤을 녹음한다.
- [ ] 주변 대화와 스피커 소리가 섞이는 조건을 검증한다. 현재 VAD는 화자 분리기가 아니므로 답변 중 다른 사람 목소리를 확실히 제거한다고 보장하지 않는다.
- [ ] 발화 경계와 실제 발음 음절 수를 사람이 검수한다. 화자·원본 단위로 기준 조정용과 최종 평가용을 나눈다.
- [ ] 측정 오차·멈춤 정밀도/재현율·측정 가능 비율과 실제 응답 지연을 기록한 뒤 품질 및 감점 경계를 확정한다.

이 검증 전에는 음성 점수와 자동 지적을 켜지 않는다. 마이크 거리 변화는 현재 자동 감지 대상이 아니므로 현장 안내와 재검사 절차도 함께 정한다.
