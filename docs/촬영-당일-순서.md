## 0. 기동 (2분)

```bash
cd ~/Desktop/EXPO && ./start-dev-mac.sh
```

Ollama → 백엔드 8001 → mvp 5173이 한 번에 뜬다. Ctrl+C 한 번으로 전부 종료된다.

## 1. 점검 (1분)

```bash
cd ~/Desktop/EXPO && ./preflight-shoot.sh
```

**GO**가 나와야 촬영을 시작한다. NO-GO면 출력에 적힌 조치를 그대로 따른다.

> 특히 **8001·5173을 다른 워크트리의 서버가 잡고 있는지**를 본다. 겉보기엔 멀쩡한데
> 다른 빌드·빈 DB를 보게 되는 함정이라, 2026-08-01에도 실제로 5173이 다른 체크아웃에
> 물려 축 교체 전 화면이 떴다. preflight가 이 두 가지를 경로까지 찍어 준다.
사람이 눈으로 봐야 하는 항목(어댑터·권한·조명·녹화 설정)은 출력 마지막에 목록으로 나온다.

## 2. 워밍업 완주 1회 — **비교 화면(S12)을 찍으려면 필수** (8분)

비교 화면의 추이 곡선은 완주 기록 **2회 이상**에서만 그려진다. 본 테이크가 1회를 채우므로,
그 전에 **같은 크롬 프로필로** 한 번 끝까지 완주해 둔다. (localStorage의 `client_key`가 유지돼야
기록이 이어진다 — 시크릿 창·프로필 변경·localStorage 삭제 금지.)

- 워밍업은 대충 답해도 된다. 점수가 아니라 "기록이 1건 쌓이는 것"이 목적이다.
- 여유가 있으면 2회 해서 3점 곡선을 만든다(2점은 직선이라 밋밋하다).
- 워밍업이 끝나면 `./preflight-shoot.sh`를 다시 돌려 4번 항목이 ✓로 바뀌는지 확인한다.

## 3. 촬영 (30~40분, 재촬영 포함)

브라우저는 **반드시 이 주소**로 연다:

```
http://localhost:5173/?idle=0
```

`?idle=0`이 없으면 리포트 화면에서 90초만 가만히 있어도 **세션이 지워지고 홈으로 돌아간다.**
내레이션하거나 카메라 각도를 바꾸는 동안 반드시 걸린다.

- ⌘⇧5 → 크롬 창만 선택 → 옵션에서 마이크 ON, 부동 섬네일 끄기, 타이머 5초
- 장면 단위로 끊어 찍는다(발열·실수 복구에 유리)
- 테이크를 다시 갈 때는 "연습 종료"로 정상 종료한다. 새로고침만 하면 이전 세션이 자동 재개돼
  홈 화면 컷을 못 찍는다

## 4. 후반 편집

AI 팀장 음성은 촬영에 안 담긴다(맥 화면 녹화는 시스템 소리를 못 잡는다). 편집에서 얹는다.

1. 촬영본에서 AI 질문 대사를 **화면 자막 그대로** 받아 적어 `대사.txt`에 한 줄씩 저장
   (시나리오 1은 LLM이 답변에 맞춰 문장을 다듬으므로 대사가 테이크마다 다르다 — 사전 제작 불가)
2. 일괄 생성:

```bash
cd ~/Desktop/EXPO && ./make-demo-tts.sh 대사.txt tts-out
```

3. 각 발화 구간 **시작 +1.0초** 지점에 얹는다 (합성 지연 실측 1.01초)
4. 녹화본 마이크 트랙은 싱크 가이드로만 쓰고 음소거 → 내레이션 별도 녹음 후 믹스

## 내레이션 주의 (심사 질의 방어)

S6에서 **"로컬 LLM이 질문을 실시간으로 만듭니다"라고 말하지 않는다.** 실제 구조는 사람이 쓴
시나리오 질문을 LLM이 답변에 맞춰 **다듬는** 것이고, 실측상 턴의 31~44%는 LLM을 아예 거치지 않는다.
대본에 적힌 정정된 문장을 그대로 쓴다.
