## 실행 환경과 데이터 보존

기존 백엔드 `.env`, 가상환경, Whisper 모델, SDK 실행 도구와 외부 분석 모델 연결을 현재 작업본으로 옮겼습니다. 이동한 Python 실행 경로와 Node 의존성 연결을 확인했습니다. 비밀 설정과 대용량 모델은 Git에 포함하지 않습니다.

이전 main의 SQLite DB는 `poc/backend/data/retained-main/`에 별도로 보존했습니다. `mirror-ting.db`는 WAL 내용을 포함해 SQLite backup API로 보존했고, 현재 서비스 DB는 교체하지 않았습니다. 이 폴더와 테스트 SQLite 임시 파일·생성 로그·브라우저 검증 증거는 Git에서 제외합니다.
