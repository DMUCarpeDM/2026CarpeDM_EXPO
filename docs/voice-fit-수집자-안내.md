# Voice-Fit 수집자 안내

## 바로 시작하기

1. 조용한 장소에서 진행한다.
2. 마이크와 입 사이를 손 한 뼘 정도로 맞춘다.
3. 아래 문장 중 하나와 목소리 상태 하나를 고른다.
4. 참가자에게 고른 상태로 문장을 한 번 읽게 한다.
5. 다음 샘플에서는 다른 문장 또는 다른 목소리 상태로 넘어간다.

한 번 읽을 때는 목소리 상태를 하나만 넣는다. 예를 들어 빠르게 말하는 샘플에 “음…”을
넣거나, 중간에 멈추지 않는다.

## 읽을 문장

아래 네 문장을 고르게 사용한다.

1. “현재 상황을 확인한 뒤 오후 세 시까지 다시 공유드리겠습니다.”
2. “불편을 드려 죄송합니다. 우선 원인을 확인하겠습니다.”
3. “대안을 정리해서 오늘 안에 말씀드리겠습니다.”
4. “제가 담당자와 확인하고 진행 상황을 알려드리겠습니다.”

## 한 문장을 녹음하는 순서

1. 수집자가 목소리 상태 하나와 문장 하나를 고른다.
2. 참가자에게 어떤 방식으로 읽을지 짧게 말해 준다.
3. 참가자가 1초 준비한 뒤 문장을 처음부터 끝까지 한 번 읽는다.
4. 수집자가 다음 문장 또는 다음 목소리 상태를 고른다.

## 목소리 상태와 참가자에게 할 말

### 말하는 속도

| 수집 이름 | 참가자에게 이렇게 말하기 |
| --- | --- |
| 평소처럼 말하기 | “평소 대화할 때처럼 편하게 읽어 주세요.” |
| 빠르게 말하기 | “발음이 뭉개지지 않는 선에서 평소보다 분명히 빠르게 읽어 주세요.” |
| 천천히 말하기 | “단어를 끊지는 말고, 평소보다 분명히 천천히 읽어 주세요.” |

### 말버릇과 멈춤

| 수집 이름 | 참가자에게 이렇게 말하기 |
| --- | --- |
| “음…” 넣기 | “문장 중간에 ‘음…’ 또는 ‘어…’를 한 번만 넣고 끝까지 읽어 주세요.” |
| 다시 말하기 | “짧은 구절을 한 번 말한 뒤, 그 구절부터 다시 말하며 이어서 읽어 주세요.” |
| 중간에 멈추기 | “문장 중간에서 약 1.5초 멈췄다가 이어서 읽어 주세요.” |

### 목소리 크기와 변화

| 수집 이름 | 참가자에게 이렇게 말하기 |
| --- | --- |
| 작은 목소리 | “속삭이지는 말고, 들리지만 평소보다 작은 목소리로 읽어 주세요.” |
| 목소리 변화 | “목에 힘을 주지 말고, 높낮이나 크기가 조금 바뀌게 읽어 주세요.” |

목소리를 억지로 떨게 하거나 목에 힘을 주지 않는다. 목이 불편하면 바로 멈춘다.

## 녹음 횟수

1. 한 사람당 목소리 상태 하나를 25번씩 녹음한다.
2. 목소리 상태가 8개이므로, 한 사람당 총 200번을 녹음한다.
3. 한 사람을 녹음하는 데 약 35~45분 걸린다.
4. 20명을 녹음하면 목소리 상태마다 500개, 전체 4,000개를 만들 수 있다.

## 녹음 예시

1. 수집자가 “중간에 멈추기”와 첫 번째 문장을 고른다.
2. 참가자에게 “문장 중간에서 1.5초 멈췄다가 끝까지 읽어 주세요”라고 말한다.
3. 참가자가 문장을 한 번 읽는다.
4. 수집자는 다음 문장이나 다음 목소리 상태를 고른다.
