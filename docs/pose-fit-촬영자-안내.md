# Pose-Fit 촬영자 안내

## 바로 시작하기

1. 카메라를 참가자 눈높이에 맞춘다.
2. 카메라와 참가자 사이를 1.5~2m로 맞춘다.
3. 화면에 머리부터 발끝, 양쪽 어깨와 손이 모두 보이게 한다.
4. 화면에는 참가자 한 명만 나오게 한다.
5. 참가자가 카메라를 보고 편하게 서도록 한 뒤 촬영을 시작한다.

## 한 자세를 촬영하는 순서

1. 아래 표에서 촬영할 자세를 하나 고른다.
2. 참가자가 먼저 정면으로 편하게 선다.
3. “시작”이라고 말한 뒤, 안내한 자세만 3~5초 동안 하게 한다.
4. 촬영이 끝나면 참가자를 다시 정면 자세로 돌아오게 한다.
5. 다음 자세를 골라 같은 방법으로 촬영한다.

한 영상에는 자세를 하나만 담는다. 예를 들어 팔짱을 낀 촬영에서는 고개를 숙이거나 몸을
흔들지 않는다. 참가자가 아프거나 어지러우면 바로 멈춘다.

## 촬영할 자세와 참가자에게 할 말

### 기본 자세

| 촬영 이름 | 참가자에게 이렇게 말하기 |
| --- | --- |
| 정면으로 편하게 서기 | “카메라를 보고, 팔을 자연스럽게 내린 채 서 주세요.” |
| 고개 숙이기 | “눈만 내리지 말고, 고개를 살짝 아래로 숙여 주세요.” |
| 옆으로 기울기 | “몸통을 왼쪽 또는 오른쪽으로 살짝 기울여 주세요.” |
| 앞으로 기울기 | “허리를 많이 굽히지 말고, 상체만 살짝 앞으로 기울여 주세요.” |
| 뒤로 기울기 | “넘어지지 않는 범위에서 상체만 살짝 뒤로 기울여 주세요.” |

`옆으로 기울기`는 왼쪽과 오른쪽을 비슷한 횟수로 촬영한다.

### 행동 자세

| 촬영 이름 | 참가자에게 이렇게 말하기 |
| --- | --- |
| 몸 흔들기 | “상체를 왼쪽과 오른쪽으로 천천히 한 번 이상 움직여 주세요.” |
| 팔짱 끼기 | “자연스럽게 팔짱을 끼고 서 주세요.” |
| 손을 얼굴에 대기 | “손을 볼이나 턱 근처에 가볍게 대 주세요.” |
| 큰 손동작 하기 | “가슴 아래쪽에서 양손을 평소보다 크게 움직여 주세요.” |
| 가볍게 끄덕이기 | “카메라를 보면서 작게 두세 번 끄덕여 주세요.” |

## 촬영 횟수

1. 한 사람당 자세 하나를 20번씩 촬영한다.
2. 자세가 10개이므로, 한 사람당 총 200번을 촬영한다.
3. 한 사람을 촬영하는 데 약 40~50분 걸린다.
4. 25명을 촬영하면 자세마다 500개, 전체 5,000개를 만들 수 있다.

## 촬영 예시

1. 촬영자가 “팔짱 끼기”를 고른다.
2. 참가자가 정면으로 선다.
3. 촬영자가 “시작”이라고 말한다.
4. 참가자가 팔짱을 낀 채 3~5초 동안 선다.
5. 촬영이 끝나면 참가자가 다시 정면으로 선다.
