# GTX 1060 Iris TTS 실측 — 2026-10-12

GTX 1060 6 GB / Windows / torch 2.8.0+cu126 / Qwen3-TTS 0.6B Base에서
Iris 원본 음색 프로필과 전체 ICL 참조를 유지한 결과다. FP32/SDPA를 유지했고
양자화, 문장 생략, 재생 배속을 사용하지 않았다. 모든 수치는 한 번의 실측이며
샘플링에 따른 음성 길이와 전시 화면의 GPU 부하에 따라 달라질 수 있다.

## 변경

- Faster Qwen 0.3.2 CUDA Graph, 512 토큰 고정 캐시.
- 약 1.2 GB의 텍스트 임베딩을 CPU에서 조회하고 필요한 행만 GPU로 복사.
- 준비된 프로필 생성에 필요 없는 speaker/codec encoder를 CPU에 보관.
- 로드·예열·추론을 전용 CUDA 작업 스레드 하나에서 실행.
- 생성 후 미사용 GPU 할당 캐시를 반환하고, 서버 시작 시 실제 합성으로 예열.
- 고정 캐시 용량 부족 또는 잘림 의심 시 같은 모델의 일반 생성으로 재시도.
- WAV/스트림이 하나의 모델을 재사용하며 동시 추론을 제한.

## 실제 Gemini 문장별 검증

Gemini가 만든 답변에서 문장 경계로 나눈 완전한 문장을 `force_regenerate=true`로 합성했다.
첫 소리까지의 시간이 아닌 문장 전체의 생성 시간이다.

| 문장 | 합성 | 재생 길이 | 3초 목표 |
| --- | ---: | ---: | --- |
| 오, 오전 열한 시요? | 1.545초 | 1.20초 | 충족 |
| 벌써 그렇게 잡았어요? | 1.850초 | 1.52초 | 충족 |
| 그럼 그 초안 나한테도 바로 보내줘요. | 3.431초 | 2.56초 | 미달 |

새 Gemini 전체 답변 “아, 열 시 반까지요? 그럼 그거 먼저 보고 정리해서 이따 저한테 바로 알려줘요.”는
Gemini 생성 1.997초, Iris 합성 7.174초, 재생 길이 6.16초였다. Gemini fallback은 0회다.
**모든 문장과 전체 답변의 3초 달성은 확인되지 않았다.**

연속 요청 후 GPU 사용량은 4,707 MiB, 여유는 1,323 MiB였다.
모든 WAV는 24 kHz, 유한한 비무음 파형이다. 새 답변과 위 세 문장의 Whisper 전사에서
끝부분 누락은 없었다. 기준 긴 답변의 “훑어보고”는 자동 전사가 다르게 인식했으므로
전사 결과만으로 발음·음색의 완전한 품질을 보장하지 않는다. 실제 스피커 청취는 별도다.
