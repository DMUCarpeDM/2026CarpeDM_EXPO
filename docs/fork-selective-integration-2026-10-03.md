# 포크 변경 선택 통합

기준: 원본 main ff65417, kwakminoo/main 2354c06.

## 반영

- Ollama를 대화 제공자로 선택할 수 있게 연결. 기존 장면 검증, 평가 목표, 면접·카페 흐름은 유지.
- Iris 음성 런타임을 선택할 수 있게 연결. 기존 ElevenLabs 기본값과 브라우저 음성 폴백은 유지.
- 모델 태그가 정확히 설치됐는지 확인. 설정된 대기 상한과 오류 처리를 사용.

## 반영하지 않음

직장대화·감정 영상은 main에 이미 있음. 포크의 화면 덮어쓰기, 음성 분석·면접 평가 코드 제거, Gemini 접근 확인 제거, 남성 음성 차단, MIT 라이선스 추가는 제외함.

## 사용 설정

실제 .env는 변경하지 않음. 기본 제공자도 바꾸지 않음.

Ollama를 사용하려면 MIRROR_TING_DIALOGUE_PROVIDER=ollama로 설정하고 MIRROR_TING_OLLAMA_MODEL에 실제 설치한 모델의 정확한 태그를 입력함. 특정 Gemma 모델의 설치나 성능을 보장하지 않음. 답변 내용 분석의 OpenAI 의존성은 기존대로 유지됨.

Iris를 사용하려면 별도 음성 런타임을 준비한 뒤 MIRROR_TING_TTS_PROVIDER=iris로 설정함. MIRROR_TING_IRIS_VOICE_BASE_URL은 런타임 주소, MIRROR_TING_IRIS_AUDIO_DIR은 해당 런타임이 반환하는 WAV가 저장된 디렉터리임. 백엔드가 그 디렉터리를 읽을 수 있어야 함. 원격 런타임을 쓰면 공유 볼륨이 필요함.

Iris 선택 시 현재 단일 서버 음성 경로에 적용됨. 성별별 음성 선택 기능은 이번 통합 범위가 아님. 기본 대기 상한은 20초이며 실패하면 기존 프런트의 브라우저 음성 폴백을 사용함.

실제 모델 및 Iris 런타임의 지연·음질은 장비에서 별도 확인해야 함. 자동 테스트는 네트워크를 모의 처리함.
