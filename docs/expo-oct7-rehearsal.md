# 10/7 로컬 통합과 오늘의 리허설

현재 원격 미러 main `1ffb9fa`를 기준으로 10/6 로컬 수정 `7a46fbc`를 통합한 브랜치는 `codex/expo-oct7-integration`이다. 팀원의 픽셀 오피스, 자동 장면 안내, 동의·발급 횟수 검증, 마이크 화면 및 가독성 변경을 보존했다. 키오스크 계약 검사는 원격 main `7c2d01e`와 별도 검증된 로컬 `eed4c4523ca67720569924504df4604c6d4087df`의 실제 앱으로 수행한다. 원격 반영과 운영 배포는 하지 않는다.

## 이번 호환 수정

- IDPrinter는 미러의 동의·발급 횟수를 제공하지 않는다. 해당 카드의 UID·kiosk 방문 회차를 유지하고 체험 역할을 선택한 뒤 미러에서 직접 동의받는다. 동의 후 기존 43초 장면 안내와 자동 시작이 이어진다. 이 경로가 완전히 무접촉이라는 설명은 하지 않는다.
- 기존 미러 발급 카드의 동의·발급 횟수 검증은 그대로 유지한다. 외부 카드에 미검증 로컬 발급 횟수를 섞어 보내면 서버가 거부한다. 동의 없는 요청, UID 없는 방문 회차, 재발급된 스냅샷도 거부한다.
- 새 카드 태그와 미러의 결과 idle 복귀에서 이전 세션·결과·기록·client key·동의·장치 스트림을 정리한다. 미러는 기존 대기 홈으로 복귀하면서 서비스 선택을 유지한다. 이전 방문자의 늦은 응답은 새 방문자 상태를 복구하지 못한다.
- 자동 시작의 중복 요청 잠금과 방문자 변경 취소를 함께 유지한다. 실제 미러 모드에서 카메라와 마이크가 모두 준비되지 않으면 세션을 생성하지 않는다.
- 모델 준비 스크립트는 중단된 다운로드를 완료 파일로 저장하지 않고, 임시 파일·길이 확인·전체/유휴 시간 제한을 사용한다. 불완전한 기존 모델도 준비 완료로 처리하지 않는다.

## 가장 작은 무장비 검사 경로

양쪽 Python 의존성이 이미 설치된 환경에서:

```sh
cd poc/backend
python scripts/rehearse_expo.py \
  --printer-root /absolute/path/to/CarpeDM_EXPO_IDPrinter \
  --output /absolute/path/to/rehearsal-result.json
```

이 명령은 실제 두 앱의 API·SQLite·인증·결과 정규화를 사용하며, NFC 읽기·캐릭터 결과·서버 간 transport·화면 출력은 모의 처리한다. 유료 키는 비우고 모든 Python outbound socket을 차단한다. 테스트 DB·미디어·캐시는 임시 경로에서 삭제하며 서버를 계속 띄우지 않는다. 정확한 양쪽 Git revision과 검사 결과를 JSON에 남긴다.

검사 범위: 동의 없음 거부, 기존 카드 동의·재발급 검증, 외부 카드 회차 불일치, 링크 장애→같은 세션 재연결, 잘못된 토큰, 완료 전 pending, 무키 대체 대화→결과, 중복 화면 출력 방지, 카드 재사용 후 이전 결과 차단.

브라우저의 핵심 동작은 아래로 별도 확인한다. 검사에 Chrome 가상 장치를 사용하며 실물 장치는 사용하지 않는다.

## 실제 장비 리허설 조건

- 일반 무장비 UI 경로는 `?service=workplace`다. 운영 미러 경로는 `?service=workplace&mirror=1`이며 NFC·동의·카메라·마이크 조건이 필요하다. 샘플 화면이나 고정 데이터 화면은 서버 간 리허설이 아니다.
- 실제 키오스크와 미러의 주소 및 동일 bridge token을 서버에 설정한다. 프론트엔드와 로그에는 토큰을 넣지 않는다. 현재 사용자에게 보이는 키오스크 4187과 별도 백엔드 8013은 이 작업에서 보존했다.
- OpenAI 답변 근거 분석과 유료 생성/TTS는 키 설정과 별도 호출 승인을 요구한다. 무키 대체 대화는 실제 개인화·근거 채점 성공을 입증하지 않는다.
- 실제 E5 최종 가중치는 팀에서 준비해야 한다. 다른 기본 E5 모델로 대체하지 않는다. Whisper 파일은 준비·로딩 여부와 실제 받아쓰기 품질을 구분한다. MediaPipe도 자산 로딩과 실제 사람 검증을 구분한다.
- Voice 점수는 현재 정책상 null이고 Expression 공통 판단 연결은 미완료다. 미측정 값을 점수로 채우지 않는다.
- 카드 A→대화→결과→퇴근→실제 종이, 카드 재발급 B, 연결/USB/전원/용지 장애, 커터, 재부팅 인수를 완료해야 현장 완성으로 표시할 수 있다.
