# AI 마스터리 플랜 — 4-Fit + 교차 분석을 최고 수준으로

> 목표: "게임 수준"이 아니라 **측정을 신뢰할 수 있고, 코칭이 사람을 실제로 놀라게 하는 AI**.
> 제약 유지: 외부 API 키 0, 온디바이스/로컬, Python 3.14(numpy DSP), 폴백 우선.
> 원칙: 순서대로 하나씩. 각 단계는 평가 하네스로 **개선을 증명**하고 넘어간다.
>
> **진행: ⓪①②⑤⑥ 완료 · ③④ 헤드리스 구현 완료** — 남은 것은 실기기 검증
> (임계 보정·부호/스케일 확인, 7/14~18 가조립 주간)과 ④ 수직 홍채·완전한 다인 배제

---

## 실행 순서와 근거

```
⓪ 평가 감독관     ← 심판 먼저. 이후 모든 업그레이드는 측정된 개선이어야 한다
① Voice 마스터    ← 데모 임팩트 최대 + 헤드리스 완전 검증 가능 + ②의 재료 생산
② Response 마스터 ← ①의 텍스트-음성 정렬을 소비, 의미 매칭으로 도약
③ Posture 마스터  ← 실기기 검증 필수 → 하드웨어 가조립 주간(7/14~18)과 동기화
④ Eye 마무리      ← 1차 심화 완료 상태. 수직 홍채·히트맵·다인 배제 마무리 패스
⑤ 표정 관찰 레이어 ← blendshape 조합 지표 (진정성 미소 등) — 짧은 패스
⑥ 교차 분석 마스터 ← ①~⑤의 신규 지표 전부를 소비하므로 반드시 마지막
```

순서를 정한 세 가지 논리:
1. **심판 먼저** — 평가 기준 없이 지표를 더하면 "많아 보이는 AI"가 되지 "좋은 AI"가
   되지 않는다. 골든 케이스 셋이 모든 후속 작업의 합격선이다.
2. **검증 가능성 순** — Voice·Response는 합성 신호·텍스트로 헤드리스에서 완전
   검증된다. Posture·Eye의 잔여 작업은 실기기가 필요하므로 하드웨어 일정에 붙인다.
3. **의존성 순** — 텍스트-음성 정렬(①)은 Response(②)의 재료다. 교차 분석(⑥)은
   모든 Fit의 지표를 소비하므로 마지막이 아니면 두 번 만들게 된다.

---

## ⓪ 평가 감독관 (Evaluation Lead) — 0.5일 ✅ 완료

**최고 수준의 정의**: 모든 판정에 "이 케이스에서 이렇게 판정해야 한다"는 정답표가 있고,
어떤 변경도 회귀 없이 통과해야 머지된다.

- **골든 응답 셋 40+**: 좋은/나쁜/경계 답변 텍스트 × 에피소드별 기대 판정
  (케이스·커버리지 범위·담화 지표 방향). 경계 케이스에 힘을 준다 —
  "짧지만 완벽한 답", "길지만 동문서답", "내용은 맞는데 반말".
- **합성 음성 시나리오 확장**: 현재 개별 지표 검증을 넘어 "시나리오 신호"
  (떨리는 사과 → 안정된 보고)를 만들어 종합 판정을 검증.
- **판정 일관성 리포트**: 같은 입력 반복 시 판정 분산 0 확인 (랜덤 요소 격리).
- 산출물: `backend/tests/golden/` + `test_golden_responses.py` — 이후 모든
  단계의 착륙장.

## ① Voice-Fit 마스터 (음성분석가) — 1일 ✅ 완료

**최고 수준의 정의**: "목소리가 떨렸다"가 아니라 **"어느 문장에서, 무엇을 말할 때
떨렸는지"**를 짚는다.

- **텍스트-음성 정렬 (핵심)**: Vosk가 이미 서버에 있고 단어 타임스탬프를 출력한다
  → DSP 프레임을 단어·문장에 정렬 → 문장별 성량/피치/속도 프로파일.
  코칭이 이렇게 바뀐다: "사과 문장에서 성량이 27% 떨어졌어요 — 사과일수록
  또렷하게 말해야 진심으로 들려요."
- **소음 강건 VAD**: 현재 에너지 임계 방식은 전시장 소음에 취약 →
  스펙트럼 엔트로피 + 적응 임계값(numpy)으로 교체. 전시 생존성 직결.
- **문장 단위 프로소디**: 문장별 F0 레인지 → 강조 능력("핵심 문장을 강조했는가"),
  단조로운 문장 나열 감지.
- **간투어 감지**: 전사에서 "음/어/그" 밀도 (Vosk 전사 기준, 근사임을 명시).
- 검증: 합성 신호(문장 경계에 침묵 삽입 + 구간별 진폭 변조) + 골든 셋.

## ② Response-Fit 마스터 (NLP 전문가) — 1일 ✅ 완료

**최고 수준의 정의**: 키워드가 아니라 **의미**를 이해한다. "고객께 사과드립니다"가
'사과' 키워드 없이도 사과로 인식된다.

- **로컬 임베딩 의미 매칭 (핵심)**: Ollama `/api/embeddings`(로컬, API 키 무관)로
  체크리스트 항목 설명 ↔ 응답 문장 코사인 유사도 → 패러프레이즈 커버리지.
  키워드 매칭과 OR 결합, Ollama 부재 시 완전 폴백 (기존 대화 엔진과 동일 패턴).
- **인용 근거 선택**: 리포트의 "이 문장이 좋았어요/아쉬웠어요"를 문장 단위
  점수(체크리스트 기여 + 위험 표현 + ①의 음성 프로파일)로 자동 선택 —
  지금은 턴 단위 인용이라 뭉툭하다.
- **청자 배려 화법(You-attitude)**: "제가 못 해요" vs "이 조건에서는 ~까지
  가능합니다" — 부정 표현의 긍정 재구성 여부 감지.
- **완곡 명령 감지**: 상사/동료에게 지시형 어미를 쓰는 실수.
- 검증: 골든 셋에 패러프레이즈 케이스 10개 추가 — 키워드 매칭이 놓치고
  의미 매칭이 잡아야 통과.

## ③ Posture-Fit 마스터 (동작분석가) — 🔶 헤드리스 구현 완료 (실기기 검증 남음)

**최고 수준의 정의**: 카메라 거리·각도가 달라져도 같은 자세는 같은 판정.

- ✅ **3D 월드 랜드마크 전환 (핵심)**: worldLandmarks(미터·골반 원점)로 어깨
  기울기 계산 — 거리 불변 + 수평 성분에 z 포함으로 몸이 비스듬히 서도(yaw)
  왜곡 없음. 월드 부재 시 기존 2D 폴백, `world_ratio`로 가동률 보고.
- ✅ **제스처 에너지**: 손목 평균 속도(m/s, 골반 원점이라 몸 이동과 무관) +
  활동 비율 → 경직(활동≤5%)·과다(≥70%+0.5m/s) 습관 카드, composure '제스처
  위축'(압박에서 얼어붙음) 프로브. 표본 5초 미만 보류(null).
- ✅ **가시성 신뢰 게이트**: visibility 0.5 게이트 — 손이 안 보이면 경직 판정
  자체를 보류, 하체(무릎) 가시성으로 스탠딩 미러/데스크 웹을 자동 구분.
- ✅ **전신 확장**: 골반 중심 좌우 흔들림(어깨너비 정규화) → 체중 이동 습관
  카드 (하체 가시 ≥50%일 때만 판정).
- 🔶 **다인 배제**: 경량 가드 구현 — 어깨 중심·폭이 한 샘플에 급변하면 그
  프레임의 자세 집계 폐기(`guard_dropped_frames`로 투명 보고). 완전한 최대
  크기 얼굴/포즈 잠금은 실기기 주간에 (Eye와 공동).
- ✅ **경청 자세 레이어 (정밀화 패스)**: Eye의 듣기/말하기 분리와 동형 —
  · 끄덕임 근사: 듣기 중 headGap 상하 반전(진폭 ≥4% 어깨너비 게이트).
    몸 전체 출렁임은 코·어깨가 함께 움직여 상쇄됨. **긍정 신호 전용**
    (끄덕임 없음은 지적하지 않는다 — 문화·개인차, 오탐해도 칭찬이라 피해 최소)
  · 듣기 리닝: 캘리브레이션 어깨폭 기준 듣는 동안 전진(+, 경청 칭찬)/후퇴
    (-, 거리두기 관찰) % — composure '듣기 자세' 프로브(압박에서 몸 물러남)
- ✅ **score_posture v2**: 자세 유지력(tilt_drift — 후반 붕괴) 통합, 가중 0.15.
  음수 드리프트(개선)는 감점하지 않음. v1 페이로드 하위 호환. 이번 신설 관찰
  지표(제스처·골반·경청)는 원칙대로 점수 밖 유지 — 실기기 보정 후 승격 검토.
- 남은 검증(실기기, demo-checklist §2.5): 경직/과다/체중 이동 임계 보정,
  3D 기울기 부호·스케일, 다인 가드 실측. 서는 위치 3곳 × 자세 5종 프로토콜.

## ④ Eye-Fit 마무리 (시선분석가) — 0.5일

1차 심화(홍채 보상·듣기/말하기 분리·응시 리듬·개시 관용) 완료 상태. 남은 것:
- ~~**수직 홍채**~~ ✅ 완료: 눈꺼풀 사이 홍채 상하 위치(0=위, 1=아래)를 기준
  보정해 상하 판정의 주 신호로 승격. 수평과 달리 이미지 y축은 부호가 기하적으로
  명확. 눈 열림 게이트(눈 너비 15%)로 깜빡임·실눈 표본 배제, 두 방향으로 작동 —
  미세한 아래 훔쳐보기 정밀 감지(Δ0.25) + 홍채 중앙인데 blendshape만 높은 실눈
  오작동 구제(Δ0.05). 시선 존 히트맵 상하 행도 홍채화. `iris_v_ratio` 가동 보고.
- ~~**시선 존 히트맵 시각화**~~ ✅ 완료: `fit_scores.eye.gaze_map` — 세션 합산 3×3
  비율 지도(표본 10초 미만 보류), 웹 리포트 Eye 카드에 발열 그리드 렌더링.
  코멘트는 상하·중앙만 단정, 좌우는 실기기 부호 검증 전이라 '옆'으로 중화.
- ~~**깜빡임 동역학**~~ ✅ 완료: 브리핑 캘리브레이션에서 개인 기저선 산출(표본
  10초 미만 보류) → 리포트 판정을 '본인 대비 1.6배 급증'으로 승격. 기저선이
  있으면 상대 판정만 적용해 기저 높은 사람을 절대 임계(32)의 오판에서 구제하고,
  없으면 절대 폴백. 2초 빈 타임라인(moments) 연동은 깜빡임이 빈당 0~2회로
  희소해 오판 위험 → 의도적으로 제외.
- 🔶 **다인 배제**: 얼굴 가드 구현 — 얼굴 중심·크기가 한 샘플(200ms)에 급변하면
  그 프레임의 시선·표정 집계를 통째로 폐기(③의 자세 가드와 동형, 같은
  `guard_dropped_frames` 카운터). 완전한 최대 크기 얼굴 잠금은 실기기 주간에.
- 실기기 부호 검증 프로토콜 (§2.5 — 수평 홍채·히트맵 좌우·수직 홍채).

## ⑤ 표정 관찰 레이어 (표정분석가) — 0.5일 ✅ 완료

- **진정성 미소 근사(Duchenne proxy)**: mouthSmile + eyeSquint 동시 활성 여부 —
  입만 웃는 "서비스 미소"와 눈까지 웃는 미소 구분. 관찰 지표.
- **표정 전환 속도**: 압박 질문 직후 표정 복구 시간 — 교차 분석 재료.
- 원칙 유지: 전부 감점 없는 관찰 + 외모 지적으로 오독되지 않는 문구 가이드.
- 구현 결과: `smile_duchenne_ratio`(미소 중 눈 참여, 미소 표본 2초 미만 보류=null) ·
  `expr_recover_sec`(긴장 표정 에피소드 평균 지속 초, 깜빡임 중 eyeSquint 오판 제외) ·
  타임라인 긴장 빈에 찡그림 통합(moments '긴장 표정' 재료) · composure '표정 복구
  시간' 프로브(악화 지표 우선 표시) · 습관 카드 2종(의례적/진정성 미소, 상한 유지).
  eyeSquint 임계 0.35는 합성 검증 불가 → 실기기 보정 항목(demo-checklist §2.5).

## ⑥ 교차 분석 마스터 (코칭 과학자) — 1일 ✅ 완료

**최고 수준의 정의**: 턴 단위 평균이 아니라 **순간**을 잡는다.

- **시간 정렬 이벤트 스트림 (핵심)**: 모든 지표를 (시각, 지표, 값) 이벤트로 통합
  → "압박 질문 직후 3초: 시선 이탈 + 피치 떨림 + 침묵"처럼 순간 단위 패턴 포착.
  ①의 문장 정렬 + ④⑤의 동역학 지표가 재료.
- **코호트 백분위**: 현장 DB 축적 데이터로 지표별 백분위 ("말속도가 오늘 체험자
  중 상위 12%") — 표본 20+부터 활성화.
- **신뢰도 라벨**: 각 렌즈·지표에 표본 크기 기반 신뢰 등급(확실/참고/보류) 표기 —
  전문가는 모르는 것을 모른다고 말한다.
- **재방문 성장 델타**: 체험 코드 재방문 시 "지난번 동요형 → 이번 회복형" 서사.
- 검증: 골든 시나리오(⓪)의 종합 판정 + 합성 세션 재생 테스트.
