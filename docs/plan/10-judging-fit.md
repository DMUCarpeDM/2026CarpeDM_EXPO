# ⑩ 심사 기준 대조 — 지금 우리는 몇 점짜리인가

> 작성 2026-07-26 (D-9) · 기준 출처: Notion 「평가 대응」 2026-07-23 갱신 \[공식 공지\]
> **경고: 이 문서는 앞선 ⑧·⑨의 전제 하나를 뒤집는다.** 재기획은 10월 본전시를 전제로 짰는데, **9일 뒤 선정심사가 먼저 있다.**

## 0. 결론 세 줄

1. **지금 우선순위가 틀렸다.** 8/4 선정심사(D-9)를 통과 못 하면 10월 대상은 논의 자체가 없다. 블록 2(시나리오 설계)는 선정심사 뒤로 미뤄야 한다. **[높음]**
2. **라이브 데모가 금지다.** 개인 노트북 연결 불가 → 지금까지 강조한 "부스 30초 머니모먼트"는 **10월용**이고, 8/4는 **시연영상 한 편이 전부**다. 전략의 매체가 다르다. **[높음 — 공식 공지]**
3. 5개 항목 중 우리가 약한 곳은 **발표력**과 **완성가능성**인데, 이 둘이 **합계 40점(전체의 40%)**이다. 기술 추가 개발은 지금 시점에 득점력이 가장 낮다. **[중간]**

## 2. 항목별 대조

평가는 **강/중/약** 3단계. 점수 예측은 하지 않는다(근거 없음).

### 작품성 (20) — **강**

| 근거 | 상태 |
|---|---|
| 웨이크 → 역할극 → 분석 → 리포트 → QR 전 구간 동작 | 구현됨 |
| 하프미러 폼팩터 + "거울 문법"(검정=거울, 반사 존, 프레임 글로우) | 기획 완료, **실물 미제작** |
| 세계관 완결성(㈜클라우드밋, 캐릭터 4인, 에피소드 5개, 결말 3분기) | 시드 구현됨 |
| 2단 한 문장으로 정체성 응집 (⑨) | 확정 |

**갭**: ⓪ 진단서가 지적한 *"기능 모음으로 읽힐 위험"*은 ⑨의 한 문장 확정으로 상당 부분 닫혔다. 남은 것은 **시연영상이 이 응집을 5분 안에 보여주느냐**다.

### 기술성 (20) — **강. 단, 정합성 리스크 있음**

| 근거 | 상태 |
|---|---|
| 온디바이스 7모듈, API 키 0개, 오프라인 동작 | 구현됨 |
| numpy 직접 구현 음성 DSP(librosa 미사용), 옥타브 오류 수리, 스펙트럼 평탄도 VAD | 구현됨 |
| 멀티모달 시간축 정렬(결정적 순간) + 회귀 테스트 | 구현됨, 264개 테스트 |
| LLM→템플릿, Whisper→Vosk 3중 폴백 | 구현됨 |

> **⚠️ 정합성 리스크 — 즉시 정리 필요.**
> Notion 「평가 대응」의 기술성 대응란은 **"Kinect 3D + 음성 + LLM"**이라고 적혀 있다. 그러나 리포지터리의 실제 구현은 **MediaPipe(웹캠)** 기반이고, Kinect 관련 코드는 없다. 제출된 계획서 PDF도 **FHD 웹캠 + MediaPipe**로 적혀 있다.
> → 발표에서 Kinect를 말하면 "그 코드 어디 있나"에 답할 수 없다. **8/3 전에 셋 중 하나로 통일**할 것. **[높음 — 코드·PDF 확인]**

### 창의성 (20) — **강**

| 근거 | 상태 |
|---|---|
| "합격 전(면접)이 아니라 합격 후(첫 출근)" — 작년 출품작(AI 면접)과 정면 대비 | 확정 (⑧·⑨) |
| "어떻게 말했나"가 아니라 "대화가 통했나"를 채점 | 구현됨 |
| 말·목소리·시선·자세를 같은 시계축에 정렬해 **무너진 순간을 발화 인용과 함께** 제시 | 구현됨 (`moments.py`) |
| 한국 직장 화법 도메인 + 미러 폼팩터 | 시드 + 기획 |

**이 항목이 가장 유리하다.** 특히 작년작 대비가 명확해져 "또 AI 면접이네"라는 인상을 선제 차단할 수 있다.

### 발표력 (20) — **약** ⚠️

| 필요한 것 | 상태 |
|---|---|
| 5분 발표 스크립트 | **없음** |
| 시연영상 | **없음** |
| Q&A 5분 예상질문 답변 시트 | 부분(Notion 경쟁분석·평가대응에 산재, **통합 안 됨**) |
| PDF 제출본 | **없음** (마감 8/3 13:00) |
| 3단 리허설 | **미실시** |

**여기가 최대 취약점이다.** 20점 항목인데 착수조차 안 됐고, 마감이 8일 남았다.

### 완성 가능성 (20) — **중**

| 근거 | 상태 |
|---|---|

## 3. 라이브 데모 불가가 바꾸는 것

지금까지 ⑧에서 강조한 논리는 **"차별화가 부스 30초에 보여야 한다"**였다. 이건 **10월 본전시에서는 유효하지만 8/4에는 적용되지 않는다.**

| | 8/4 선정심사 | 10월 본전시 |
|---|---|---|
| 매체 | **시연영상 + PDF 슬라이드** | 실물 미러 부스 |
| 심사위원 체험 | 불가 | 가능(60초 대본) |
| 승부처 | **영상 편집·발표 전달** | 체험 설계·부스 운영 |
| 배선 복구(T0) 필요성 | **영상은 POC 프론트로 촬영하면 우회 가능** | 필수 |

> **중요한 우회로**: 전시용 MVP 프론트는 `timeline`·`answer_offset_sec` 등을 안 보내서 "결정적 순간"이 반쪽이지만(⑧ §1), **POC 프론트는 전부 보낸다.** 따라서 **8/4 시연영상은 POC 프론트로 촬영하면 결정적 순간이 온전히 나온다.** T0 배선 복구를 8/4 전에 못 끝내도 영상 품질은 확보된다.
> 단 이 경우 **영상과 10월 실물이 달라지므로**, T0는 10월 전까지 반드시 닫아야 한다. **[중간 — 설계 판단]**

## 6. 대상(10월)을 위해 — 지금 말할 수 있는 것

**대상 심사 기준이 미확보이므로 확정적 조언은 불가능하다.** 다만 구조적으로 확실한 것 둘.

1. **선정 통과가 선결 조건이다.** D-9에 리소스를 몰아야 한다.
2. **10월에는 체험이 승부처로 복귀한다.** 그때는 ⑧의 T0(배선 복구)와 블록 2(비개발 트랙)가 다시 1순위가 된다 — 심사위원이 직접 거울 앞에 설 수 있기 때문이다.

**즉시 해야 할 확인**: 대상·PD Lab STAR 심사 기준 문의(학생처 또는 지도교수). 기준을 모른 채 10월을 준비하는 것이 현재 최대 리스크다.
