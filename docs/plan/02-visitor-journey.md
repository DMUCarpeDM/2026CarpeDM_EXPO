# ② 관람객 여정 지도 — 부스가 보이는 순간부터, 집에서 다시 여는 순간까지

> 입력: 01-concept-charter (A척추: 서사 몰입 → 과학 보상). 화면이 아니라 **감정**을 설계한다.

---

## 1. 여정 지도 (7구간)

| 구간 | 목표 감정 | 지금 제공되는 것 | 간극 | 처방 |
|---|---|---|---|---|
| **발견** (3~10m 거리) | "저게 뭐지?" | 잠든 거울(검정+한 줄) — 원거리에선 꺼진 화면으로 보일 수 있음 | 원거리 신호 없음 | 체험자가 있을 때는 글로우·음성이 곧 신호. **빈 부스일 때**가 문제 → 대기 화면에 저휘도 "숨쉬는 빛" 순환(구현됨) + 부스 상단 실물 사인(⑤) |
| **관찰** (대기줄) | "재밌어 보인다, 나도 할래" | 없음 (설계 공백) | **최대 공백** | §2 대기줄 기획 |
| **진입** (0~30초) | "어, 나를 알아봤네" | 웨이크+인사 TTS+3탭 | 양호 | 인사말을 대기줄에서 이미 들었다면 신선도 하락 → 웨이크 인사 2~3종 로테이션 |
| **체험** (5분) | 몰입→긴장→성취 | 리액션·분기·오라·장면 전환 | 첫 15초 오라 학습 비용(⓪-2-6) | 브리핑 마지막 줄에 **한 문장 해설**: "가장자리의 빛이 당신과 함께합니다" — 설명하지 않되 존재를 승인 |
| **결말·리포트** (1.5분) | 정서적 마침표→통찰 | 결말 TTS+시상식 3막 | 피크-엔드의 '엔드'가 QR(사무적) | §3 엔드 재설계 |
| **퇴장** | "가져간다" | QR+체험 코드 | QR 스캔 실측 시간 미검증 | 리허설 계측 항목화(⑤) + 코드 4자리는 **말로도 불러주기**(TTS) |
| **사후** (귀가 후) | "다시 해보고 싶다" | 웹 상세 리포트+성장 델타 | 재방문 유인이 리포트 안에만 있음 | 리포트 말미 "다음 도전 과제 1개" 상시 노출(구현됨 — 유지) + 부스 재방문 시 성장 델타가 서사가 됨(구현됨) |

## 2. 대기줄 기획 — 공백을 예고편으로

- **각도 원칙**: 대기 동선은 미러의 45° 측면(⑤ 도면). 대기자는 화면 내용이 아니라
  **빛과 목소리의 분위기**만 본다 — 스포일러 없이 궁금증만 쌓인다. 체험자의 답변
  내용은 지향성 스피커로 보호(⑤ 소리 설계).
- **사원증 카드** (C안 차용, 저비용): 대기 시작 시 "㈜클라우드밋 임시 사원증"
  카드를 배부. 앞면: 세계관 한 줄("오늘 09:04, 장애가 터졌다"), 뒷면: 소개 사이트
  QR + 체험 코드 기입란. 효과 3중 — 대기 이탈 방지(투자 심리), 세계관 선탑승,
  퇴장 시 코드 메모지 겸용. 비용: 명함 인쇄 수준.
- **대기 중 마이크로 콘텐츠**: 카드에 "오늘의 사내 소식" 3줄(세계관 유머) —
  읽는 90초가 지루함을 소화.
- **진행 신호**: 부스 밖에서 보이는 것은 "체험 중 / 곧 끝남" 2단계 표시등만
  (프레임 글로우 색으로 겸용 가능). 체험자 점수·내용은 절대 비노출(원칙 2·프라이버시).

## 3. 감정 피크 설계

- **피크 후보 실측 필요**: 가설 — 1피크 "첫 리액션"(내 말을 알아들었다, ~90초 지점),
  2피크 "하루의 결말"(정서, 5분 지점). 리허설에서 표정·발화로 관찰해 확정.
- **피크 증폭**: 결말 직전 1.5초 페이드 투 미러(장면 전환 재사용 — 구현 자산)로
  "숨 고르기"를 넣으면 결말 대사의 무게가 커진다. 저비용.
- **엔드 재설계**: 마지막 화면(QR)을 "퇴근 도장" 은유로 — "수고했어요. 오늘의
  기록에 도장을 찍어 가세요"(QR = 도장). 문구 교체 수준의 비용으로 사무적 엔드를
  세계관 엔드로. 원칙 5(모든 출구에 선물)와 정렬.

## 4. 이탈 설계 — 부끄러움의 출구

- 중도 포기 버튼("여기서 마치고 결과 보기")을 세계관 언어로: **"조퇴하기"**.
  조퇴해도 반쪽 리포트(측정된 것까지) + "다음에 이어서 출근" 코드 발급 — 구현은
  기존 경로 재사용, 문구·결말 대사 1종 추가("오늘은 여기까지. 내일 봅시다").
- STT 연속 실패 시(⓪-2-2): 3회 연속 인식 실패면 시스템이 먼저 제안 —
  "오늘 사무실이 시끄럽네요. 조퇴하고 다음에 이어갈까요?" (갇힘 방지의 세계관화).

## 5. 동반자 설계 (2~3인 그룹)

- 관찰자는 45° 측면에서 분위기만 보고, **끝나면 리포트를 함께 본다** — 시상식
  2막(레이더)이 자연스러운 공유 화면. 관찰자 전환 장치: 시상식 마지막에
  "함께 온 분도 해보실래요? 지금 바로 출근할 수 있어요" 한 줄 + 운영자 콜.
- 비교 놀이는 웹 코호트 백분위가 담당(구현됨) — 미러에서 1:1 비교 기능은
  만들지 않는다(프라이버시·회전율).

## 팀이 결정해야 할 질문 (②)

1. **사원증 카드 채택 여부와 수량** — 인쇄 발주가 필요(하드웨어 트랙에 합류).
   (채택: 대기·세계관·코드 메모 3역 / 미채택: 운영 단순)
2. **"조퇴" 이탈 경로**를 8/1 범위에 넣는가? (①-Q3과 동일 결정 — 문구+결말
   1종이면 저비용, 단 테스트 추가 필요)
3. **웨이크 인사 로테이션**(2~3종): 시드 추가 수준 — 넣을가?
4. **피크 실측**: 7/23~27 리허설에서 감정 곡선 관찰(표정·이탈·재도전율)을
   공식 항목으로 넣는가? 누가 기록하는가?
