# ④ 학습 설계서 — "이걸 하면 실제로 는다"를 지탱하는 문서

> 입력: 01 헌장. 심사석에 교육 전문가가 앉아 있다고 가정하고 쓴다.
> 원칙: 근거는 교과서 수준의 정설만. 과장된 학습 효과 주장은 그 자체가 감점이다.

---

## 1. 학습 목표 — 관찰 가능한 행동 문장 5개

| # | 목표 행동 | 대응 측정 (구현됨) |
|---|---|---|
| 1 | 보고를 **결론부터** 시작한다 | 담화: conclusion_first / 결말·리액션 분기 |
| 2 | 약속에 **기한**을 붙인다 ("10분 안에") | 담화: time_commitment (기한 표지 결합만 인정) |
| 3 | 지적을 받으면 변명 대신 **사실 확인**부터 말한다 | 위험 표현(책임 회피군) + 압박 턴 리액션 |
| 4 | 거절할 때 **대안**을 함께 낸다 | 담화: negative_no_alternative + EP4 체크리스트 |
| 5 | **듣는 동안** 상대를 본다 | 듣기 응시 분리(listening_front_ratio) |

이 5개에 직접 대응하지 않는 나머지 측정(~45개)은 **관찰·맥락 지표**로 공식 분류
한다 — 목적: 교차 분석의 재료, 코칭의 근거, 개인차 이해. "측정하지만 목표로
삼지 않는다"를 문서화(⓪-3의 지표 인플레이션 지적에 대한 답).

## 2. 피드백 루프의 이론적 근거

- **Kolb 경험학습 사이클과의 대응**: 구체적 경험(역할극) → 반성적 관찰(시상식·
  리포트: 관찰 문장) → 추상적 개념화(해석+처방 문장 — "이렇게 바꿔 말해보세요")
  → 능동적 실험(**재도전**). 재도전이 사이클을 닫는다 — 이 루프가 있어서
  "체험"이 아니라 "학습"이라 부를 수 있다.
- **피드백 타이밍**: 수행 중 피드백은 인지 부하를 높인다(이중 과제). 현 설계 —
  체험 중에는 앰비언트(오라)와 희소한 토스트(세션 3회 한도)만, 상세는 사후 —
  는 인지부하 관점에서 옳다. **바꾸지 말 것**을 설계 근거로 명문화.
- **분기(결말 3종)의 학습 기능**: 결과 가변성은 "내 행동이 결과를 바꾼다"는
  통제감(agency)을 만든다 — 반복 동기의 핵심. 역전 서사(초반 실수 만회 → 인정
  결말)가 골든 테스트로 보장되는 것은 학습 설계 관점에서도 중요 자산.

## 3. 5분의 정직한 경계

**5분으로 늘지 않는 것**: 습관·태도·유창성 (수십 회 반복의 영역).
**5분으로 생기는 것**: ①자기 인식("나는 압박에서 시선이 무너지는구나") ②구체적
처방 문장 1개 ③"연습하면 바뀐다"는 증거(재도전 델타).

공식 주장 문구(피치·리포트·사이트 공용): **"5분은 훈련이 아니라 거울입니다.
자기 인식이 모든 훈련의 시작점입니다."** — 과잉 주장 차단과 콘셉트 정렬을 동시에.
반복 훈련의 자리는 웹 모드가 맡는다(체험 코드 연속성 — 구현됨).

## 4. 성장 가시화 — 무엇을 비교해야 "늘었다"가 체감되는가

총점 비교(구현됨)는 변동 잡음이 크다. 체감 순위:
1. **압박 내성 프로파일 전이** ("동요형→회복형") — 구현됨. 성장 서사의 주인공.
2. **습관 소멸** ("지난번의 손-얼굴 터치가 사라졌어요") — 이전 리포트 습관 카드와의
   차집합. *(미구현 — 10월 후보)*
3. 목표 행동 5의 개별 달성 ("이번엔 기한을 붙였어요") *(미구현 — 10월 후보)*
4. 총점 델타 — 보조로만.

## 5. 윤리 경계 (기존 원칙의 명문화 + 보강)

- **외모 판단 금지**: 표정 지표는 "상대에게 어떻게 읽히는가"로만 서술(구현 반영).
  금지어 목록 유지: 인상/생김/얼굴형 관련 일체.
- **저성과 보호**: '아쉬움' 결말도 내일 프레임("첫날이니까")·처방 동반(구현됨).
  리포트에 절대 등급 낙인("하위권") 금지 — 백분위는 상위 표현만 쓴다(구현 확인됨).
- **동의·데이터**: 영상 무전송·기본 미저장·익명 코드(구현됨). 어린 관람객(중고생)
  대응: 표현 수위는 현행 무해 — 별도 조치 불요, 단 부모 동반 아동은 운영자 재량.
- **측정 대상의 알 권리**: 무엇을 측정하는지 온보딩 동의 3줄에 요약(구현됨) —
  10월까지 "자세히 보기" 정적 페이지 1장 추가 권고(소개 사이트와 겸용).
