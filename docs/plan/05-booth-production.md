# ⑤ 부스 프로덕션 — 여정을 물리 공간에 구현한다

> 입력: 02 여정 지도, 03 세계관 소품, hardware-plan. 부스 3×3m 가정(실측 확정 시 갱신).
> 심사위원 체류 3~5분의 밀도가 순위를 가른다.

---

## 1. 레이아웃 2안

```
A안 — 후벽 배치 (권장)                B안 — 중앙 섬형
┌─────────────┐                ┌─────────────┐
│ [소품벽]  M │  M=미러(후벽 우측)  │      M      │ 360° 노출
│           ↑ │  체험자 위치        │    ↗   ↖   │
│   대기줄  ○ │  ○=체험자          │  대기  대기  │
│ ↘(45°관찰) │                    │             │
│ 입구──사원증 │                    │ 입구        │
└─────────────┘                └─────────────┘
```
- **A안 권장**: 후벽이 배경을 통제(하프미러 반사 품질은 배경 어두움에 좌우) +
  45° 대기 관찰각(② 스포일러 방지) + 벽면이 세계관 소품 자리. 카메라 뒤 공간이
  없어 난입 변수도 감소.
- B안은 노출 최대지만 반사 배경 통제 불가·프라이버시 취약 — 기각 사유 명기.

## 2. 빛과 소리

- **조명**: 미러 정면 상단 스팟 **금지**(반사 씻김 + 홍채 추적 역광 리스크).
  측후방 간접광 + 소품벽 국부 조명. 체험자 얼굴에는 부드러운 전면 보조광
  (측정 품질 — 카메라가 얼굴을 봐야 한다). 설치일 휘도 캘리브레이션은
  demo-checklist에 이미 항목화.
- **소리 3원 문제**(TTS ↔ 체험자 발화 ↔ 전시장 소음): TTS는 미러 상단
  **지향성(사운드바형 부품) 하향** — 체험자에게 명료, 대기줄엔 분위기만.
  발화 수음은 구즈넥 마이크 근접 배치(30cm 내) — 소음 강건 VAD가 2차 방어.
  개방 스피커는 두지 않는다(④ 자의식 보호 + 답변 내용 프라이버시 우선).
  대기줄 "예고편"은 새어 나오는 소리 + 빛으로 충분(② 각도 설계).

## 3. 운영 대본 (2인 체제)

| 역할 | 상시 | 피크(대기 15분+) | 장애 시 |
|---|---|---|---|
| **호객·안내** ("인사팀" 명찰) | 발견→진입 전환 멘트, 사원증 배부, QR 안내 | 대기 예상시간 고지, 웹 모드 태블릿으로 분류(짧은 체험 원하는 사람) | 심사위원 응대(피치 1분) |
| **리셋·기술** | 세션 간 초기화 확인(자동이나 감시), 볼륨·조명 감시 | 5분 모드 고정 안내(회전율) | demo-checklist 문제 표 실행, 조퇴 유도 |

- 심사위원 식별 시: 호객 담당이 pitch-1min 60초 → 즉시 체험 권유 → 체험 중
  개입 금지(혼자 되는 체험이 메시지) → 리포트 화면에서 심층 분석 1개만 짚기.
- 교대: 2시간 단위, 15인 팀 로테이션 표는 별도(사람 몫).

## 4. 기록 계획 — 전시가 데이터가 된다

- 자동 수집(구현): 세션 수·완주율·재도전율·평균 점수·코호트 축적(admin metrics).
- 수동 기록(운영자, 시간당 1줄): 대기열 길이, 중도 포기 사유 관찰, 오판 신고
  ("안 꼈는데 팔짱이래요") — **오판 신고는 즉시 이슈화**(신뢰 급소 ⓪-5).
- 활용: 일일 마감 10분 회고 → 최종심사 "체험자 N명, 완주율 N%, 재도전율 N%"가
  완성가능성의 증거가 된다.

## 5. 리허설 캘린더 연동

- 7/14~18 가조립 주간: 레이아웃 A 실측 → 도면 확정, 조명·소리 1차 튜닝,
  실기기 검증(demo-checklist §2.5) 병행.
- 7/23~27: 감정 피크 관찰(②-Q4), QR 스캔 실측, 백업 영상 촬영(7/28).

## 팀이 결정해야 할 질문 (⑤)

1. **부스 실제 규격 확인** — 3×3m 가정이 맞는가? (도면 전체가 이 값에 걸려 있다)
2. **지향성 스피커 부품**: hardware-plan 음향 항목을 지향성 우선으로 확정?
   (개방 스피커 포기 = 대기줄 소리 예고편 약화를 수용)
3. **운영 로테이션 표** 오너 지정 (2시간×전시 기간 — 사람 몫).
4. **오판 신고 프로토콜**: 운영자가 오판 관찰 시 그 자리에서 사과 멘트
   ("측정이 겸손하지 못했네요") + 기록 — 이 대응 문구를 공식화할까?
