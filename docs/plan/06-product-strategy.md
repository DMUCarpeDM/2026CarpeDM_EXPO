# ⑥ 제품 전략 — 전시가 끝나면 이건 무엇이 되는가

> 입력: 01 헌장, 04 학습 설계. 심사의 "확장 계획은?"에 대한 답이자, 11월의 팀이
> 실제로 걸을 길의 초안.

---

## 1. 시장 지도 — 이 거울이 놓일 수 있는 세 자리

| 자리 | 구매자/사용자 | 요구되는 변화 | 경쟁재와의 차별 축 |
|---|---|---|---|
| **대학 취업지원센터 상설 기기** | 처장·센터장 / 재학생 | 기관 대시보드(모델 존재·미구현), 익명 ID 배치 발급, 콘텐츠 팩 2+ | 모의면접 부스와 달리 **혼자·반복·무예약** — 한계비용 0 |
| **기업 신입 온보딩** | HRD 담당 / 신입사원 | 직무 커스텀 시나리오(시드=데이터 설계가 자산), 보안 심사 대응 문서 | **온디바이스·영상 무전송이 결정타** — 인사 데이터 외부 반출 없음 |
| **B2C 웹 (개인 연습)** | 취준생 본인 | 웹 모드 강화(이미 존재), 모바일 UX 정련 | AI 면접 '평가' 서비스와 달리 **적응 훈련** — 합격 이후를 다루는 유일한 자리 |

**포지셔닝 문장**: AI 면접 서비스들은 "뽑히는 법"을 팔고, 미러팅은 **"버티고
적응하는 법"** 을 판다 — 선발이 아니라 온보딩 시장. 경쟁이 아니라 인접.

## 2. 온디바이스는 철학이자 사업 모델이다

- API 비용 0 = **한계비용 0의 상설 기기**. 취업지원센터가 연간 구독료 없이
  기기 1대로 무제한 세션 — 도입 장벽이 구조적으로 낮다.
- 영상·음성 무전송 = 기관 보안 심사의 최대 관문을 **설계로 통과**. 기업 온보딩
  시장에서 이것이 없으면 대화 자체가 안 된다.
- 심사 화법: "저희는 비용을 아낀 게 아니라, **팔 수 있는 구조**를 설계했습니다."

## 3. 8주 로드맵 (8/1 중간심사 → 10월 본전시)

| 주간 | 트랙 | 내용 |
|---|---|---|
| 8월 1~2주 | 심사 반영 | 중간심사 피드백 소화, 콘셉트 헌장 개정(필요 시) |
| 8월 | 콘텐츠 40% | 리액션 2배 확장, 팩1(비개발 직군) 집필·탑재, 조퇴 경로 |
| 8~9월 | 신뢰도 30% | 실기기 보정 상시화, 오판 신고 루프, 코호트 축적 검증, 성장 가시화 2단계(습관 소멸) |
| 9월 | 연출 30% | 부스 소품 제작, 캐릭터 비주얼(③-Q4 채택 시), 소개 사이트, 백업 영상 갱신 |
| 9월 말 | 리허설 | 전체 리허설 2회 + 내구성(하루 8시간 연속 구동) 시험 |

자원 배분 권고: **콘텐츠 40 / 신뢰도 30 / 연출 30** — 신기능 0. 8주간 새 측정
기능을 만들지 않는다(마스터리 플랜 완료로 측정은 충분 — 이제 채우고 다듬는 기간).

## 5. 팀의 유산 — 전시가 끝났을 때 각자 가져가는 것

포트폴리오 조각을 의도적으로 설계한다: 측정 엔진(음성 DSP·시선 추적) 담당자에겐
"합성 신호 검증 하네스" 스토리, 서사 담당자에겐 "분기 서사 시스템" 스토리,
운영 담당자에겐 "N명 체험 운영 데이터" 스토리 — **최종 발표 자료에 기여자 지도
1장**을 넣는 것을 공식화한다(팀 제품이면서 각자의 증거가 되도록).

## 팀이 결정해야 할 질문 (⑥)

1. **자원 배분 40/30/30(신기능 0) 승인** — 8주간 새 측정 기능 동결에 동의하는가?
2. **1차 시장 선택**: 최종 발표의 "확장" 슬라이드는 셋 중 무엇을 앞세우는가?
   (권장: 대학 취업지원센터 — 심사위원의 상상 비용이 가장 낮다)
3. **기관 대시보드**(⓪ 죽은 기획): 10월 전 구현 이월 vs 로드맵 슬라이드로만 —
   어느 쪽인가? (구현 이월 시 신기능 동결 원칙과 충돌 — 예외 승인 필요)
4. **기여자 지도**: 최종 자료에 팀원별 기여를 명시하는 방식에 합의하는가?
