## 0. 원페이저

**콘셉트 한 문장**
> **첫 출근을 미리 살아보는 거울. 하루가 끝나면, 거울이 본 당신을 건네준다.**
> (서사가 척추, 측정은 보상 — "이야기로 몰입시키고, 과학으로 돌려드립니다")

**제품 원칙 5**
1. 검정은 거울이다 2. 상대가 먼저, 측정은 나중 3. 감점이 아니라 관찰
4. 모르면 모른다고 말한다 5. 누구의 하루도 실패로 끝나지 않는다

**8/1 전에 팀이 내려야 할 결정 3개 (최우선)**
1. 콘셉트 A(서사 척추) 확정 + 제품명 어순("미러팅") — 모든 문구 정렬의 전제
2. 하드웨어 발주 집행 (7/11 마지노선 — 이미 임박)
3. 8/1 데모 범위 동결: 신기능 없이 현행 + 문구 정렬 + 실기기 보정만

## 1. 제품 정의 (01 헌장)

미러팅은 하프미러 앞에서 가상 회사 ㈜클라우드밋의 신입으로 하루를 사는 체험이다.
대답의 품질이 상대의 리액션과 하루의 결말을 바꾸고(분기 서사), 하루가 끝나면
4-Fit 리포트 — 문장 인용 코칭, 결정적 순간, 압박 내성 프로파일 — 가 "거울이 본
나"로 건네진다. 측정 50여 종은 전부 온디바이스/로컬(API 키 0, 영상 무전송)이다.

## 2. 체험 (02 여정 + 03 세계관)

발견 → **대기(사원증 카드·45° 관찰각)** → 진입(웨이크) → 하루(5분: 리액션·분기·
오라) → **결말(피크: 1.5초 암전 후 마지막 대사)** → 시상식 리포트 → **퇴근 도장
(QR)** → 사후(웹 상세·재방문 성장 델타). 모든 출구에 선물: 중도 포기는 "조퇴"로
세계관화하고 반쪽 리포트를 준다. 세계관 바이블(03)이 캐릭터·말버릇·시간 규칙을
고정하고, 콘텐츠 확장(리액션 2배, 팩 "비개발 직군의 하루")은 8~9월 콘텐츠 트랙.

## 3. 학습 주장 (04)

공식 주장: **"5분은 훈련이 아니라 거울입니다."** 학습 목표는 관찰 가능한 행동 5개
(결론 선행·기한 약속·사실 확인·대안 있는 거절·듣기 시선)로 한정하고, 나머지 측정은
관찰·맥락 지표로 공식 분류한다. Kolb 사이클의 완성은 재도전이다. 윤리 경계(외모
판단 금지·저성과 보호·데이터 최소화)는 구현에 이미 반영 — 문서로 명문화됨.

## 4. 전시 운영 (05)

부스 A안(후벽 미러·45° 대기·소품벽), 조명은 측후방 간접+얼굴 보조광, 소리는
지향성 원칙(개방 스피커 없음). 운영 2인(호객/리셋) 대본과 심사위원 60초 응대,
오판 신고 즉시 이슈화. 전시 데이터(세션·완주율·재도전율)가 최종심사의 증거가 된다.

## 5. 전략 (06)

포지셔닝: 선발(AI 면접)이 아니라 **적응(온보딩)**. 1차 시장은 대학 취업지원센터
상설 기기 — 온디바이스가 한계비용 0과 보안 심사 통과를 동시에 준다. 8주 자원
배분 40(콘텐츠)/30(신뢰도)/30(연출), **신기능 동결**.

## 6. 모순 판정 기록 (편집장 판정 — 재론 가능)

| 충돌 | 판정 | 근거 |
|---|---|---|
| ②대기줄 진행 표시 vs 원칙2·프라이버시 | 2단계 표시등(체험 중/곧 끝)만, 내용·점수 비노출 | 회전율 정보는 필요하나 체험자 보호 우선 |
| ②소리 예고편 vs ⑤지향성(무개방) | **지향성 우선** — 예고편은 새어 나오는 소리+빛으로 족함 | ④자의식 보호·답변 프라이버시가 상위 원칙 |
| ⓪심층 분석 미러 노출 vs 회전율 | 시상식에 **한 줄만** 승격: 압박 내성 레벨("당신은 회복형") — 카드 추가 없이 2막 문구에 삽입 | 어필과 회전율의 최소 타협 |
| ③캐릭터 일러스트 vs ⑥신기능 동결 | 연출 트랙(30%)에 속함 — 동결 예외 아님, 단 9월 여력 시만 | 동결은 '측정 기능' 동결로 한정 해석 |
| ⓪기관 대시보드 vs ⑥동결 | **10월 전 미구현** — 로드맵 슬라이드로만 | 8주 내 증거 없는 기능은 위험 |
| ①리브랜딩 vs 제출본 연속성 | 어순 조정("미러팅 — 4-Fit 리포트")으로 절충, 4-Fit 용어는 유지 | 심사 서류와의 단절 방지 |
