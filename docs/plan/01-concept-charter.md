## 1. 콘셉트 후보 3안

### A안 — "첫 출근을 미리 살아보는 거울" (서사가 척추)
- **정의**: 하프미러 앞에 서면 가상 회사의 하루가 시작되고, 내 대답이 그 하루를
  바꾼다. 측정은 하루가 끝난 뒤 "거울이 본 나"로 건네지는 **보상**이다.
- **감정 곡선**: 호기심(깨어나는 거울) → 몰입(사건 한복판) → 긴장(압박) →
  정서적 마침표(결말) → 통찰(리포트) → "한 번 더"(재도전).
- **참이 되려면**: 체험 중 계측의 존재감을 더 낮추고(오라는 유지하되 해설 없이),
  결말·리액션의 드라마를 강화. 이름·부제·부스 카피를 서사 언어로 통일.
- **버려야 하는 것**: 체험 중 "지금 분석되고 있다"는 어필 (리포트가 대신 증명).

### B안 — "나를 비추는 AI 커뮤니케이션 코치" (측정이 척추)
- **정의**: 50가지를 보는 온디바이스 AI가 나의 말하기를 실시간으로 비추고
  교정한다. 역할극은 측정을 위한 **과제 상황**이다.
- **감정 곡선**: 신기함 → 자기 의식 → 통찰("이런 것까지?") → 교정 의지.
- **참이 되려면**: 라이브 오라 해설 도입, 심층 분석의 미러 노출, 지표의 가시화.
- **리스크**: 거울 앞 자의식 증폭(기존 원칙과 충돌), "평가받는 기계" 인상,
  AI 면접 서비스들과 같은 카테고리로 지각됨(차별성 희석).

### C안 — "거울 속 회사, 클라우드밋" (세계관이 척추)
- **정의**: 부스 전체가 하나의 회사다. 사원증을 받고 입사해, 거울(사무실)에서
  하루를 보낸다. 측정과 서사는 세계관의 소품이다.
- **참이 되려면**: 부스 아트·소품·운영자 연기까지 세계관화. 콘텐츠 제작 비용 최대.
- **리스크**: 기술성 어필이 배경으로 밀림. 15인 팀 잔여 8주에 과함.

### 비교표

| | A 서사 | B 측정 | C 세계관 |
|---|---|---|---|
| 작품성 | ◎ 감정 곡선 완결 | ○ | ◎ (실행되면) |
| 기술성 | ○ 리포트가 증명 | ◎ 전면 어필 | △ 배경화 |
| 창의성 | ◎ 분기·결말 | ○ 순간 감지 | ◎ |
| 발표력 | ◎ 이야기 하나로 관통 | △ 지표 나열 위험 | ○ |
| 완성가능성 | ◎ 현 구현과 최단 거리 | ○ | △ 추가 비용 큼 |
| 기존 구현과의 거리 | **가깝다** (결말·리액션이 이미 중심) | 중간 (노출 재설계 필요) | 멀다 (소품·연출 신규) |

## 2. 권장안 — A를 척추로, B를 보상으로

**"첫 출근을 미리 살아보는 거울. 하루가 끝나면, 거울이 본 당신을 건네준다."**

이유: 체험의 실제 최고 순간(리액션·결말·인용)이 이미 서사에 있고, 측정의 깊이는
**리포트에서 터뜨릴 때** 가장 놀랍다("놀고 있는 줄 알았는데 이만큼 보고 있었어?").
B를 척추로 세우면 자의식 원칙과 충돌하고 AI 면접기와 같은 진열대에 놓인다.
C의 자산(사원증·소품)은 A의 연출 요소로 **차용**한다(⑤에서 저비용 범위 설계).
심사 화법도 하나로 정리된다: *"이야기로 몰입시키고, 과학으로 돌려드립니다."*

## 3. 제품 원칙 5 — 모든 결정의 리트머스

기존 코드에서 발굴해 승격(1~4)하고 하나를 신설(5)한다:

1. **검정은 거울이다** — 면(面)을 채우지 말고 빛으로 그린다. 반사 존은 비운다.
2. **상대가 먼저, 측정은 나중** — 체험 중 계측은 숨 쉬듯 존재하고(오라),
   말하는 것은 리포트다. 체험 중 숫자 노출 금지.
3. **감점이 아니라 관찰** — 모든 피드백은 관찰·해석·처방 3단. 과잉 지적 금지.
4. **모르면 모른다고 말한다** — 표본 부족은 보류, 판정엔 신뢰도, 관용 규칙 우선.
5. **누구의 하루도 실패로 끝나지 않는다** *(신설)* — 중도 포기자도, 아쉬움 결말도,
   무언가를 들고 나간다. 전시의 모든 출구에 선물이 있다.

## 4. 이름·문구 감사

- **"4-Fit 미러팅"**: 4-Fit(계측)이 앞에 서 있어 A 콘셉트와 어긋난다.
  권고: 제품명은 **"미러팅"**으로 세우고, **4-Fit은 리포트의 브랜드**로 강등
  ("미러팅 — 4-Fit 리포트로 하루를 돌려받는 거울"). 리브랜딩 비용: 낮음
  (README·대기 화면·피치의 어순 조정 수준, 로고 미확정 상태라 지금이 적기).
- 화면 문구 정렬 대상: 대기 화면 부제(계측 나열 → 서사 문장), 분석 대기
  ("퇴근하는 중" — 이미 A 정렬, 유지), 온보딩(이미 A 정렬, 유지).
