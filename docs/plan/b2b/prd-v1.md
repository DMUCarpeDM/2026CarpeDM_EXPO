## 0. 한 문장

취준생 전시 체험작 미러팅을, **기업·프랜차이즈가 신입·수습 직원의 응대·보고 역량을 롤플레이로 훈련시키고 관리자가 결과를 대시보드로 확인하는 B2B 온보딩 교육 제품**으로 확장한다. 전시(EXPO)는 이 제품의 데모 무대이자 첫 검증 장이다.

---

## 1. 문제 정의

B2B 온보딩 교육 시장에서 세 개의 결핍이 겹친다.

1. **신입·수습의 실전 응대 훈련 부재** — 프랜차이즈·유통 현장의 신입은 매뉴얼 암기와 짧은 OJT만으로 고객 컴플레인 같은 고압 상황에 투입된다. 첫 실전이 곧 첫 훈련이 되고, 이 스트레스가 조기 이탈로 이어진다.
2. **온보딩 표준화 부재** — 훈련 품질이 매장·지점별 사수의 역량에 의존한다. 본사가 만든 응대 매뉴얼이 "읽는 문서"에서 "몸에 붙는 행동"으로 전환되는 표준 경로가 없다.
3. **관리자의 가시성 부재** — 신입이 어디까지 훈련됐고 무엇이 약한지, 교육 담당자가 확인할 수단이 집합 교육 출석부 수준에 머문다. 훈련 결과가 기록·비교·추적되지 않는다.

미러팅은 이 셋을 하나의 루프로 닫는다: **롤플레이 훈련(신입) → 근거 기반 평가(시스템) → 대시보드 가시화(관리자)**.

## 2. 타깃 고객

| 순위 | 고객 | 구매자 | 사용자 | 근거 |
|---|---|---|---|---|
| **1차** | 프랜차이즈 본사 교육팀 (외식·유통) | 본사 HRD·교육팀 | 신입·수습 크루, 고객센터 상담원 | 신입 이직률이 높고 온보딩 표준화 수요가 크다. 감정 상태 머신 데모 효과가 대면 응대에서 극대화된다([도메인 결정](domain-decision.md)). |
| **2차** | 대학 취업지원센터 | 센터(기관 예산) | 재학생·졸업 유예생 | 기존 전략 문서(⑥ 제품 전략, 자리 A)의 연장. 기존 사무직 시나리오 자산을 그대로 재사용한다. |

## 3. 사용자 페르소나

### 페르소나 A — 교육 담당 매니저 (본사 교육팀)

| 축 | 내용 |
|---|---|
| 상황 | 분기마다 수십 명의 신입 크루 온보딩을 책임진다. 매장별 교육 편차가 골칫거리다. |
| 목표 | 표준화된 훈련을 배포하고, 누가 준비됐고 누가 더 연습이 필요한지 근거를 갖고 판단하고 싶다. |
| 불편 | 집합 교육은 비용이 크고 1회성이다. 이러닝은 시청 여부만 남고 행동 변화를 못 본다. |
| 제품에서 하는 일 | 코호트(기수) 개설, 초대코드 배포, 대시보드에서 이수율·등급 분포·회차별 개선폭 확인, 시나리오 팩 선택. |

### 페르소나 B — 신입 수강생 (매장 크루 수습)

| 축 | 내용 |
|---|---|
| 상황 | 입사 1~2주차. 매뉴얼은 읽었지만 실제 화난 고객 앞에 서 본 적이 없다. |
| 목표 | 실전에서 얼어붙지 않기. "이 상황엔 이렇게 말한다"는 감각을 미리 갖기. |
| 불편 | 사수 앞 롤플레이는 부끄럽고, 혼자 연습은 피드백이 없다. |
| 제품에서 하는 일 | NFC 카드 태그로 세션 시작 → AI 고객·상사와 롤플레이 → 등급·코칭 리포트 수령 → 재도전으로 개선폭 확인. |

## 4. 핵심 사용 시나리오

```
[발급 키오스크]          [미러(컨셉 UI)]           [리포트]              [이후]
 NFC 카드 발급     →     카드 태그로 세션 시작  →   영수증 QR 발급   →   QR 스캔 → 세션 계정 귀속
 + PIPA 동의             롤플레이(음성·비언어)      등급 + 코칭            관리자 대시보드에 집계
```

1. **발급 키오스크** — 수강생이 초대코드로 본인 코호트를 확인하고, PIPA 음성 수집 동의([동의 문구](consent-copy.md)) 후 NFC 카드를 발급받는다(카드에는 무의미 UID만 사용).
2. **미러 롤플레이** — 미러(풀스크린 컨셉 UI) 앞에서 카드를 태그하면 본인 직무의 시나리오가 시작된다. AI 고객의 감정 온도가 답변 품질에 따라 변하고, 음성·비언어 지표가 온디바이스로 집계된다. NFC 리더 장애 시 4자리 코드 수동 입력으로 폴백.
3. **영수증 QR** — 세션 종료 시 등급(우수/양호/보통/연습 필요)과 핵심 코칭이 담긴 리포트 화면 + 지참용 QR이 발급된다.
4. **계정 귀속** — QR 스캔으로 세션이 수강생 계정에 귀속(클레임)되고, 회차별 추이가 이어진다.
5. **관리자 대시보드** — 교육 매니저가 코호트별 이수율·등급 분포·1차→2차 개선폭을 확인한다. 원점수는 관리자 화면에만 노출한다([점수 표기 방침](score-display-policy.md)).

## 6. KPI

| KPI | 정의 | 측정 |
|---|---|---|
| **온보딩 이수율** | 코호트 배정 인원 중 지정 시나리오를 완주(completed)한 비율 | 세션 FSM `completed` 도달 수 ÷ 코호트 인원 |
| **1차→2차 개선폭** | 같은 시나리오 재도전 시 등급(및 내부 원점수) 상승 폭 | 회차별 세션 비교(계정 귀속 기반) |
| **관리자 재사용률** | 대시보드를 2회 이상 재방문·코호트를 2개 이상 개설한 관리자 비율 | 관리자 접속·개설 로그 |

## 7. 제약·원칙 (기존 원칙 계승)

1. **외부 API 무의존** — STT/TTS 브라우저 내장, 대화·평가는 로컬 Ollama, 폴백은 템플릿/결정적 파이프라인. API 키·사용료 0원.
2. **폴백 계층** — LLM→템플릿, Whisper→Vosk, NFC→수동 코드. 어떤 단일 장애도 세션을 죽이지 않는다.
3. **개인정보 최소화** — 영상 원본 미전송, 집계 지표만. 음성은 동의 기반 보관([동의 문구](consent-copy.md)). NFC 카드에는 개인정보를 기록하지 않는다.
