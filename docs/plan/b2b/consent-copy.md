# PIPA 음성 수집 동의 문구 초안

> 상태: 초안(2026-07-31) · 법무·전문가 검토 전 내부 초안 — 실제 B2B 계약 전 반드시 검토를 거친다
> 관련 스펙: S-B2B-005 (임시 ID) · 연관: S-B2B-108(동의 플로우), S-B2B-109(동의 문구), 기존 S-CBYKOH(음성 저장 동의)
> 적용 지점: 발급 키오스크 동의 화면([PRD v1](prd-v1.md) §4 1단계)

---

## 0. 원칙 (문구가 지켜야 하는 사실)

문구는 아래 구현 사실과 어긋나면 안 된다. 구현이 바뀌면 문구를 먼저 바꾼다.

| 항목 | 사실 |
|---|---|
| 수집 항목 | 음성 녹음, 발화 전사 텍스트, 비언어 집계 지표(시선·자세·표정의 수치 요약). **영상 원본은 수집하지 않는다** — 카메라 분석은 기기 안에서 끝나고 집계 숫자만 저장된다 |
| 수집 목적 | 교육 평가(4-Fit 분석) 및 코칭 리포트 생성 |
| 보관 기간 | 기본 7일(`media_retention_days`). **계정 저장 동의 시 교육 과정 종료 + 30일**. 미저장 동의 시 음성은 분석 직후 삭제 |
| 삭제 절차 | 수강생 본인 또는 소속 기관 교육 담당자를 통한 즉시 삭제 요청 경로 제공 |
| 제3자 제공 | 없음. 외부 클라우드 API로도 전송하지 않는다(전 처리 로컬) |
| 거부 권리 | 동의를 거부해도 불이익 없음 — **텍스트 입력 방식으로 동일 교육 참여 가능**(단, 음성 관련 지표는 측정 제외) |
| 14세 미만 | 본 서비스는 기업·기관 소속 성인 수강생 대상이며 14세 미만 아동의 개인정보를 수집하지 않는다 |

## 1. 화면 문구 (짧은 버전 — 발급 키오스크 동의 화면)

> **음성 수집 동의**
>
> 교육 평가와 코칭 리포트를 만들기 위해 **음성 녹음, 발화 텍스트, 비언어 집계 지표**(숫자 요약)를 수집합니다.
> **카메라 영상 원본은 저장·전송되지 않습니다.** 분석은 이 기기 안에서 이루어집니다.
>
> - 보관: 기본 **7일** 후 자동 삭제 (계정에 저장을 선택하면 교육 과정 종료 후 30일)
> - 제3자 제공: **없음** (외부 서버·클라우드로 보내지 않습니다)
> - 삭제 요청: 언제든 교육 담당자 또는 안내된 경로로 즉시 삭제를 요청할 수 있습니다
>
> 동의하지 않아도 불이익은 없으며, **텍스트 입력 방식**으로 동일하게 참여할 수 있습니다.
>
> ☐ (필수 아님) 음성 수집에 동의합니다
> ☐ (선택) 내 계정에 결과와 함께 음성을 저장하는 것에 동의합니다 — 교육 과정 종료 후 30일 보관

- 두 번째 체크박스는 첫 번째에 동의한 경우에만 활성화한다(기존 S-CBYKOH 저장 동의 흐름 계승).
- "필수 아님" 표기를 지운 채 배포하지 않는다 — 거부 가능성이 화면에서 보여야 한다.

## 2. 전문 (긴 버전 — "자세히 보기" / 인쇄물)

### 음성 등 개인정보 수집·이용 동의서

㈜(운영 주체명 기입) — 이하 "운영자" — 는 「개인정보 보호법」에 따라 아래와 같이 개인정보를 수집·이용하고자 합니다. 내용을 확인하신 후 동의 여부를 결정해 주시기 바랍니다.

**1. 수집 항목**

- 음성 녹음 파일(롤플레이 중 수강생 발화)
- 발화 전사 텍스트(음성을 문자로 변환한 기록)
- 비언어 집계 지표(시선·자세·표정에 대한 수치 요약값)

※ **카메라 영상 원본은 수집하지 않습니다.** 영상 분석은 훈련 기기 내부에서만 수행되며, 결과 숫자(집계 지표)만 저장됩니다.

**2. 수집·이용 목적**

- 교육 평가(응대·보고 역량 분석) 및 코칭 리포트 생성
- 회차 간 개선 추이 확인(계정 저장 동의자에 한함)

**3. 보관 및 이용 기간**

- 음성 녹음 파일: 수집일로부터 **7일** 후 자동 삭제
- 계정 저장에 별도 동의한 경우: **소속 교육 과정 종료 후 30일**까지 보관 후 삭제
- 음성 수집에 동의하였으나 저장에 동의하지 않은 경우: 분석 완료 직후 삭제
- 전사 텍스트·집계 지표: 코칭 리포트 제공 목적 범위에서 위 기간에 준하여 보관

**4. 삭제 요청**

정보주체는 언제든지 본인의 음성·전사·지표 데이터의 즉시 삭제를 요청할 수 있습니다. 요청 경로: 소속 기관 교육 담당자 또는 화면에 안내된 운영자 연락처. 요청 접수 시 지체 없이 삭제합니다.

**5. 제3자 제공 및 처리 위탁**

수집된 정보는 제3자에게 제공하지 않습니다. 음성·영상 처리는 외부 클라우드 서비스로 전송되지 않고 훈련 기기 및 운영 서버 내부에서만 이루어집니다.

**6. 동의 거부 권리 및 불이익**

정보주체는 동의를 거부할 권리가 있으며, 동의하지 않아도 교육 참여에 불이익이 없습니다. 이 경우 음성 대신 **텍스트 입력 방식**으로 동일한 교육에 참여할 수 있습니다(음성 관련 지표는 측정에서 제외됩니다).

**7. 14세 미만 아동**

본 서비스는 기업·기관 소속 수강생(성인)을 대상으로 하며, 14세 미만 아동의 개인정보를 수집하지 않습니다. 14세 미만임이 확인되는 경우 수집을 중단하고 기존 수집분을 삭제합니다.
