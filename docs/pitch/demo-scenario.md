# 시연 큐시트 — 중간심사(8/1) 라이브 데모

> 역할: **발표자**(미러 앞, 마이크) / **조작자**(백업 노트북, 개입은 비상시에만)
> 대원칙: 시연 중 조작자가 화면을 만지는 순간 "혼자 되는 체험"이라는 메시지가 깨진다.
> 발표 전 점검은 docs/demo-checklist.md 15분 루틴을 그대로 따른다.

## 초 단위 큐시트 (발표 대본 (2) 구간, 60~90초)

| 시각 | 발표자 행동 | 화면에서 일어나는 일 | 말할 것 |
|---|---|---|---|
| 0:00 | 미러에서 두 걸음 떨어져 서 있다 | 잠든 거울 — 검정 + "다가와 보세요" | (발표 진행 중) |
| 0:05 | **한 걸음 다가선다** | 웨이크 — 글로우 점등 + 인사 TTS | "거울이 저를 알아봅니다" |
| 0:12 | 5분 카드 탭 → 동의 탭 → 출근 탭 | 3탭 온보딩 | "출근까지 세 번이면 됩니다" |
| 0:25 | 브리핑 — 화면 응시 (캘리브레이션) | 09:04 장면 자막 + 얼굴 링 | "지금 저에게 기준을 맞추는 중입니다" |
| 0:32 | 시작 탭 → 팀장 질문 듣기 | 팀장 TTS + 자막 | (듣는다 — 말 겹치지 않기) |
| 0:45 | 마이크 탭 → **준비된 답변** (아래) → 전달 | 인식 자막 실시간 표시 | — |
| 1:00 | 리액션을 기다린다 (침묵) | 팀장 리액션 TTS → 다음 장면 | "방금 그 반응, 대본이 아닙니다" |
| 1:10 | (시간 여유 시) 두 번째 턴 or 마침 | 페이드 투 미러 장면 전환 | "10시 12분으로 시간이 흘렀죠" |

### 준비된 답변 (외울 것 — excellent 케이스 보장)

> "안녕하십니까, 오늘 합류한 신입 개발자 ○○○입니다. 플랫폼팀에서 백엔드 운영
> 지원을 맡게 됐고, 오늘은 온보딩 문서 파악과 장애 대응 참관을 퇴근 전까지
> 마치는 게 목표입니다. 모르는 건 바로 여쭤보면서 배우겠습니다."

- 이름·역할·목표·협업 4요소를 모두 커버 → "좋아요. 그렇게 정리해서 말하면
  돼요" 계열 리액션 + 다음 장면 신뢰 변주가 보장된다.
- **일부러 나쁜 답 시연**(분기 어필)을 하고 싶으면 Q&A 시간에: "그냥 왔는데요"
  라고 답하면 팀장의 태도가 달라지는 것을 20초로 보여줄 수 있다.

## 막혔을 때 애드리브

| 상황 | 애드리브 |
|---|---|
| STT가 못 알아들음 | "전시장이 시끄러울 때를 대비한 오프라인 인식 모드도 있습니다" → 또박또박 재시도 |
| 웨이크 안 됨 | 그냥 화면 터치 → "조명이 강한 환경에선 터치로도 시작합니다" (멈추지 말 것) |
| TTS 지연/침묵 | "거울이 생각 중이네요 — 로컬에서 다 처리하다 보니 가끔 신중합니다" (웃음 유도) |
| 리액션이 평이함 | "지금은 템플릿 반응이고, 전시 버전은 로컬 LLM이 제 문장을 직접 인용합니다" |

## 시연 실패 시 백업 플랜 (2단계)

1. **1차 — 사전 녹화 영상**: 완주 영상(웨이크→리포트, 90초 편집본)을 조작자
   노트북에 준비. "라이브 환경 이슈가 있어 녹화본으로 보여드리고, 부스에서
   직접 체험을 도와드리겠습니다" — 사과는 한 문장만, 바로 영상.
   *(영상은 7/28 리허설 때 촬영해둘 것 — 이 문서의 유일한 사전 준비물)*
2. **2차 — 웹 모드 전환**: 미러 하드웨어 문제면 조작자 노트북 웹 모드로 동일
   시나리오 진행. "같은 엔진이 웹에서도 돕니다 — 개인 연습용 모드입니다"로
   오히려 듀얼 모드 어필로 전환.

## 리허설 체크 (발표 전 최소 2회)

- [ ] 준비된 답변으로 excellent 리액션이 실제로 나오는지
- [ ] 발표자 목소리 크기에서 STT 인식률 (부스 소음 조건)
- [ ] TTS 볼륨이 발표자 마이크에 되먹임되지 않는지
- [ ] 시연 총 소요가 90초 안에 끝나는지 (스톱워치)
- [ ] 백업 영상이 조작자 노트북에서 한 클릭으로 재생되는지
